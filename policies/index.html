서비스 이용 시 TETH AI에서 수집하는 정보의 유형을 이해하시기 바랍니다

TETH AI는 사용자에게 더 나은 투자전략 추천 및 검증 서비스를 제공하기 위해 정보를 수집합니다. 사용자가 입력한 전략 아이디어부터 백테스트 결과, 거래소 연결 상태, 페이퍼 및 실주문 기록까지 포함됩니다.

TETH AI 계정에 로그인하지 않고 랜딩 페이지를 둘러보는 경우, 브라우저/기기와 연결된 익명 식별자만 수집됩니다. 로그인한 경우 계정에 저장되며 개인정보로 취급됩니다.

수집 항목은 크게 세 가지입니다. 자세한 보관 기간은 정보 삭제 및 보관에서 확인하실 수 있습니다.

  • 대화로 입력한 전략 아이디어 및 자연어 프롬프트
  • 거래소 API 키 (읽기 및 주문 권한만, 출금 권한은 요청하지 않습니다 — 자세한 내용은 정보 보안 유지 참고)

  • 백테스트 및 페이퍼 실행 로그
  • 실주문 체결 기록 (거래소로부터 회신된 결과)
  • 로그인 시각, 접속 IP, 기기 정보

맞춤형 전략 추천

사용자의 관심 자산군(주식, 암호화폐, 금 등)과 과거 검증 이력을 바탕으로 유사 전략과 개선안을 추천합니다.

서비스 안정성 및 부정 이용 방지

비정상적인 API 호출, 자동화된 어뷰징을 탐지하기 위해 접속 로그를 활용합니다. 관련 정책은 관련 규제 준수 및 당국과의 협력 참고.

TETH AI는 사용자 정보를 함부로 공유하지 않습니다

TETH AI는 다음 경우에 한해서만 정보를 제3자와 공유합니다.

  • 사용자의 명시적 동의: 거래소 연결 시 사용자가 승인한 범위 내에서 주문 정보가 전달됩니다.
  • 서비스 제공 위탁: 클라우드 인프라, 결제 처리, 시장 데이터 공급사 등 서비스 운영에 필수적인 파트너에게 최소한의 정보만 제공합니다.
  • 법적 요구: 법령 또는 정당한 사법 절차에 따른 요청 시. 자세한 절차는 관련 규제 준수 및 당국과의 협력 참고.

거래소 연결은 어떻게 처리되나요

TETH AI는 두 가지 연결 방식을 제공합니다. 간편 연결과 API 키 연결입니다. 두 경우 모두 출금 권한은 요청하지 않으며, TETH AI가 사용자의 자산을 보관하지 않습니다.

파트너 거래소로 신규 가입한 경우 가입 즉시 자동 연결되며, 이용료 혜택이 제공됩니다.

API 키는 서버에서 암호화되어 저장됩니다. 암호화 방식은 정보 보안 유지에서 자세히 설명합니다.

정보 보호를 위해 서비스에 보안을 구축합니다

TETH AI는 사용자 정보를 지속적으로 보호하기 위한 다층 보안 체계를 운영합니다.

  • 데이터 전송 구간은 TLS 1.3으로 암호화됩니다.
  • 거래소 API 키는 저장 시 AES-256으로 암호화되며, 서명 필요 시에만 복호화되어 즉시 폐기됩니다.
  • 출금 권한이 부여된 API 키는 등록 자체가 차단됩니다.
  • 이상 로그인, 미승인 기기 접속 시 사용자에게 즉시 알림이 전송됩니다.
  • 내부 접근 통제, 감사 로그, 정기적인 취약점 점검을 수행합니다.

정보는 필요한 기간만 보관됩니다

계정 삭제를 요청하면 30일 유예 기간 후 영구 삭제됩니다. 다만 관련 법령상 보관이 요구되는 최소한의 거래 기록은 법이 정한 기간 동안 별도 보관됩니다.

국외 데이터 이전 및 파기 원칙

TETH AI의 운영 주체인 JOO HOLDINGS LTD.는 영국령 버진아일랜드(BVI)에 등록된 법인으로, 서비스 특성상 사용자의 개인정보가 국외 클라우드 인프라(AWS 싱가포르, 서울, 도쿄, 미국 리전 등)에서 처리될 수 있습니다.

국외 이전 시 관련 국제 표준(예: ISO/IEC 27001 관리 체계) 및 서비스 제공 지역의 개인정보 보호 법령이 요구하는 수준의 보호 조치를 적용하며, 이전 대상 국가·항목·목적·보유 기간을 본 방침에서 고지합니다.

사용자는 국외 이전에 동의하지 않을 권리가 있으며, 이 경우 일부 서비스 이용이 제한될 수 있습니다.

보관 기간이 만료된 전자적 파일은 복구 불가능한 방식으로 삭제되며, 출력물은 파쇄합니다.

법령 준수 및 당국 협력

TETH AI는 BVI 법인 규정 및 서비스 제공 지역의 개인정보 보호 법령을 준수합니다. 대한민국 사용자에 대해서는 개인정보보호법 및 정보통신망법상 관련 조항도 함께 적용됩니다.

정당한 사법 절차(영장 등)에 따른 정보 제공 요청 시, 요청 범위와 근거 법령을 검토한 후 필요 최소한의 범위에서 응답합니다.

투자 관련 위험 고지는 서비스 약관 요약에서 다룹니다.

사용자 대화가 AI 학습에 사용되나요

TETH AI는 기본값으로 사용자의 개별 전략 대화를 모델 학습에 사용하지 않습니다.

사용자가 개인정보 보호 설정에서 명시적으로 옵트인한 경우에 한해, 익명화된 대화 로그가 모델 개선에 활용됩니다.

익명화란 계정 식별자, 거래소 계정 정보, 실제 체결 데이터를 제거하는 절차를 의미합니다.

검증 및 거래 기록의 보관 방식

백테스트 결과와 페이퍼(Paper) 실행 로그는 사용자가 언제든 열람, 다운로드, 삭제할 수 있습니다.

실주문 기록은 관련 법령상 요구되는 기간 동안 보관됩니다. 자세한 사항은 정보 삭제 및 보관 참고.

모든 자동 매매 실행은 사용자가 사전에 승인한 조건 범위 내에서만 이루어지며, 1회 최대 손실은 설정한 한도(투자금의 1% 등)로 제한됩니다.

본 약관의 준거법은 영국령 버진아일랜드(BVI) 법률이며, 본 약관과 관련된 분쟁의 관할은 BVI 법원을 원칙으로 합니다. 다만 사용자의 소재지 법이 소비자 보호를 위해 달리 정하는 경우 해당 법이 우선 적용될 수 있습니다.

회원 자격, 이용 제한, 분쟁 해결에 관한 상세 조항은 전체 서비스 약관 문서를 참고하십시오.
