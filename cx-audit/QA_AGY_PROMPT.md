# [작업] TETH 블랙박스 프로덕트 QA (QA Commander: claude)

너는 처음 방문한 실제 사용자다. 대상: http://localhost:8741 (로컬 프리뷰, 원격은 https://aresjoo.github.io/tesia-lab/). 브라우저를 쓸 수 없으면 코드(`index.html`)를 사용자 여정 순서로 추적하며 UX 결함을 찾아라. **실호출은 총 8회 이내** (비용).

## 시나리오 (전부 수행)
1. 비로그인 첫 방문: 홈에서 서비스를 설명 없이 이해할 수 있는가, 첫 CTA는 명확한가
2. 로그인 → 첫 질문 "비트코인 어떰?" → 타임라인/사고/답변/후속 칩 경험
3. follow-up 2연속("그럼 이더리움은?", "왜?") → 맥락 유지, 이전 메시지 스크롤
4. 위임 칩 클릭 → 인테이크 5문항 → 전략 계약서 → 검증 워크스페이스 → 리포트 → 실행 온보딩(무료 경로, 새 탭 복귀) → 완료 → 대시보드: 각 화면에서 "지금 어디인가, 다음이 뭔가"가 명확한가
5. 뒤로가기/새로고침을 각 단계에서 시도 → 상태 복원
6. 응답 생성 중 사이드바로 다른 대화 이동, 즉시 새 질문 → 응답이 엉뚱한 곳에 붙는지
7. 랭킹 → 따라하기 → 재검증 흐름
8. 모바일 390px: 위 4번 여정 재현, 겹침/가로 스크롤/터치 타깃

## 채점 관점
버튼 눌렀는데 아무 일 없음, 다음 행동 모호, 개발자용 에러 노출, 상태 사라짐, 로딩 죽은 시간, 언어/톤 흔들림, 신뢰를 깨는 표현.
