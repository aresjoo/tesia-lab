핵심 실패는 다음과 같다.

- **짧게 요청을 초과:** 채권과 채권 ETF 설명은6문장·3단락, 확인된 손실 계산은5문장이다.
- **두 문장 요청을 초과:** 검증 여부가 미확인이라는 답에 독립 “맞습니다.”를 붙여3문장이 됐다. 보고서 전체에 검증 항목이 없다고 읽히는 출처 범위도 문제다.
- **번역에 지시를 섞음:** 번역만 요청했는데 대안 문장을 추가했다. 실제 helper는 번역 대상 문안의 “두 문장으로”를 응답 선호로 추출했다. 표현 경계 오류는 코드로도 재현했다.
- **React 질문 동선이 다름:** 실제 React Mock 화면은 RSI 뜻을 묻는 질문에 매수 진입 기준을 요구하고, 단일 조건 정정은4단계 전략 설정으로 보냈다. source 정책1.24가 이 producer에 적용되지 않는다.

정정 뒤 미정 조건7개·검증/미실행 고지를 반복하거나, “조금 더 자세히”에Markdown 본문14단락과 요청하지 않은 Calmar 비율까지 설명하는 부담도 있다. 축약할 때 계산 분모·체결 가정·실제 손실 초과 가능성은 보존해야 한다. 특히 별도로 고르는 ASK 카드의 독립 조건을 중복이라는 이유로 지우면 안 된다. 수동 교정 예시는 제안이며 새 모델 응답이나 해결 PASS가 아니다.
