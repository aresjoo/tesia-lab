# CLAUDE 독립 제안 — TETH 제품 모델과 UX 아키텍처 (v1, 토론 전)

역할: Head of Product + Principal UX Architect. 다른 에이전트 제안을 보기 전에 작성. 근거: ux/current/*, ux/research/*, 크롤 증거.

## 0. 한 문장 정의

**TETH는 사용자의 의도를 받아 전략을 만들고, 검증하고, 거래소에서 실행하고, 매 판단의 이유를 보여주는 AI 트레이딩 운영체제다.** 사용자는 TETH를 쓴다. Claude/GPT/Gemini/Grok/DeepSeek은 TETH가 작업마다 고르는 도구이며 전략의 정체성이 아니다.

성공 테스트: 첫 방문자 "TETH가 나 대신 AI 전략을 만들고 돌려주는구나". 로그인 사용자 "연결이나 결제 전에 먼저 써볼 수 있구나". 활성 사용자 "TETH가 내 전략을 돌리고 있고 지금 뭘 하는지 보이네".

## 1. 전략 유형 분류 (Phase 5)

| 유형 | 정의 | 누가 결정하나 | 판단 로그 형식 | UI 배지 |
|---|---|---|---|---|
| **AI 판단형** (Agent) | TETH가 주기마다 시장 맥락(가격 구조, 거래량, 뉴스, 심리, 포지션, 리스크 한도)을 보고 진입/추가/축소/청산/대기를 결정 | TETH | 에이전트 판단 카드(확인한 것 → 결정 → 이유 2~4줄 → 행동 → 다음 확인) | `AI 판단` |
| **규칙형** (Rule) | 명시적 조건식(RSI, 이평, 돌파, 손절/익절). AI가 만들어 줄 수는 있으나 실행은 규칙이 함 | 규칙 | 규칙 로그(검사한 규칙 → 조건 결과 → 트리거 → 주문 → 리스크 규칙) | `규칙` |
| **결합형** (Rule + AI veto) | 규칙이 신호를 내고 TETH가 맥락으로 거부/축소 | 규칙 제안, TETH 승인 | 규칙 로그 + 거부 사유 한 줄 | `규칙 + AI 검토` |
| **따라가기** (Follow) | 다른 사용자(또는 TETH 공식 에이전트)가 운용하는 전략을 내 예산으로 복제 실행 | 원 전략 | 원 전략의 로그를 그대로 보되 "내 체결"만 강조 | `따라가는 중` |

- "워뇨띠 학습형 #15367" 같은 이름은 **폐기**. "누구의 매매 스타일에서 영감을 받은 AI 판단형"이라면 유형은 AI 판단형이고, 이름은 행동을 말해야 한다(예: `BTC 급락 후 분할 진입`, 부제 "워뇨띠식 낙폭 매수 스타일을 학습"). 학습·행동복제 여부는 상세의 "어떻게 만들어졌나" 한 줄로만.
- 모델 벤더는 전략 속성이 아니다. 상세 → 기술 정보 → "이번 판단에 사용: Claude(구조 설계), Gemini(뉴스), 시세 도구"처럼 판단 단위로만 표시.

## 2. 전략 이름 체계

**제목 = 자산 + 행동 (+ 성격)**, **부제 = 언제 사고 언제 쉬는지 한 줄**. 닉네임은 작성자 필드로 분리. 클릭베이트 금지.

| 현행 | 제안 제목 | 부제 |
|---|---|---|
| 월급두배 (비트코인) | BTC 눌림목 추세 추종 | 강한 추세에서 조정이 끝날 때만 진입, -5%면 정리 |
| 세븐틴층 (비트코인) | BTC 추세 확인 후 진입 | 추세가 확인되기 전에는 움직이지 않아요 |
| 바닥만줍는사람 | BTC 급락 후 반등 포착 | 낙폭이 큰 날만 노리고, 반등이 약하면 건너뜀 |
| 조용한복리 (나스닥) | NASDAQ 저변동 스윙 | 손절 -3%, 익절 +10%의 느린 복리 |
| 안정 추세형 · 비트코인 (인트로) | BTC 추세 추종 · 보수형 | 추세가 뚜렷하고 잠깐 눌린 자리가 올 때만 사요 |
| 비트코인 위임 전략 (터미널) | BTC 추세 추종 · 보수형 (내 전략) | |

규칙: 제목 ≤ 14자(한글 기준), 자산 티커 우선(BTC/ETH/SOL/NASDAQ), 행동 어휘 사전(추세 추종 / 눌림목 / 급락 반등 / 변동성 돌파 / 평균회귀 / 모멘텀 / 분할 매집 / 시장 중립), 성격 접미(보수형/공격형/저변동/중기)는 선택.

## 3. AI 트레이딩 = 세 제품, 한 메뉴 (Phase 6)

### A. 게스트: "TETH를 갖고 싶게"
- 히어로 한 줄: **"말하면, TETH가 전략을 만들고 검증하고 거래소에서 돌립니다"** + 부제 "매 판단의 이유까지 보여줘요". CTA `무료로 시작` 단일. 로빈후드 번역 카피(에이전트에게 시장 접근 권한…, 주식·옵션) 제거.
- 첫 스크롤에 **살아있는 증거 1개**: TETH 공식 에이전트 1개의 실시간 판단 상태 카드(관망 중 / 무엇을 보는지 / 마지막 확인 N초 전) + 소형 성과. 3D 타일 히어로 이미지는 배경으로 축소.
- 섹션 순서: ①정의+CTA+라이브 카드 → ②"이런 전략을 돌려요" 3장(유형별 1장: AI 판단형 / 규칙형 / 따라가기, 제목·부제·30일·MDD) → ③판단 로그 실물(에이전트 카드 1장 + 규칙 카드 1장, 둘이 다르다는 걸 보여줌) → ④3스텝(말하기 → 검증 → 연결·실행) → ⑤통제(예산/승인/정지, 기존 벤토 축소) → ⑥CTA 반복.
- 삭제: 리더보드의 모델 컬럼, "한 모델에 맡기지 않습니다" 로고 궤도(→ ③의 기술 정보 한 줄 "작업마다 Claude·Gemini 등을 고릅니다"로 격하), 아이폰 목업, 미니 푸터의 "터미널 미리 둘러보기"는 유지하되 ①의 라이브 카드 클릭으로 흡수.
- 전략 따라하기 허브는 게스트에게 계속 공개(관전 → 욕구).

### B. 로그인, 미활성: "가치를 증명하고 활성화로"
- 같은 페이지가 아니라 **"내 AI 트레이딩" 준비 화면**. 상단: "안녕하세요 도현님. 아직 돌아가는 전략이 없어요. 연결이나 결제 없이 여기까지 해볼 수 있어요" + 3개 행동(전략 만들기 / 공개 전략 골라보기 / TETH에게 묻기).
- 중앙: 무료 체험 진행 바(무료 분석 N회 중 M회 사용) — 게이트가 어디인지 미리 보여줌.
- 하단: **활성화 카드 1장**(두 개의 동등 박스 금지). 추천 = 거래소 연결(Bitget) "약 1분, 자산 이동 없음, 거래하면 TETH 이용료가 상쇄돼요". 그 아래 텍스트 링크 "거래소 연결 없이 카드로 이용하기". 24/7 도움 한 줄.
- 전략을 만들고 검증까지 끝낸 뒤 실행 버튼을 누르는 순간이 게이트(서비스 플로우 확정 위치 유지).

### C. 활성: 터미널 (Phase 8)
운영 화면. 마케팅 0.

- **상단 컨텍스트 바(고정)**: 전략 이름 · 유형 배지 · 거래소/마켓 · 상태(실행 중/일시정지/오류) · 운용금 · 오늘/누적 P&L · [일시정지] · 24/7 도움(작은 아이콘).
- **좌 레일**: 내 전략 목록(사용자 전략만. 데모 6개는 "예시 전략" 별도 접힘 섹션으로 격리하고 QA 프리셋에서만 채움).
- **중앙**: 차트 + 판단 마커(에이전트 판단은 점, 체결은 화살표).
- **우 = TETH 에이전트 패널**. 2초 안에 답해야 할 블록이 최상단 고정:
  ```
  TETH가 보고 있어요            마지막 확인 12초 전
  BTC/USDT · 포지션 없음
  기다리는 것: 4시간봉 모멘텀 확인
  다음 확인: 다음 봉 마감(52분 후)
  ```
  그 아래 활동 타임라인(연속 관망은 "관망 중 · 12회 · 36분"으로 접음), 그 아래 질문 칩 4개(왜 아직 진입 안 했어? / 지금 가장 큰 리스크는? / 다음 진입 조건은? / 더 보수적으로 바꿔줘) + 입력.
  삭제: "사용자 프롬프트 / 생각의 사슬" 접기(CoT 극장), "TETH 에이전트 · 시장 분석" 반복 카드.
- **하단 탭**: 포지션 · 미체결 · 주문 내역 · 체결 · 종료 포지션 · 자산 (유지) + 스코프 토글을 탭 왼쪽으로.
- 모바일: 컨텍스트 바 → 에이전트 상태 블록 → 차트(접힘 가능) → 활동 → 하단 탭.

## 4. 판단 로그 (Phase 7)

**에이전트 판단 카드** (AI 판단형/결합형)

이유      4시간봉이 아직 범위 안이라 추세 판단을 유보. 급락 뒤 반등 신호도 약함.
행동      주문 없음
다음 확인 4H 봉 마감 또는 ±2% 급변 시
```
**규칙 로그 카드** (규칙형)
```
14:00  규칙 검사: RSI(14) ≤ 44 → 38 ✓ · 추세 필터(SMA20>SMA60) → ✗

```
원칙: 입력·결정·행동·근거만. 가짜 내면 독백 금지. 카드 제목은 "TETH 에이전트"가 아니라 결정 동사(대기/진입/축소/청산).

## 5. 전략 따라하기 = 마켓플레이스 (Phase 9)

- 히어로·카운터 삭제. 첫 화면 = 필터 바 + 리스트.
- **리스트 행/카드 위계**: 제목(자산+행동) · 유형 배지 · 부제 → **30일 수익률(크게)** · 소형 자산곡선(30일, 실선) → MDD · 운용 기간 · 팔로워 · 팔로워 수익 → 위험도(낮음/보통/높음) → [따라가기].
- 정렬: 종합(공개 가중치: 30일 수익 30 / MDD 25 / 운용 기간 20 / 팔로워 수익 25) 기본, 수익률 / 안정성(MDD) / 팔로워 / 운용 기간. 필터: 기간(30/90/전체) · 시장(BTC/ETH/알트/전체) · 유형 · 위험도. 4개 이하.
- 라이브 성과와 검증 성과를 분리 표기: 운용 기간이 30일 미만이면 "검증 기준" 배지, 이상이면 라이브 수치.
- **상세 탭**: 개요(무엇을 하나·지금 뭘 하나·누가) / 성과(곡선+낙폭+기간 지표) / 거래(포지션·체결) / 활동(판단 로그) / 정보(만든 방법, 사용 도구, 버전). 백테스트 리포트 12섹션은 성과 탭 안으로 흡수.
- **따라가기 설정 3단계**: ①금액(예산) ②최대 손실(전략 단위, 기본 20%) ③고급(선택: 기존 포지션 복제 여부, 주문당 상한) → 검토(요약 1장) → [따라가기 시작]. cp 트레이더 프로필(407일차/카피어 4/500/총자산) 세계관은 상세 "개요 탭"으로 흡수하고 별도 라우트 폐기.
- **내 공유(크리에이터)**: 별도 탭 "내 전략 공유"에서 공개 여부, 팔로워, 팔로워 수익, 보상. 탐색 카드에 크리에이터 컨트롤 없음.
- 용어 통일: **따라가기**(리스트/상세/설정/상태 전부). "복제/카피" 폐기. 인트로 리더보드 "복제하기"는 "따라가기"로.

## 6. 지원 거래환경 (Phase 10)

- 페이지 이름 후보: **"거래소 연결"** (행동형, 사이드바 1급 승격). 대안 "지원 거래환경"(명사형, 약함).
- 구조:
  1. **추천: Bitget** 카드 1장 = 연결 상태(미연결/연결됨) · 약 1분 · 자산 이동 없음 · 현물/선물 지원 · TETH 이용료 상쇄 · [Bitget 연결하기] · "계정이 없어요 → 만들기(2분)" 링크 · 24/7 도움.
  2. **다른 지원 거래소**: Binance · OKX · Bybit (한 줄 리스트: 이름·지원 범위·[연결]).
  3. **준비 중**: 텍스트 한 줄로 축소(업비트, 코인베이스 등). 증권사/브로커 15개 카드 삭제.
- 삭제: App Store 평점, 리뷰, 회사 연혁, 수수료 표(상세의 "정보" 접힘으로), 필터 6개, "계정 개설↗" 1차 CTA.
- 거래소 상세는 유지하되 "TETH에서 이 거래소로 무엇을 할 수 있나 + 연결 방법 + 상태"만.

## 7. 연결 · 결제 = 체크아웃 (Phase 11)

**개념 2개만 남긴다.**
- **거래소 연결**(= UID 연동 + 실행 권한을 한 번에 요청). 사용자 어휘: "거래소 연결". 내부적으로 UID 판정과 API 키 등록이 분리되더라도 화면은 한 흐름("연결 중… 계정 확인 → 거래 권한 확인 → 완료").
- **카드 등록**(대안). "구독/PRO/플랜/크레딧/Fast API"는 사용자 화면에서 삭제.

체크아웃 화면(활성화 게이트에서 1회):
```
