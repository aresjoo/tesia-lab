# UX_COPY_SYSTEM — 카피 규칙과 교체표

## 규칙
1. 순서: 가치 → 행동 → 기술. 헤드라인은 "왜 신경 써야 하나"에 답하고, CTA는 "다음에 무슨 일이 일어나나"를 동사로 말한다.
2. 엔진에 없는 것은 약속하지 않는다(호가창 분석, 뉴스 실시간, 확률 %, 평생 무료, 상위 1%, 원격 세팅, 1분 보장 등). 시간 표현은 "약 1분"처럼 근사로.
3. 거래를 늘리라는 능동 권유 금지. 상쇄는 사실만("₩X 중 ₩Y 상쇄").
4. 사용자 어휘만: 거래소 연결 / 카드 등록 / 이용료 / 상쇄 / 무료 체험 / 모의 / 실거래. 금지: UID·Fast API·API 키(입력 필드 라벨에서만 허용)·PRO·플랜·크레딧·소진·업그레이드·위임·구독 멤버십·정산 엔진·체험 모드.
5. 전략 유형 3개 어휘: AI 판단 / 규칙 / 따라가기. 판단 동사: 대기 / 진입 / 추가 / 축소 / 청산. "사요/팔아요/쉬어요" 금지.
6. 데모 고지는 화면당 최대 1곳, 문장은 "시뮬레이션 데이터예요"로 통일.
7. 문장부호: em dash, 가운뎃점 금지(쉼표). 존댓말 "~해요"체. 브랜드 표기 TETH.
8. 모델명(Claude, GPT, Gemini, Grok, DeepSeek)은 (a) 연결 완료 화면 1회 (b) 활성화 시트 불릿 1줄 (c) 상세 정보 탭 "이번 판단에 사용"에만. 버전명 금지.
