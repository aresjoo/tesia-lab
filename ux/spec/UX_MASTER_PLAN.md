## 0. 제품 정의
**TETH는 사용자의 의도를 받아 전략을 만들고, 검증하고, 거래소에서 실행하고, 매 판단의 이유를 보여주는 AI 트레이딩 운영체제다.** 사용자는 TETH를 쓴다. 기반 모델(Claude/GPT/Gemini/Grok/DeepSeek)은 TETH가 작업마다 고르는 도구이며 전략의 정체성이 아니다. 세 유형이 공존한다: AI 판단형 / 규칙형 / 따라가기.

성공 테스트(모든 화면): 3초 안에 "어디인가 / 무슨 일이 일어나나 / 다음에 뭘 하나 / 왜 신경 써야 하나".

## 2. 전략 유형·이름·표시 규칙

| kind | 배지 | 정의 | 판단 로그 |
|---|---|---|---|
| agent | AI 판단 | TETH가 주기마다 시장 맥락(가격 구조·거래량·뉴스·포지션·리스크 한도)을 보고 진입/추가/축소/청산/대기 결정 | 에이전트 카드 |
| rule | 규칙 | 명시 조건식. AI가 만들 수 있으나 실행은 규칙 | 규칙 카드 |
| hybrid | 규칙 + AI 검토 | 규칙 신호에 TETH 거부권. 생성 메뉴에는 agent 고급 옵션으로만 노출 | 규칙 카드 + 검토 한 줄 |
| follow | 따라가는 중 | 다른 전략을 내 예산으로 복제 실행 | 원본 로그 + 내 체결 |

**이름 = 자산 + 행동 (+성격)**, 부제 = 언제 사고 언제 쉬는지 한 줄. 파라미터에서 도출(trendFilter→"추세 추종", rsiTh≤40→"급락 반등", 그 외 "눌림목", sl≥-3→"보수형"). 작성자 닉네임은 별도 필드. 모델 벤더·마케팅 명사(수호자)·닉네임·클릭베이트 금지. 모델명은 상세 "정보" 탭의 "이번 판단에 사용" 한 줄에만.

기존 시드 매핑(제목/부제):
- 월급두배 → BTC 눌림목 추세 추종 / 추세가 뚜렷할 때 눌린 자리에서 사고, +8%면 팔고 -5%면 멈춰요
- 세븐틴층 → BTC 추세 확인 후 진입 / 추세가 확인되기 전에는 움직이지 않아요
- 바닥만줍는사람 → BTC 급락 후 반등 포착 / 낙폭이 큰 날만 노리고, 반등이 약하면 건너뜀
- 조용한복리 → NASDAQ 저변동 스윙 / -3% 손절, +10% 익절의 느린 복리
- 느긋한스윙 → ETH 눌림목 스윙 / 2년 검증, 보유 평균 20일
- 리스크헌터 → NASDAQ 추세 추종 · 공격형 / 익절 +15%
- 천천히꾸준히 → BTC 급락 반등 · 보수형
- 단타는안해요 → ETH 추세 추종 · 장기
- 터미널 user 전략 "비트코인 위임 전략" → 자산+행동 규칙으로 자동 명명. 데모 d1~d6는 preview 컨텍스트로 이동.

## 3. AI 트레이딩 3뷰 (#/trade 하나, 세 화면)

### 3A 게스트 뷰 (tfIntroView 교체)
목적: TETH를 갖고 싶게. CTA 1개 `무료로 시작`.
1. 히어로: "말하면, TETH가 전략을 만들고 검증하고 거래소에서 돌립니다" / 부제 "매 판단의 이유까지 보여줘요" / CTA / 보조 링크 "터미널 미리 보기(preview)". 배경 3D 타일은 축소·저채도.
2. 라이브 에이전트 카드 1장(공식 예시 전략): "TETH가 보고 있어요 · BTC/USDT · 포지션 없음 · 기다리는 것: 4시간봉 모멘텀 확인 · 마지막 확인 12초 전"(틱 갱신).
3. "이런 전략을 돌려요" 3장: AI 판단형 / 규칙형 / 따라가기 각 1장(제목·부제·30일·MDD·배지). 모델 컬럼 없음.
4. 판단 로그 실물: 에이전트 카드 1장 + 규칙 카드 1장 나란히(둘이 다르다는 것을 보여줌).
5. 3스텝: 말하기 → 검증 → 연결·실행.
6. 통제 4항목(예산 안·승인 후·출금 권한 없음·한 번에 정지) 한 줄 리스트 + 긴급 정지 버튼 시각.
7. CTA 반복 + 미니 푸터.
삭제: 로빈후드 번역 카피, 리더보드 모델 컬럼(리더보드 자체는 3장 카드로 대체), 모델 궤도 섹션, 아이폰 목업, 듀얼 CTA.

### 3B 미활성 뷰 (신설 tfTradeInactiveView)
목적: 가치 증명 후 활성화. 두 층.
- 초안 없음: "도현님, 아직 돌아가는 전략이 없어요. 연결이나 결제 없이 여기까지 해볼 수 있어요" + 행동 3개(전략 만들기 [1차] / 공개 전략 골라보기 / TETH에게 묻기) + 무료 체험 잔량 바(N/10).
- 검증된 초안 있음: 초안 카드(제목·부제·검증 요약·[이 전략 실행하기] 1차) + 활성화 진행 요약(Codex activation: 요금 연동 / 실행 연결 / 예산 3행 상태).
- 하단 활성화 카드 1장(추천 Bitget 연결: 약 1분·자산 이동 없음·거래하면 이용료 상쇄 / 텍스트 링크 "연결 없이 카드로 이용하기" / 도움 행). 두 개의 동등 박스 금지.
- 삭제: 히어로, "영원히 무료" 획득 카피, 마케팅 섹션.

### 3C 터미널 (tfDashView 개편)
- 상단 컨텍스트 바: 전략 제목 · kind 배지 · 거래소/마켓 · 상태 · 운용금 · 오늘/누적 P&L · [일시정지] · 도움 아이콘.
- 좌 레일: 내 전략만(selectOwnedStrategies: user + clone + follow). 비어 있으면 미활성 뷰로.
- 중앙 차트: 유지. 판단 마커(점)와 체결 마커(화살표) 구분.
- 우 에이전트 패널 상단 고정 블록: "TETH가 보고 있어요 / 마켓·포지션 / 기다리는 것 / 다음 확인 / 마지막 확인". 그 아래 활동 타임라인(연속 관망 접기: 3회 이상 → "관망 중 · N회 · M분"), 질문 칩 4개(왜 아직 진입 안 했어? / 지금 가장 큰 리스크는? / 다음 진입 조건은? / 더 보수적으로 바꿔줘) + 입력.
- 삭제: "사용자 프롬프트 / 생각의 사슬 / 거래 결정" 접기, "TETH 에이전트 · 시장 분석" 반복 카드, "위임" 어휘, KRW 표기.
- 하단 탭 유지 + 스코프 토글을 탭 왼쪽.
- 데모 6개: `#/trade?preview=1` 컨텍스트에서만 표시(게스트 "터미널 미리 보기"와 QA 프리셋용). 상단 "데모 체험 · 내 화면으로".
- 모바일(<768): 컨텍스트 바 → 에이전트 상태 블록 → 차트(접힘 가능) → 포지션 요약 → 활동 피드·입력.

## 4. 판단 로그 두 형식
에이전트 카드: `시각 · 결정(대기/진입/추가/축소/청산)` / 확인한 것(실제 입력 신호 3~6개) / 이유 2~4줄(입력에서 도출 가능한 것만) / 행동 / 다음 확인. confidence 숫자 비노출.
규칙 카드: `시각 · 규칙 검사` / 규칙별 값과 ✓✗ / 결과 / 주문 / 리스크 규칙.
기존 엔진 이벤트(event.k=watch/scan/entry/risk/exit)는 규칙 카드로 렌더(source=backtest). 에이전트 카드는 agent kind 전략에만, 결정론적 fixture로 생성(가짜 확률·기관 매수세 같은 날조 금지).

## 5. 전략 따라하기 = 마켓플레이스
- 히어로·카운터 삭제. 첫 화면 = 필터 바 + 리스트.
- 카드/행: 제목 · kind 배지 · 부제 · 작성자 → 30일 수익률(크게) + 소형 곡선 → MDD · 운용 기간 · 팔로워 · 팔로워 수익 → 위험도 → [따라가기]. 라이브 30일 미만은 "검증 기준" 배지.
- 정렬: 종합(공개 가중치: 30일 수익 30 / (1-MDD) 25 / 운용 기간 20 / 팔로워 수익 25, 결측 재분배) 기본, 수익률 / 안정성 / 팔로워 / 운용 기간. 필터: 기간 · 시장 · 유형 · 위험도.
- 상세 탭: 개요(무엇을·지금 뭘·누가·[따라가기] 1차) / 성과(곡선+낙폭+지표) / 거래 / 활동(판단 로그) / 정보. 12섹션 리포트는 성과 탭으로.
- 따라가기 3단계: 예산 → 최대 손실(전략 단위, 기본 20%) + 기존 포지션 처리(기본 건너뛰기) → 검토·시작. 중단 시 3택(지금 정리 / 원본 청산 대기 / 직접 관리).
- 용어 통일: 따라가기. "복제/카피" 폐기. ss3 "설정 가져오기"는 보조 액션(가져오기)으로 별도 라벨.
- cp 트레이더 프로필 세계관(407일차·카피어 4/500·총자산)은 상세 개요 탭으로 흡수, 수치 모순 제거(원본 시드 1개 = 수치 1벌).
- 내 공유: 별도 탭. 탐색 카드에 크리에이터 컨트롤 없음.
