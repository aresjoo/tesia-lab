# TETH 제품 UX 재구축 최종 보고 (2026-09-25, 브랜치 ux/product-model)

## 1. 발견한 가장 큰 제품 문제 5개
1. TETH가 무엇인지 화면마다 달랐다. 홈은 종목 챗봇, 인트로는 로빈후드 카피 번역("에이전트에게 시장 접근 권한을…주식, 옵션"), 리더보드는 Claude/GPT/Gemini 모델 쇼케이스, 검증 화면은 내부 엔진 4개 이름.
2. 규칙형 봇에 LLM 사고 극장을 씌워 "AI 판단"처럼 보이게 했다("생각의 사슬", "사용자 프롬프트" 접기, "총알을 아끼고…" 서사). AI 판단형과 규칙형의 구분이 제품 어디에도 없었다.
3. 게스트, 로그인, 활성 사용자가 같은 페이지를 봤다. 로그인 직후에도 "영원히 무료, 신용카드 필요 없음"을 다시 보여주고, 전략 1개가 생기면 데모 전략 6개(₩2,800만 운용 중)가 "내 전략"처럼 섞였다.
4. 활성화가 네 문(퍼널 ₩0 vs ₩599,000 앵커, PLAN "Fast API", 지원 거래소 "계정 개설↗", QA 토글)으로 쪼개져 UID·Fast API·API 키·파트너 시작·기존 계정 연결 7개 이름을 썼다. 11개 상업 상태 중 거래량·AI 사용량 축은 상태 모델에 존재하지 않았다(Codex 격리 실행으로 확인).
5. 전략 따라하기는 백테스트 갤러리(닉네임 제목 "월급두배", 7자리 카운터 "모의 검증으로 계산된 거래")와 Bitget 카피 UI 이식(같은 사람이 +14.7%와 -2.72%)의 혼종이었고, 지원 거래소는 App Store 평점과 가짜 리뷰가 달린 21개 브로커 디렉터리였다.

## 2. 최종 UX 아키텍처
- 정의: "사용자 의도 → 전략 생성 → 검증 → 거래소 실행 → 매 판단의 이유"를 한 제품에서. 기반 모델은 도구.
- 파생 상태 엔진 `tfDerive()` 하나가 로그인·요금 연동(UID)·실행 연결(API)·카드·AI 사용량 구간·거래량 구간을 읽어 stateId(1~11), 청구 라인, 1차/2차 CTA, 자격, 터미널 모드를 낸다. 모든 화면은 이것만 읽는다.
- 사이드바 1급: 새 전략 / AI 트레이딩 / 전략 따라하기 / 거래소 연결(신설). 설정 메뉴: 이용 현황(구 PLAN).
- 라우트 문자열은 전부 유지, 뷰 함수만 교체(딥링크 호환).

## 3. 재구축한 주요 화면
게스트 랜딩 / 로그인 미활성 뷰(신설) / 터미널(컨텍스트 바, 에이전트 상태 블록, 판단 카드 2형식, 긴급 정지, 데모 preview 격리, 모바일 세그먼트) / 활성화 시트 + Bitget 한 폼 연결 + 완료 화면 / 이용 현황 / 전략 따라하기 허브·카드·상세 5탭·따라가기 시트·중단 3택 / 거래소 연결 페이지·상세 / QA 제품 실험실 / 홈 배지 제거.

## 4. 게스트 / 로그인 / 활성의 차이
- 게스트: "밤새 차트 보지 마세요…" + 라이브 에이전트 카드 + 3유형 전략 카드 + 판단 카드 2종(AI vs 규칙) + 3스텝 + 통제 4항목. CTA `무료로 시작` 하나. 데스크톱은 `터미널 미리 보기`(데모 6개 preview).
- 로그인 미활성: 온보딩 4단계 바, "도현님, 아직 돌아가는 전략이 없어요", 1차 `대표 전략 모의로 켜보기`(규칙형 paper, 연결·결제 없이), 직접 만들기, 공개 전략 골라보기, 무료 체험 잔량, 활성화 카드 1장(Bitget 추천 + 카드 대안 + 24/7 문의). 검증된 초안이 있으면 `이 전략 실행하기`.
- 활성: 운영 화면. 컨텍스트 바(제목·유형·거래소/마켓·상태·운용·P&L·일시정지·긴급 정지·도움), 내 전략만(데모 없음), 우측 "TETH가 보고 있어요" 블록 → 판단 카드 → 전략 관리 행 → 질문 칩 4개.

## 5. 전략 이름·유형 체계
- 유형 3개 노출: AI 판단 / 규칙 / 따라가기 (결합형은 규칙의 "AI 검토 켜짐" 태그). 모델 벤더는 전략 정체성에서 제거(상세 정보 탭 "이번 판단에 사용"에서만).
- 이름 = 자산 + 행동(RSI 깊이: 급락 반등 / 깊은 눌림 반등 / 눌림목 반등 매수) + 통제 어휘(추세 구간, 보수형, 공격형, 짧은 익절, 넓은 손절). 부제 = 실제 판정식 한 줄("RSI 44 아래로 눌렸다가 반등하면 사고, +12%에 팔고 -5%면 멈춰요. 추세 구간에서만 사요."). 닉네임은 "작성자" 필드와 URL 식별자로만. "워뇨띠 학습형 #15367"류는 영감 출처를 상세 정보에 한 줄로만 쓰고 제목에 못 쓴다.

## 6. 전략 따라하기 모델
- 리스트: 필터 바 + 카드(제목·유형·부제·작성자 → 선택 기간 검증 수익률 + "검증 기준(백테스트 N개월)" + "수수료 반영" → MDD·검증 기간·팔로워·팔로워 수익(자료 없으면 "-") → 위험도 → [따라가기]). 기본 정렬 검증 수익률, 칩 안정성/거래 수/검증 기간. 종합 점수와 팔로워 손익 정렬은 근거 없어 폐기.
- 상세: 개요(지금 뭘 하나 = 실제 규칙 검사 결과) / 성과(4타일 + 곡선 + 히트맵, 나머지 접힘) / 거래 / 활동(규칙 카드) / 정보.
- 따라가기: 시트 1장(예산 → 최대 손실 → 시작, 고급 접힘). 중단 3택. 트레이더 프로필 세계관 폐기(라우트는 상세로 리다이렉트), 카피 계정 성과는 "내 따라가기 계정"으로 분리 표기.

## 7. 거래소 연결 모델
- 페이지 "거래소 연결"(사이드바 1급). Bitget 추천 카드가 화면 대부분(상태 배지 5종, 약 1분, 자산 이동 없음, 이용료 상쇄, 권한 3행, [Bitget 연결하기], 계정 만들기 링크, 24/7 문의). 다른 지원 거래소는 한 줄 행, 준비 중은 접힘. 평점·리뷰·회사 정보·수수료 표(접힘) 삭제.
- 연결 = UID + API 한 폼, 내부 두 체크 행(요금 연동 / 실행 연결), 부분 실패 재시도. 완료 화면 1회(멀티모델 문장 + coverage 조건부 상쇄 문장).

## 8. 11 상태 표현
QA 프리셋 11개(스냅샷 통째 교체) → `tfDerive()` → 이용 현황(상태 문장 + 상쇄 바 + 공식 한 줄 "플랜 ₩49,000 - 상쇄 ₩49,000 = 청구 ₩0" + 줄이는 방법 + 연결 상태 2행), 미활성 뷰 헤드, 활성화 시트 CTA. 검증 결과(데모 정책 상수): ②₩0 무료 체험 / ③₩0 첫 거래 대기 / ④부족분 ₩9,000 / ⑤₩0 상쇄 / ⑥₩64,000 + 거래소 연결 CTA / ⑦₩49,000 / ⑧₩14,000 / ⑨₩49,000 / ⑩₩0 "대신 냈어요" / ⑪₩34,000. 플랜+연동+거래0은 내부 unclassified, UI는 "첫 거래 대기". 거래 늘리라는 문구 0.

## 9. QA 변경
QA 버튼은 localhost 또는 `tethDev=1`에서만. 패널 = 시나리오 11버튼 / 오버레이 6(활성 전략, 데모 미리 보기, 판단 로그 채움, 결제 실패, 크레딧 다 씀, 관망) / 기대값 카드(현재 상태·1차 CTA·청구·자격·거래소·터미널 모드·확인 화면, PASS/FAIL 저장) / 진척판 10항목 / 고급(원시 토글 9개).
