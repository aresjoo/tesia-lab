## 3. 스크린샷 간 상태 불일치 목록

1. **거래소 연결 완료 후 대시보드 활성화 블록 잔류 모순**
   - 증거: `d1440__s03_connectpage.png` vs `d1440__s03_trade.png`
   - 내용: `connectpage`에서는 Bitget이 '연결됨'으로 완결되었으나, 동일 프리셋의 메인 화면인 `trade`에서는 하단에 `TETH 활성화 (Bitget 연결하기 / 카드 등록)` 섹션이 사라지지 않고 그대로 남아 재연결/카드 등록을 촉구함. (index.html L15278 `!(apiDone&&cardDone)` 버그).

2. **소유 전략 0개 계정의 1차 CTA 라벨 불일치**
   - 증거: `d1440__s03_trade.png` vs `d1440__s03_connectpage.png`
   - 내용: 소유 전략이 전혀 없는 Preset 03에서 `trade` 화면은 '대표 전략 모의로 켜보기'를 권장하지만, `connectpage`는 전략이 없음에도 상단에 '터미널 열기' 버튼을 제공하여 클릭 시 빈 대시보드로 튕기는 멘탈모델 오류 유발.

## 4. 이번 라운드에서 "삭제만으로" 해결되는 것 목록

1. **미활성 뷰 최하단 '터미널 미리 보기' 링크 삭제**: 로그인 대시보드 하단에 잔존하는 게스트 전용 미리보기 링크를 완전히 제거하여 회원 계정과의 경계 분리.
2. **거래소 연결 완료 후 온보딩 문구 삭제**: Bitget 연결 완료 화면에서 의미를 상실한 `✓ 약 1분`, `✓ 자산 이동 없음` 불릿 텍스트 삭제.
3. **전략 카드 그리드의 결측 메트릭 삭제**: 시드 데이터에 존재하지 않아 100% 빈 대시(`-`)로만 출력되는 '팔로워 수익' 수치 및 라벨 블록 삭제.
4. **활성화 완료 계정의 미활성 화면 활성화 섹션 컨테이너 삭제**: API 또는 카드 중 하나라도 활성화된 경우 화면 하단의 중복 `tx-ac` 섹션 렌더링 삭제.
5. **터미널 영구 잔류 토스트 DOM 삭제**: 화면 로드 시 생성되어 포지션 탭 영역을 가리고 사라지지 않는 `전략이 시작됐어요` 토스트 엘리먼트 삭제.
6. **게스트 뷰 통제 섹션 우측 더미 버튼 삭제**: '결정권은 항상 회원님에게 있어요' 우측에 기능 없이 비활성화(disabled)된 갈색 `긴급 정지` 버튼 삭제.
7. **모바일 마켓 상단 중복 기간 필터 행 삭제**: 좁은 390px 화면에서 세로 4단을 차지하는 필터 중 2번째 행인 `[검증 기간] 기간 [1년] [2년] [전체]` 칩 행 삭제.
8. **거래소 상세 지원 기능 내 금지어 삭제**: Bitget 상세 페이지의 지원 기능 태그에 남아 있는 `카피 트레이딩` 뱃지 텍스트 삭제.
9. **규칙형 전략 터미널의 에이전트 더미 피드 카드 삭제**: 규칙형 봇 구동 시 맥락 없이 피드에 강제 주입되는 `AI 판단 고정 fixture, 시뮬레이션` 정적 카드 삭제.
