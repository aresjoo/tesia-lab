# CURRENT_PROBLEMS — 현행 제품의 문제 (Claude, Head of Product 관점)

기준: 크롤 증거(scratchpad/crawl/*.json, *.png), CURRENT_IA.md. 등급: P0=멘탈모델/상태논리/전환 오류, P1=위계·사용성, P2=폴리시.
컴플라이언스 관점은 배제. "목업이라서"는 변명이 아니라는 전제로 씀.

## P0 — 제품 모델이 틀린 곳

### P0-1. "TETH가 무엇인가"가 화면마다 다르다
- 홈: "차트 대신 말로 하세요 / 템플릿 또는 채팅으로 투자를 설명하세요. TETH 모델로 만듭니다" → 챗봇 워크스페이스.
- 인트로 히어로: "AI가 거래하게 만드세요 / AI 에이전트에게 시장 접근 권한을 몇 분 만에 연결하세요. 당신을 위해 주식, 옵션 및 암호화폐 거래를 시작하게 만드세요" → 로빈후드 Agentic 카피의 번역. TETH는 "에이전트를 가져오는" 제품이 아니라 "에이전트인" 제품인데, 이 문장은 사용자에게 에이전트를 연결하라고 말한다. 주식·옵션은 이 제품에 없다.
- 인트로 리더보드: 전략 = "안정 추세형 · 비트코인 + 모델 컬럼(Claude/GPT/Gemini)" → 모델 벤더 쇼케이스.
- 검증 화면: "4개의 전문 분석 엔진(Strategy Architect/Quant Validator/Risk Reviewer/Explanation AI)" → 내부 파이프라인 노출.
- 터미널: "비트코인 위임 전략 / Binance 위임 실행" → "위임"은 내부 법무 어휘.
- 결론: 방문자는 "챗봇인가, 에이전트 연결 툴인가, 백테스터인가, 모델 5개 묶음인가"를 판단할 수 없다.

### P0-2. 전략의 정체성이 "모델 벤더"로 표현된다
- 인트로 리더보드 컬럼 "모델"에 Claude/GPT/Gemini가 전략의 속성으로 붙어 있다. 사용자가 "GPT 전략 vs Claude 전략" 중 고르는 구조. TETH가 작업마다 모델을 고르는 오케스트레이터라면 이 컬럼은 존재 자체가 모순. 같은 페이지 아래 섹션이 "한 모델에 맡기지 않습니다"라고 말해 자기모순.
- "워뇨띠 학습형 #15367" 류 이름: 무엇을 하는 전략인지 설명 불가.

### P0-3. AI 판단형과 규칙형이 한 화면에서 뒤섞인다
- 터미널 Agent 패널의 판단 카드는 전부 "RSI 44 이하 반등"이라는 고정 규칙 대기 로그인데, 카드 제목은 "TETH 에이전트 · 시장 분석"이고 "▶ 사용자 프롬프트 / ▶ 생각의 사슬 / ▶ 거래 결정" 접기가 붙어 있다. 규칙형 봇에 LLM 사고 극장을 씌운 형태(=파인스크립트 래퍼처럼 보이는 이유).
- "판단마다 이유가 남아요" 섹션(인트로)도 "낙폭 조건 충족 → 반등 신호 대기" 규칙 서사. AI가 시장 맥락(뉴스, 온체인, 포지션, 리스크)을 보고 판단하는 nof1형 루프가 제품 어디에도 없다.
- 결과: 제품 정체성 메모리(3모드: 스크립트형 / AI 판단형 / AI 트레이더 팔로우)와 화면이 불일치.

### P0-4. AI 트레이딩 3상태(게스트/로그인/활성)가 같은 페이지다
- 게스트 #/trade와 로그인+전략0 #/trade가 픽셀 단위로 동일(tfintro). 가입한 사용자에게도 "시작하기 / 영원히 무료, 신용카드 필요 없음"을 다시 보여준다. 로그인 후 "이제 뭘 할 수 있지?"에 대한 답이 없다.
- 전략 1개가 생기는 순간 랜딩이 통째로 터미널로 바뀐다(중간 상태 없음). 처음 보는 사용자 전략 1개 옆에 데모 전략 6개(BTC 돌파 추종 +30.9% 등)가 "내 전략"처럼 섞여 있어 "이게 내 돈인가"가 불명확.

### P0-5. 활성화(연동/결제) 흐름이 4개 문으로 쪼개져 서로 다른 말을 한다
- 퍼널 connect: "TETH 파트너 거래소로 시작 ₩0 (추천, 약 2분, 연 최대 ₩5,000,000 절약)" vs "기존 거래소 연결 ₩599,000/월". → 기존 거래소를 쓰면 월 60만원이라는 뜻으로 읽힌다(실제 과금 모델: UID 연동 + 거래량 상쇄, 카드 대안). 금액 앵커가 틀렸고 협박처럼 읽힌다.
- PLAN: "무료로 UID 연동하기 (Fast API) / 구독으로 업그레이드", 상세 4행 "파트너 거래 활성: 체결 1회 시 30일 무제한 / 고급 응답 비용: PRO 심층 분석 사용량 기반". → 내부 회계 용어.
- 지원 거래소: "이용 시 영원히 TETH 이용료 ₩0" + "계정 개설 ↗"(외부 이탈) + App Store 평점.
- QA 토글: "거래소 연결 (Binance)"가 UID 연동과 별개 불리언.
- 결론: 사용자는 UID 연동 / Fast API / API 키 / 파트너 시작 / 기존 계정 연결 / 간편 연결 / 계정 개설 7개 이름 중 무엇이 무엇인지 알 수 없다. 과금 판정(UID)과 실행 권한(API)이 다른 개념이라는 사실이 어디에도 설명되지 않는다.

### P0-6. 전략 따라하기가 "백테스트 갤러리 + 거래소 카피 UI 이식"의 혼종이다
- 히어로 "검증되면, 복제됩니다" + 7자리 카운터 "모의 검증으로 계산된 거래" → 의미 없는 가짜 숫자, 첫 3초를 낭비.
- 카드 제목 = 닉네임(월급두배, 세븐틴층, 바닥만줍는사람). 전략이 무엇을 하는지 0 정보. 부제 "검증 완료 전략, 거래 비용 0.2% 반영 백테스트" → 시스템 설명.
- 카드 지표: TETH 점수 92점 / MDD / 승률 / 팔로워 / "검증 수익 +23.9% 누적 백테스트 성과" → 전부 3년 백테스트. 라이브 성과, 운용 기간, 팔로워 수익이 없다. 비교 불가.
- "카피하기"(cp 플로우: 트레이더 프로필 → 407일차, -2.72%, 승률 0%, 카피어 4/500) vs "복제하기"(인트로: 파라미터 복사) vs "따라하기"(상세). 같은 카드에서 다른 세계로 간다. 카피 프로필의 수치(-2.72%, 승률 0%)와 카드의 수치(+14.7%, 승률 62%)가 같은 사람인데 다르다.
- 카피 설정: 카피 금액 입력 하나에 "스팟 잔고 1,000 USDT, 충전은 스팟 계좌에서 카피 계좌로" → 거래소 백엔드 개념 노출. 손실 한도 없음.

### P0-7. 지원 거래소 = 브로커 디렉터리
- 21개 카드(Binance 1순위, 업비트·한투·로빈후드·IBKR·슈왑·피델리티… "준비 중"), App Store 평점, 리뷰 수, 가짜 리뷰 8건, 수수료 표, 회사 연혁. 사용자 질문 "TETH를 어디서 돌릴 수 있나"에 답하지 않고 "어느 브로커가 좋은가"에 답한다. Bitget-first 사업 방향과 정면 충돌(Bitget이 4순위).
- 카드 1차 CTA "계정 개설 ↗"가 외부 이탈. TETH 연결은 상세로 한 번 더 들어가야 나온다.
- 설정 메뉴 안에 숨어 있어 활성화 경로에서 만나지 못한다.

### P0-8. 11개 상업 상태가 상태 모델에 없다
- 현재 변수: login, uidLinked, payDone/plan, api, freeUsed, creditBal, bc.mode(active/grace/watch), cardOn. "거래량 高低"와 "AI 사용량 高低"가 축으로 존재하지 않는다(tradeActiveUntil = 체결 1회 시 30일 무제한이라는 다른 정책). 결과: 케이스 ⑤/⑧/⑩(거래 혜택으로 상쇄)의 보상 순간, 케이스 ⑨/⑪(차액 청구)의 청구서가 표현 불가.
- 화면은 케이스가 아니라 토글 조합에 따라 배너·시트가 산발적으로 뜬다(bwarn 시트, watch 고지).

### P0-9. 인증 게이트가 가치 체험 앞에 있다
- 게스트 홈 컴포저 전송 즉시 로그인 모달. 게스트가 AI 대화·전략 생성·백테스트를 1초도 못 본다. 인트로의 "터미널 미리 둘러보기"만 유일한 체험. 서비스 플로우 확정안(게이트=백테스팅 진입 시)과도 다르다(현행은 대화 시작 시).

## P1 — 위계·사용성

- P1-1. 홈이 챗봇 템플릿 그리드(종목 50개 타일)라 제품 첫인상이 "종목 검색 챗봇". 사이드바 1급 "새 전략"이 곧 홈.
- P1-2. 인트로 히어로가 화면의 100%를 3D 타일 이미지로 채워 첫 스크롤에 제품 증거 0(리더보드는 2번째 화면).
- P1-3. 터미널 우측 패널 첫 줄 "지금 관망 중이에요. 진입 기준(RSI 44 이하 반등)에 닿으면 검토를 시작해요"는 좋으나, 그 아래가 곧바로 반복 카드(3봉 연속 관망 / 시장 분석 / 6봉 연속 관망 …) + "이전 판단 더 보기 (1260)". 상태 요약 블록(무엇을 보고 있나, 포지션, 다음 체크, 마지막 확인 N초 전)이 없다.
- P1-4. 터미널 상단 컨텍스트 바에 P&L·운용금·리스크 없음(전략 레일 카드에만). 하단 탭 "현재 전략/전체 전략" 스코프 토글이 오른쪽 끝에 숨음.
- P1-5. 터미널에서 24/7 고객지원 FAB를 통째로 숨김(bk3 p1 지시). 연결·결제 순간에 도움 어포던스가 없다.
- P1-6. 퍼널 connect 스텝퍼(실행 방법 → 거래소 연결 → 연결 확인 → 시작)가 활성화 결정을 "실행 직전"에만 배치. 로그인 상태에서 미리 준비할 길이 PLAN 페이지(설정 메뉴 안)뿐.
- P1-7. PLAN 페이지 제목 "PLAN 및 크레딧 / AI 수준, 수수료 적립, 알림 수신을 관리해요" → 회계 화면. 사용자 질문(지금 무료인가, 왜, 얼마 내나, 어떻게 줄이나)에 답하는 구조가 아님.
- P1-8. 전략 상세(share/s)의 12개 섹션(수익 곡선, 낙폭, 지표 6, 캘린더, 보유 분포, 연도별, 체결 표)은 백테스트 리포트이지 "따라갈지 결정"하는 페이지가 아니다. "무엇을 하는 전략인가 / 지금 뭘 하고 있나 / 누가 만들었나"가 없다.
- P1-9. 상단 우측 내비(TETH 정보 / 앱 다운로드 / 로그인 / 무료로 시작)가 로그인 후에도 마케팅 링크를 유지(로그인 화면 스샷에서 확인 필요).
- P1-10. QA 패널이 9개 원자 토글: 시나리오를 만들려면 토글 4~5개를 순서대로 눌러야 하고 조합의 의미가 없다. 진척 확인 기능 없음.
- P1-11. 인사이트는 완성도 높으나 제품 흐름과 연결점이 없다(설정 메뉴 안, 홈·터미널에서 참조 없음).
- P1-12. 홈 타일 "AI가 대신 거래"와 "지표 생성 후, 거래"에 붙은 배지 "강력"은 의미 없는 장식.

## P2 — 폴리시

- P2-1. 인트로 "한 모델에 맡기지 않습니다" 궤도 섹션: 로고 5개가 도는 장식. 벤더 로고를 제품 정체성으로 쓰는 문제(P0-2)의 시각 버전.
- P2-2. 전략 따라하기 히어로 대형 세리프 + 블루 글로우 배경이 AI 트레이딩 인트로와 다른 브랜드처럼 보임.
- P2-3. 거래소 카드 로고 타일이 화면의 절반. 정보 밀도 낮음.
- P2-4. 검증 화면 "본 데모는 검증 흐름을 시뮬레이션합니다" 류 데모 고지가 UI 곳곳(터미널 "실행, 체결, 손익은 체험 모드 시뮬레이션이에요", 상세 "시뮬레이션 데이터 기준")에 반복.
- P2-5. 카피 프로필 "카피하는 사람 4 / 500", "트레이더 총자산 110,153 USDT" 등 Bitget 필드 그대로.
