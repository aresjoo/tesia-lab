# 이용 현황 화면 긴급 3자 판정 (짧게, 20분 내)

대표(발주자)가 배포된 이용 현황 화면(1.png)을 보고 두 가지를 지적했다. 2.png는 대표가 확정한 11개 상업 상태 표다.
1. "무료 체험 10회 남았어요" 같은 횟수 숫자가 왜 노출되나. 표에는 "최소 무료 크레딧 제공, 소진되면 게이트"만 있다(수치 비노출 원칙이 원래 있었음).
2. "정산 탭도 빼야 하는 것 아니냐. 사용자가 우리(TETH)에게 얼마나 많이 가져다 바치는지 모르게 해야 한다." 즉 거래 커미션 적립 내역·적립률·상쇄 금액처럼 TETH가 사용자 거래에서 얼마를 얻는지 역산할 수 있는 정보는 감춰야 한다.

제약: 목업, 컴플라이언스 관점 배제. 과금 공식(월 청구 = max(0, 플랜료 + 초과 종량 - 커미션 크레딧 - 무료 크레딧))은 내부 정본이지만 화면에 그대로 보일 필요는 없다. 사용자가 답을 얻어야 하는 질문은 5개뿐: 쓸 수 있나 / 지금 무료인가 / 왜 / 내면 얼마 / 어떻게 줄이나.

## Claude(제품 책임자) 초안 입장
- 횟수·퍼센트·상쇄 금액 전부 비노출. 상태 문장 + "이번 달 청구 ₩N"(청구액만) + 줄이는 방법 1줄.
- 정산 탭 삭제(적립 내역·적립률·누적 적립 전부). 적립 알림도 삭제.
- 상쇄 프로그레스 바 삭제. 상쇄는 정성 문장으로만("거래 혜택으로 일부/전액 상쇄됐어요").
- 미활성 뷰의 "무료 체험 N회" 바도 삭제하고 "연결이나 결제 없이 만들고 검증할 수 있어요" 한 줄로.
- 게이트 시점 문구: "무료 체험을 다 썼어요" (숫자 없음).

## 당신의 임무
아래 4개 질문에 각각 3~6줄로 답하라. 근거 없는 동의 금지, 반대하면 대안을.
Q1. 청구액 ₩N만 보여주면 사용자가 "왜 이 금액인가"를 납득하는가? 납득시키면서도 커미션 규모를 역산 못 하게 하는 최소 표시는 무엇인가(예: 청구액 + "플랜 ₩49,000에서 거래 혜택만큼 줄었어요" 같은 방향 표현).
Q2. 무료 체험 잔량을 숫자 없이 어떻게 전달할 것인가(게이트 도달 전 경고 필요한가, 필요하면 어떤 형태).
Q3. 정산 탭을 삭제하면 "따라가기 창작자 보상(내 전략을 남이 따라가서 받는 보상)"은 어디에 두는가(그건 사용자가 받는 돈이라 숨길 이유가 없음).
Q4. 상태 11개 각각의 이용 현황 한 줄 문장을 숫자 없이 다시 써라(청구액 ₩N만 허용).
