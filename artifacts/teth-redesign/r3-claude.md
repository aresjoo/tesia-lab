## 구체 비판
| # | 등급 | 요소 → 문제 → 사용자 해석 → 제안 |
|---|---|---|
| 1 | P1 | 보는 종목 표의 "솔라나 +14% 약세" → 오른 종목이 약세 → 표가 틀렸다고 의심 → 상태 말을 "평균 아래"로 |
| 2 | P1 | 같은 표에서 1, 2위는 후보인데 5, 8위를 보유 → 왜 1위를 안 사는지 모름 → 판단이 임의로 보임 → 안내 문장에 "자리가 다 차 있고, 든 종목은 순위에서 많이 밀릴 때까지 유지해요" |
| 3 | P2 | 혼합 단계 3의 손익이 기울임꼴 → 마감 불량 → 기울임 제거 |
| 4 | P1 | 혼합 "지금" 패널에 AI 가 본 후보가 없음 → AI 역할이 "종목 고르기 도지코인" 한 단어 → AI 가 실제로 비교했는지 안 보임 → 단계 1 아래에 비교한 상위 3종목과 오름폭 |
| 5 | P2 | 조건 실행 상세 "하는 일" 상자 → 아래 절반이 빔 → 빈 면 → 상자 높이를 내용에 맞춤 |
| 6 | P2 | 최근 판단의 날짜가 "9월 24일 2번 연속" → 9월 24일과 그 전 재평가를 묶은 것인데 기간이 안 보임 → 언제부터인지 모름 → "9월 19일부터 2번" |
| 7 | P1 | 목록 카드 "지금" 줄이 조건 실행에서 "하락 대기"만 → 기준까지 얼마나 남았는지는 상세에만 → 카드끼리 구별이 약함 → Codex 제안대로 현재안과 숫자 포함안을 둘 다 렌더 |
| 8 | P2 | 상세 성과 구역 → 개요에서 차트가 여전히 큼(높이 300) → 판단 기록보다 넓은 면 → 개요 차트 높이 축소 |
