# ROUND 2 (Claude Code): 신뢰 라운드 독립 비평

대상: `r2-main*.png`, `r2-detail-*.png`, `r2-id-*.png`, `r2-glyphs-*.png`, `r2-cta-*.png`, `r2-ev1-detail.png`, `r2-ev4-detail.png`.

## 이번 라운드에 반영한 것
세 유형 공통 원장(조건 실행도 같은 계산기), 원장 방어, 사건에 수량과 비용, 상태 순위를 기준일 종가로, 혼합과 조건 실행의 상태를 마지막 평가 객체로, 캐시 키, 옛 정의 제거(정의 하나), 옛 이름 별칭, 이름 확정, 설명 교정(건널목, 동행, 환승, 작은 걸음, 물러섬, 두 문턱, 마침표), 배너 제목, 조건 대기의 실제 원인, KPI 묶음 간격, 미니 차트 선만, 상세 순서(지금, 하는 일, 움직이는 방식, 최근 판단, 성과), 조건 위치 표시, 누적 수익을 차트 아래로, 모바일 버튼, 따라가기 시트의 유형.

## 재대결 판정(내 의견)
| 축 | 판정 | 근거 |
|---|---|---|
| 식별 | B1 | `r2-glyphs-B1.png`: 세 줄이 점 묶음, 꺾인 선, 결합으로 갈려 유형 보조 PASS. 같은 유형 안에서도 점 모양(원, 사각, 마름모), 채운 개수, 골 깊이, 끝점 위치, 앞 세로선으로 갈린다. 약점: 조건 실행 2번과 6번, 8번이 28px 에서 비슷하다 |
| 버튼 | P3(둘 다 외곽선) | `r2-main-full.png` 의 흰 채움 20개는 카드마다 가장 밝은 면이라 수익률 대신 새 띠를 만든다 |
| 최근 판단 | 4건 | 1건이면 "기록이 있다"는 증거가 약하다. 정책(움직이는 방식)을 위로 올렸으므로 4건이 정책을 밀어내지 않는다 |

## 구체 비판
| # | 등급 | 요소 → 문제 → 사용자 해석 → 제안 |
|---|---|---|
| 1 | P1 | 카드 "지금 하락 대기"가 조건 실행 9장 중 7장 → 같은 말 반복 → 자산만 다른 같은 전략 → 기준까지의 위치를 붙임: "하락 대기, 밀린 정도 16 / 74" |
| 2 | P1 | "엔비디아 하락 대기" → 하락을 바라는 것처럼 읽힘 → 어색하고 불안 → "엔비디아가 밀리기를 기다림" |
| 3 | P1 | 상세 "지금 강한 종목: 도지코인 +16%, 이더리움 +10%, 솔라나 +14%" → 순서와 숫자가 안 맞음 → 계산이 틀렸다고 의심 → 순위 기준(흔들림 대비)을 행 이름에 밝히거나 표시 값을 순위 값으로 |
| 4 | P1 | 카드 흰 "자세히" → 위 재대결 | 
| 5 | P2 | 목록 판단 방식 설명 문장 → 선택기 오른쪽에 한 줄로 길게 → 1280 에서 줄바꿈 가능 → 확인 필요 |
| 6 | P1 | 상세 머리글 라임 "따라가기" 180px → 첫 화면에서 가장 밝은 면 → 판단을 읽기 전에 누르라는 신호 → 폭 140, 높이 44 유지. 라임은 상세의 이 버튼 하나에만 쓰므로 색은 유지 |
| 7 | P2 | 상세 "하는 일" 상자 → 지금 상자보다 짧아 아래가 빔 → 빈 면 → 상자 높이를 내용에 맞추고 위 정렬 |
| 8 | P1 | 30일 수익률 0.0%(갈림길), 미니 차트 평평한 빨간 선 → 0 인데 빨강 → 손실처럼 보임 → 기준선과 겹치면 중립색 |
| 9 | P2 | 카드 거래소 표시 → 버튼 오른쪽 끝, 로고 색(노랑, 하늘)이 카드에서 유일한 채도 높은 색 → 시선 분산 → 로고를 단색 처리하거나 크기 12px |
| 10 | P1 | 낙폭 -38.2%, -32.8%, -28.3% → 가상자산 단일 종목 전략의 실제 위험 → 정직하지만 "시작 이후 최대" 임을 모르면 과장되게 읽힘 → 상세 성과에서 낙폭이 난 기간을 밝힘(기존 mddStartI, mddEndI 사용) |
