## 후보 판정
| 비교 | 승자 | 근거(스크린샷) |
|---|---|---|
| 이름 | C(고유 이름) 조건부 | A 는 제목이 아래 설명과 같은 말을 되풀이한다("강한 코인 셋 고르기" 아래 "강한 셋을 나눠 듭니다"). 8장이 전부 "~기", "~반등"으로 끝나 목록이 설명서처럼 읽힌다. B 는 "TETH" 가 8번 반복되고 "NDX", "ETH" 같은 부호가 섞여 내부 상품 코드처럼 보인다. C 는 짧아서 제목과 설명의 역할이 갈린다. 단 "거름", "돌림", "분업"은 뜻이 다르게 읽히거나 약하다 |
| 식별 | B1(도식) | A 는 28px 단색 얼굴이 뭉개지고 여전히 사람이다. B2 는 고리 8개가 서로 비슷하고 아무 뜻도 전하지 않는다. B1 은 점 묶음(탐색), 꺾인 선(조건), 둘의 결합(혼합)으로 유형이 한눈에 갈린다 |
| 버튼 | 미정, 제3안 필요 | P0 는 라임 20개가 화면을 지배. P1 과 P2 는 흰 채움 20개가 새로운 띠를 만든다. 둘 다 외곽선으로 두고 굵기나 밝기로만 주종을 나누는 안을 추가로 렌더해야 한다 |
