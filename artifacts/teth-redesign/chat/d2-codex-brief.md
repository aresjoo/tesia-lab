## 1부: 독립 비평 (UI 기준)
1. 파운더 지시 충족: 성과 그래프 아래에 채팅으로 보이나. 모델명 대신 전략 이름으로 말하나. 말마다 200~300자인가(20종 전수). 말투가 1인칭 해요체로 일정한가. 지금 상태, 하는 일, 움직이는 방식이 들어 있나.
2. 글의 사실 검수: 20종 중 직접 탐색 2, 조건 실행 2, 혼합 2 를 골라 말 8개씩의 숫자(날짜, 가격, 퍼센트, 종목, 일수)를 엔진 기록과 대조. 틀린 문장, 어색한 조사, 뜻이 흐린 문장을 전부 적는다.
3. 시각 검수: 위계, 정렬(아바타와 이름 줄, 말풍선 왼쪽 선), 여백, 줄 길이, 색, 접힘 상태의 잘림, 버튼 크기, 1440 과 390. 요소 → 문제 → 사용자가 하는 해석 → 제안.
4. 동작: 펼쳐 읽기와 접기, 더 보기, 전체 기록 이동, 키보드 순서와 포커스, 탭을 오갔다 돌아왔을 때, 다른 전략으로 이동했을 때.
5. 회귀: 성과 그래프의 마우스 올림과 기간 전환, 다른 네 탭, 목록 카드, 따라가기 시트.
6. **P0, P1, P2 개수를 명시. 0 이면 0 이라고 쓴다.** P0 는 주요 흐름 차단, P1 은 파운더 지시 미충족이나 사실과 다른 글이나 초보가 잘못 이해하게 만드는 것, P2 는 다듬기.
