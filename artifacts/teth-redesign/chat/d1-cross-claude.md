# 전략 대화 디자인: 교차 검증과 합친 안 (Claude Code)

Claude 1차안은 `a1-*.png`, Codex 목업은 `b1-codex-*.png`, 합친 안은 `m1-*.png`.

## Codex 안 판정
| Codex 제안 | 판정 | 근거와 반영 |
|---|---|---|
| 태그는 중립색 테두리, 지금만 강조 | ACCEPT | 내 1차안은 팔았어요를 결과에 따라 초록과 빨강으로 칠했다. 행동과 성과를 한 색에 섞은 것. 태그는 중립으로, 지금만 밝은 테두리 |
| 지금 태그를 라임으로 | REJECT | 라임은 따라가기 버튼 색. 같은 화면 위쪽에 큰 라임 버튼이 있다. 흰색 테두리로 |
| 본문의 부호 붙은 퍼센트만 초록, 빨강 | ACCEPT | 긴 글에서 숫자를 찾기 쉽다. 부호 없는 기준값(0.5%, 12%)은 칠하지 않는다 |
| 지금 말의 첫 문장을 따로 한 줄로 | ACCEPT | 16px, 아래 여백 4px |
| 말풍선 전체 누르기 대신 펼쳐 읽기 버튼 | ACCEPT | 내 1차안은 말풍선 전체가 버튼이라 글을 긁어 복사할 수 없었다. 버튼 높이 36px, 390 에서 44px |
| 처음에 3개 | ACCEPT | 내 1차안은 4개. 지금 말이 길어 3개가 한 화면에 맞는다 |
| 묶인 판단은 날짜 범위와 횟수 문장 | ACCEPT | "9월 19일 ~ 9월 24일", 말풍선 아래 "같은 판단을 2번 이어서 했어요" |
| 390 에서 날짜를 이름 아래 줄로 | ACCEPT | 이름이 잘리지 않는다 |
| 본문 15px, 줄 간격 1.8 | ACCEPT | |
| 아바타로 사람 얼굴 프로필(t01 등) | REJECT | 카드 개편에서 사람 얼굴을 빼고 설정에서 그린 도식으로 바꿨다. 목록 카드와 상세 머리글이 도식이므로 같은 전략이 같은 표식으로 말해야 한다. 다만 파운더의 "프로필 이미지 우리꺼"가 무엇을 가리키는지는 확정이 아니다. 도식으로 구현하고 파운더에게 묻는다 |
| 이전 대화 더 보기를 라임 채움 버튼으로 | REJECT | 같은 이유. 외곽선 버튼 |
| 전체 제목 "전략의 대화", 판단 방식 바로가기 | REJECT | 제품의 상세는 전략 하나만 보여 준다. 세 전략을 한 화면에 넣은 목업의 구조일 뿐. 제목은 "이름의 말", 오른쪽에 전체 기록 |
| 전체 기록은 같은 자리에서 펼침 | MODIFY | 더 보기 버튼이 같은 일을 한다. 전체 기록은 활동 탭으로 이동 |

## 합친 안
| 요소 | 값 |
|---|---|
| 아바타 | 전략 도식 36px(390 에서 28px), 이름 줄 왼쪽 |
| 이름 줄 | 이름 14px 600, 태그 11.5px 테두리, 날짜 12px 오른쪽 끝 |
| 말풍선 | #131517, 선 .10, 모서리 3 15 15 15, 최대 폭 792px |
| 본문 | 15px, 줄 간격 1.8, #cfd2d6. 첫 문장 600 #f7f8f9 |
| 접기 | 지금은 펼침. 나머지는 3줄, 펼쳐 읽기 버튼 |
| 개수 | 처음 3개, "이전 말 5개 더 보기" |

## 스스로 본 약점
- 말을 여러 개 펼치면 같은 규칙 문장이 되풀이된다.
- 세 판단 방식의 차이는 도식과 글에만 있다.
- 날짜에 연도가 없다. 소개 말(예: 11월 29일)이 최근 판단 아래에 오면 앞뒤가 헷갈릴 수 있다.
