# 전략이 보내는 대화

## 방향
- 성과 그래프 다음에 전략의 목소리가 이어진다. 하나의 수신 대화열로 왼쪽 정렬한다.
- 첫 문장을 읽으면 한 일을 알고, 본문을 펴면 근거와 다음 행동을 읽을 수 있다.
- d1, r1, h1 순서다. 각 전략의 실제 글 8개를 원본 순서대로 넣었다.
- 원문의 문장, 공백, 수치, 말투는 고치지 않았다. 시각적 강조만 추가했다.

## 아바타
- 기존 프로필 SVG t01, t02, t03을 각 전략에 순서대로 사용했다.
- SVG를 data URI로 내장했다. 파일을 옮겨도 프로필이 사라지지 않는다.
- 같은 전략은 모든 발화에 같은 얼굴을 쓴다. 발신자 이름은 제작자가 아닌 전략 이름이다.
- PC는 36px, 모바일은 28px 원형이며 이름 줄 왼쪽에 붙인다.
- TETH 심벌이나 새 도식보다 기존 프로필이 전략 목록과의 연결을 만든다.

## 이름, 태그, 날짜
- 이름은 14px 600, #f2f3f5. 메시지마다 반복해 누가 말하는지 놓치지 않게 한다.
- 태그는 11px의 얇은 테두리다. 지금만 라임으로 표시하고 행동 태그는 모두 중립색이다.
- 매수 초록, 매도 빨강을 쓰지 않는다. 매도에도 수익이 있으므로 행동과 성과를 구분한다.
- 본문에 부호가 있는 퍼센트만 초록 #2ebd85, 빨강 #f0566a로 표시한다.
- 날짜는 12px #8b9098로 같은 줄 오른쪽에 둔다. 제공되지 않은 시간과 연도는 만들지 않는다.
- from이 있으면 날짜 범위를, cnt가 있으면 말풍선 아래에 같은 판단의 횟수를 표시한다.
- 날짜는 표시 문자열 그대로 쓴다. 연도가 없으므로 재정렬하지 않는다.

## 말풍선과 읽기
- 배경 #131517, 선 rgba(255,255,255,.10), 최신 글은 선의 불투명도 .14.
- 왼쪽 위 모서리만 3px, 나머지는 15px로 두어 수신 말풍선의 방향을 만든다.
- 전체 영역은 960px, 대화열은 최대 832px, 말풍선은 최대 784px다.
- 본문 15px, 줄 간격 1.85, 색 #cfd2d6. 첫 문장은 밝은 600 굵기다.
- 최신 글은 첫 문장을 별도 줄로 분리한다. 원문 텍스트를 바꾸지 않고 CSS로 처리한다.
- 첫 문장 판별은 마침표 뒤 공백을 기준으로 해 소수점 중간을 자르지 않는다.

## 접고 펴기
- 기본은 전략마다 3개: 지금 1개 전문, 이전 판단 2개 각 3줄 미리보기.
- 이전 글은 펼쳐 읽기 버튼으로 전문을 열고 접기로 되돌린다. 여러 글을 동시에 열 수 있다.
- nof1 참조의 펼치기 발상을 취하되, 말풍선 전체 클릭 대신 명시적인 버튼을 쓴다.
- 버튼 높이는 44px이며 aria-expanded, aria-controls와 키보드 포커스를 제공한다.
- CSS로 접힌 본문은 보조기술에는 전문이 제공된다. 정보 자체를 읽지 못하게 숨기지 않는다.
- 전체 기록 8은 같은 섹션에 나머지 5개를 펼친다. 최근 대화만 3으로 되돌릴 수 있다.
- 하단 이전 대화 5개 더 보기는 같은 동작 후 첫 추가 글로 스크롤하고 포커스를 옮긴다.
- 전체 기록을 열어도 이전 글은 각 3줄로 유지한다. 개별 펼침 상태도 보존한다.

## 섹션과 세 판단 방식
- 전체 제목은 전략의 대화, 전략별 제목은 실제 전략 이름이다.
- 판단 방식은 제목 위 작은 회색 글자다. 상단 바로가기로 세 전략 사이를 이동한다.
- 직접 탐색은 비교와 보유, 조건 실행은 조건과 거래, 혼합은 고르기와 매매가 글로 드러난다.
- 방식별 말풍선 색이나 공급사 로고를 만들지 않는다. 같은 제품의 발화 문법을 유지한다.
- 차이는 이름, 얼굴, 판단 방식, 실제 행동 태그가 담당한다.

## 390px
- 좌우 여백 16px. 28px 얼굴과 9px 간격을 제외한 말풍선 폭은 321px다.
- 이름과 태그를 첫 줄에, 날짜를 다음 줄에 둔다. 날짜 범위가 이름을 밀어내지 않는다.
- 본문은 15px와 줄 간격 1.8을 유지하고 안쪽 여백은 15px로 줄인다.
- 그래프는 모바일에서도 320px 높이를 유지한다. 별도 가로 스크롤이나 고정 패널은 없다.

## 피한 표현과 범위
- AI 모델명, 공급사, 토큰 수, 사고 과정 원문을 연상시키는 제목을 추가하지 않았다.
- 입력 중 점이나 상대 시각을 넣지 않았다. 원문 속 지금과 내일은 그대로 유지했다.
- 원문에 있는 AI라는 역할 설명은 유지했다. 추가 운영 라벨과 면책 문구는 넣지 않았다.
- 한국어 독립 HTML 하나이며 폰트, 이미지, 데이터, 스크립트의 외부 요청이 없다.
- 변경 대상은 codex-mock.html과 이 문서뿐이다.
- 참조 [nof1 Alpha Arena](https://nof1.ai/)는 직접 조회가 403으로 차단되어 요청에 적힌 UI 요소를 기준으로 삼았다.

## 스스로 본 약점 세 가지
1. 최신 글 전문은 모바일에서 세로 공간을 많이 쓴다. 상태를 감추지 않는 선택이지만 지난 판단까지 스크롤이 길다.
2. 이전 글마다 규칙 설명이 반복된다. 3줄 미리보기로 완화했지만 여러 글을 펼치면 비슷한 문장이 계속 나온다.
3. 연도 없는 날짜는 h1의 11월 소개와 9월 판단의 선후를 설명하지 못한다. 원본 순서를 유지했으며 데이터에 연도가 필요하다.

## 검증
- Chrome CDP로 로컬 파일을 직접 열었다. 1440px와 390px의 세 전략 모두 가로 넘침 0px.
- 320px 그래프, 이미지 로드, 기본 3개씩 표시, 총 24개 포함을 확인했다.
- JSON 원문과 실제 본문 textContent가 모두 일치한다. 길이는 205~260자다.
- 두 폭에서 세 전략의 펼침, 접힘, 이전 5개 표시, 전체 기록, Enter 접기와 포커스 이동을 확인했다.
- JavaScript 예외 0건, 외부 HTTP 요청 0건. PC와 모바일 캡처를 직접 확인했다.
- 지정한 두 파일에 금지 문장부호와 줄 끝 공백이 없다. 별도 캡처 파일은 만들지 않았다.
- 저장소 전체 diff 검사에는 동시 작업의 index.html 줄 끝 공백이 잡혔다. 해당 파일은 수정하지 않았다.
- agy 스킬의 네 관점 검토는 각각 한 번 재시도했으나 인증 부재, 파일 접근 거부, 네트워크 차단으로 미완료다.
- 외부 검토의 지적이나 리팩터링 제안은 수신하지 못했다. 독립 파일 범위에서 공통 렌더 함수와 상태 처리를 유지했다.
