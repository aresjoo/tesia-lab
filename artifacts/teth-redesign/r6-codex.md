## 3부. 남은 수정

1. **P1 N1:** gen 없는 저장의 이전 기준일과 길이를 복원하는 이행 경로를 정한다. 구저장 1304의 8월 29일이 새 세대 최초 로드 뒤에도 같아야 한다. 신규, 구형, 같은 길이, 한 봉 추가, flatI, 반복 이행과 새로고침을 함께 회귀 확인한다.
2. **P2 R2:** 기존 완료 토스트를 저장한 existing 값에 맞춘다. skip과 copy를 선택해 시트 요약, 저장값과 완료 문장이 일치하는지 확인한다.
3. **P2 Q1:** 시트 안에서 Tab과 Shift+Tab이 순환하게 하고 열린 동안 배경 포커스를 막는다. Escape와 호출 버튼 복귀는 보존한다.
4. **P2 Q2:** 390에서 유형 묶음과 정렬, 시장, 검색 조작이 서로 밀어내지 않도록 기존 행의 배치만 조정한다. 검색을 찾으려 전체 조작부를 270px 옮겨야 하는 상태를 줄인다.
5. **P2 R3, R4:** 위 기능 문제 이후 이름과 기존 표식의 구별력만 다듬는다. 전체 이름 체계, KPI, 버튼, 페이지 구조와 리그를 다시 설계하지 않는다.
