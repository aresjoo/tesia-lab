# 반영 여부 검증 (Codex, Astra): 클라우드 세션이 말한 것이 실제로 제품에 들어갔는가

## 배경
다른 세션(클라우드)이 작업하다 멈췄다. 그 세션이 파운더에게 보고한 항목이 실제로 `main`(지금 작업 폴더의 `index.html`, 커밋 5a0114c)에 들어갔는지 파운더가 확인을 요청했다. Claude 도 따로 검증한다. 서로의 결과를 나중에 대조하므로 Claude 의 결과 파일은 읽지 말 것.

## 할 일
1. 항목마다 **반영됨 / 일부 / 안 됨**을 판정한다. 근거는 파일:줄과 실제 화면. 정적 서버는 `http://127.0.0.1:8765/index.html` 에 떠 있다(없으면 직접 띄운다). 헤드리스 Chrome 으로 `tfShareHub('find')`, `tfSS3Go('<id>','all','ov')` 를 열어 확인. 저장 상태를 지우고 시작.
2. **3번은 숫자로 검증한다.** 1,000 USDT 로 따라가기를 시작하고 나중에 3,000 을 추가한 계좌를 실제 함수(`cpStart`, `cpTopup`, `cpCalc`)로 만들어, 판단 방식 셋(d1 AI 판단, r1 차트 규칙, h1 혼합 전략)에서 잔고, 내 수익률, 전략 수익률, 실현과 미실현, 대기 금액을 출력하고 손으로 계산한 값과 대조한다. 회수, 멈춤, 끝내기(`cpClose`) 뒤에도 돈이 생기거나 사라지지 않는지 본다(입금 합 = 회수 합 + 잔고 - 순손익).
3. 새 코드에서 찾은 결함을 P0, P1, P2 로. 옛 저장 데이터(봉 번호 없는 기록)를 가진 사용자의 화면도 본다.
4. 화면 문구에 "데모", "시뮬레이션", "예시" 같은 낱말이 새로 들어갔는지 본다.
