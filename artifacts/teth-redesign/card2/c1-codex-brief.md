# 카드 개선 1라운드 (Codex, Astra): 독립 제안

대상은 전략 따라하기 목록의 카드다. 현재 화면은 `artifacts/teth-redesign/card2/c0-main-1440.png`, `c0-main-390.png`. 직접 렌더해도 된다(서버 8843, Chrome 9333). 카드 코드는 `index.html` 의 `mkCard`, 이름과 한 줄 설명은 `artifacts/teth-redesign/tools/copy.json`, 행동 값은 `artifacts/teth-redesign/tools/cat-data.json`.

## 사용자(파운더)의 피드백 여섯 항목. 대상 고객은 투자 초보다
1. 최대 낙폭을 카드에서 뺀다. 초보 화면에서 빼기로 한 정보이고, 수익률(+9.8%)보다 숫자(-17.9%)가 커서 "버는 것보다 잃는 게 더 크네"로 읽힌다.
2. 설명 문장이 트레이더 말투다. "눌렸다 반등", "규칙이 삽니다"는 초보가 멈칫한다. 예: "AI가 미국 기술주 중 하나를 골라, 떨어졌다가 다시 오를 때 삽니다".
3. "맞물림" 같은 이름은 뭘 하는지 떠오르지 않는다. 그리고 전략은 TETH 가 아니라 유저가 등록한 것이다. 같은 이름의 전략이 둘 이상이면 구분하기 어렵다.
4. 승률 59%는 "10번 중 6번 수익"이 더 직관적이다. 거래 수 34회는 초보에게 의미가 약해 빼도 된다.
5. FOMO 장치가 없다. 예: "1,284명이 따라가는 중".
6. Bitget 로고가 버튼 줄에 붙어 세 번째 버튼처럼 보인다. 상단 태그 옆으로 옮기거나 "Bitget에서 실행" 같은 작은 텍스트로.

## 할 일
1. 여섯 항목 각각에 ACCEPT / MODIFY / REJECT 와 근거. 파운더의 결정(1, 4 의 삭제)은 뒤집지 말고, 그 결정이 만드는 빈자리와 부작용을 어떻게 메울지 제안한다.
2. 새 카드의 정보 구조를 제안한다. 1280 이상은 2열 가로형(왼쪽: 무엇을 하는가, 오른쪽: 성과와 버튼), 그 아래는 세로형이다. 줄 단위로 무엇이 어디에 놓이는지 쓴다. 오른쪽 칸에서 최대 낙폭과 거래 수가 빠지면 무엇으로 균형을 잡는지 포함.
3. 20종 전부의 새 이름과 새 한 줄 설명을 표로 제안한다(id, 이름, 설명). 조건:
   - 이름만 보고 무엇을 하는지 떠올라야 한다. 기능 조건식(RSI 26 같은)은 금지. 12자 이내.
   - 설명은 초보 말투, 한 문장, 40자 안팎. 트레이더 용어(눌림, 반등 진입, 익절, 손절, 추세, 평균선, 변동성) 금지. 엔진이 실제로 하는 일과 어긋나면 안 된다(`cat-data.json` 의 값 기준).
   - 전략끼리 이름이 겹치거나 비슷하게 읽히면 안 된다.
4. 유저가 등록한 전략이라는 점을 카드에서 어떻게 보일지(등록자 표시의 형태, 같은 이름 충돌 시 구분 방법). 사람 얼굴 아바타와 가짜 트레이더 프로필 느낌은 피한다.
5. FOMO 장치의 형태와 한도. 어떤 문구와 숫자를 쓰고 어디에 두는지. 과하면 코인 카지노처럼 보인다.
6. 구현 위험과 검수 기준(잘림, 줄 수, 390 폭).
