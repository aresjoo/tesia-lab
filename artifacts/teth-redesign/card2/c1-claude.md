# 카드 개선 1라운드 (Claude Code): 독립 제안

Codex 의 `c1-codex.md` 를 보기 전에 썼다.

## 여섯 항목 판정
| # | 판정 | 근거와 처리 |
|---|---|---|
| 1 최대 낙폭 삭제 | ACCEPT | 카드에서 뺀다. 상세의 성과 영역에는 남긴다. 오른쪽 칸의 빈자리는 4, 5 의 두 문장으로 채운다 |
| 2 설명 말투 | ACCEPT | 20종 모두 다시 쓴다. "누가(AI 또는 조건) 무엇을 언제 산다" 한 문장. 금지어: 눌림, 반등 진입, 익절, 손절, 추세, 평균선 |
| 3 이름과 등록자 | MODIFY | 이름은 "대상 + 하는 일"로 바꾼다. 다만 앞선 지시(기능명이 아니라 상품명)와 부딪히므로 조건식은 넣지 않는다. 등록자는 얼굴 없이 글자 핸들만(@이름). 같은 이름이 둘이어도 핸들로 갈린다 |
| 4 승률과 거래 수 | ACCEPT | "10번 중 6번 수익". 5회 미만은 "아직 거래가 적어요". 거래 수는 카드에서 뺀다 |
| 5 FOMO | MODIFY | "1,284명이 따라가는 중" 한 줄만. 카운트다운, 마감 임박, 실시간 깜빡임은 넣지 않는다. 숫자는 카탈로그의 고정 값 |
| 6 거래소 | ACCEPT | 버튼 줄에서 빼고 판단 방식 줄 오른쪽 끝에 "Bitget에서 실행" 작은 글자. 로고는 14px 로 글자 앞에만 |

## 카드 구조 (1280 이상, 가로형)
| 위치 | 줄 | 내용 |
|---|---|---|
| 왼쪽 1 | 도식 + 이름 | 20px |
| 왼쪽 2 | 판단 방식, 범위 | "혼합 미국 기술주 8종" |
| 왼쪽 3 | 설명 | 두 줄까지 |
| 왼쪽 4 | 지금 | 구분선 아래 |
| 오른쪽 1 | 30일 수익률 + 차트 | 그대로 |
| 오른쪽 2 | 두 문장 | "10번 중 6번 수익", "1,284명이 따라가는 중" |
| 오른쪽 3 | 버튼 | 따라가기, 자세히 |
| 왼쪽 2 또는 오른쪽 3 끝 | 등록자와 거래소 | "@핸들", "Bitget에서 실행" |

## 스스로 본 약점
- "다시 오를 때" 가 이름에 세 번, "챙기기" 가 세 번 나와 서로 비슷하게 읽힌다.
- 등록자 핸들을 넣으면 개편 기준 A(가짜 트레이더 프로필처럼 보이지 않음)와 긴장이 생긴다.
- 최대 낙폭을 빼면 음수 수익률 전략(동행 -1.2%)만 위험이 드러난다.
