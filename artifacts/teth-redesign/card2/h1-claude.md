# 판단 방식 안내 문장: 뺄지, 툴팁으로 둘지 (Claude Code 독립 의견)

Codex 의 `h1-codex.md` 를 보기 전에 썼다.

## 현재
목록 조작 줄의 판단 방식 선택(전체, 직접 탐색, 조건 실행, 혼합) 오른쪽에 한 문장. 고른 방식에 따라 바뀐다.
- 전체: 직접 탐색은 AI가 종목을 고르고, 조건 실행은 정해 둔 조건만 따르고, 혼합은 둘이 나눠 맡아요.
- 직접 탐색: 여러 종목을 비교해 무엇을 얼마나 들지 AI가 정해요. 시장이 약하면 새로 사지 않아요.
- 조건 실행: 정해 둔 자산에서 정해 둔 조건이 맞을 때만 사고팔아요.
- 혼합: 거래할 종목은 AI가 고르고, 사고파는 시점은 규칙이 정해요.
390 폭에서는 선택 줄 아래 두 줄을 차지한다.

## 의견: 전체 상태의 문장은 빼고, 설명은 ⓘ 하나로 옮긴다
- 카드마다 설명 문장이 "AI가 ..." 또는 "비트코인이 ..." 로 시작해 판단 주체를 이미 말한다. 목록 위 문장은 같은 내용을 한 번 더 말한다.
- 이 문장은 매번 보이지만 필요한 사람은 처음 한두 번뿐이다. 390 폭에서 첫 카드를 두 줄 밀어낸다.
- 툴팁을 선택 버튼 자체에 붙이는 것은 반대. 버튼을 누르면 필터가 바뀌므로 터치 화면에서는 툴팁을 볼 방법이 없다.
- 대신 선택 줄 끝에 작은 ⓘ 버튼 하나. 누르면 세 방식의 한 줄 정의가 담긴 작은 창. 마우스를 올려도, 눌러도, 키보드로도 열린다.
- 방식 하나를 고른 상태의 문장도 뺀다. 고르면 카드가 그 방식만 남아 무엇을 골랐는지 이미 보인다.

## 스스로 본 약점
- 처음 온 초보는 ⓘ 를 누르지 않는다. "직접 탐색"이라는 말만 보고는 차이를 모를 수 있다.
- 카드의 "직접 탐색" 글자에도 같은 설명을 붙일지 정하지 않았다.
