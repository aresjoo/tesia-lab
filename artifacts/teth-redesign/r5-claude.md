| 4 | AI 라면서 봇처럼 보이는 것 | 조건 실행 9종. 하지만 "조건 실행"이라고 스스로 말하고 "정해 둔 조건만 따른다"고 설명하므로 포장이 아니다. 상단 문장 "AI에게 거래를 맡길지"가 조건 실행까지 AI 로 묶는 것은 Codex 가 Round 2 에서 지적했고 아직 남아 있다 | P1 |
| 5 | 자율성이 이해 안 되는 부분 | 직접 탐색이 "흔들림으로 나눈 값"으로 고른다는 것 외에 AI 가 하는 판단의 폭이 안 보인다. 실제로는 정해진 계산식이다. "AI가 정하는 것"이라는 표현이 계산식 이상의 판단을 암시한다 | P1 |
| 6 | 이름이 자동 생성기처럼 보이는 전략 | "기술주 셋", "지수와 금"은 설명형이라 고유 이름들(세 갈래, 되짚기) 사이에서 튄다. 생성기 느낌은 아니지만 체계가 둘로 갈린다 | P2 |
| 7 | 너무 흔한 핀테크처럼 보이는 것 | 정렬 칩과 시장 드롭다운, 검색 줄. 기능상 필요하고 눈에 띄지 않는다 | 없음 |
| 8 | 너무 게임처럼 보이는 것 | 없음. 사람 캐릭터와 별명을 뺐다 | 없음 |
| 9 | 상세를 열 이유가 없는 카드 | 조건 실행 중 "하락 대기"인 7장. 카드만으로는 서로 자산만 다르다. 설명 문장이 차이를 만들지만 상태 줄은 같다 | P2 |
| 10 | 상세를 열어도 알 수 없는 것 | 따라가면 내 돈이 언제 들어가는지. "다음 진입부터 따라가요"는 따라가기 시트 뒤 토스트에만 있다. 상세의 "지금 3종목 보유 중"을 보고 따라가면 그 3종목을 바로 사는지 알 수 없다 | P1 |

| 13 | 거래소 카피트레이딩 복제처럼 보이는가 | 아니다. 트레이더 프로필, 팔로워 수, 순위, ROI 큰 글씨가 없다. 남은 닮은 점은 카드 하단의 거래소 표시와 4열 카드 격자 | 없음 |

## 고칠 것
| # | 등급 | 요소 → 문제 → 사용자 해석 → 제안 |
|---|---|---|
| A | P1 | 상단 문장 "어떤 방식으로 판단하는 AI에게 거래를 맡길지 골라요" → 조건 실행도 AI 로 묶음 → 규칙을 AI 로 포장했다는 인상 → "어떤 방식으로 판단해 거래할지 골라요" |
| B | P1 | "AI가 정하는 것"(직접 탐색) → 실제는 정해진 비교 방식 → 과장 → 하는 일에 비교 방식을 한 문장으로 밝힘: "최근 오름폭을 흔들림으로 나눠 순위를 매겨요" 는 이미 표 설명에 있음. 하는 일의 "AI가 정하는 것" 옆에 "정해진 비교 방식으로" 를 넣음 |
| C | P1 | 따라가면 언제 들어가는가 → 상세에 없음 → 지금 보유 종목을 바로 사는 줄 앎 → 움직이는 방식 네 칸 중 "얼마나 사나" 뒤에 붙이지 말고, 따라가기 버튼 옆 메타에 "다음 진입부터 따라가요" |
| D | P1 | 성과 탭 첫 KPI "수익률 +97.8%"(전체 기간) → 개요에서 내린 큰 누적 값이 탭에서 다시 맨 앞 → 수익률 판매 → 성과 탭 KPI 순서를 최대 낙폭, 승률, 거래 수, 수익률로 바꾸지 않고(사용자 KPI 순서 유지) 기간 기본값을 1년으로 |
| E | P2 | 세 번째 배너의 빛 번짐 → 톤 불일치 → 배경을 단색으로 |
| F | P2 | "기술주 셋", "지수와 금" → 체계 불일치 → 유지. 의도된 불균일. Codex 의견을 듣는다 |
