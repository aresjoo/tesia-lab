- 이전 Codex 보고서와 `r12-claude.md`를 열지 않고 이 1부를 먼저 작성했다. 기준 A~N의 정의만 `r5-codex-brief.md`에서 확인했다.
- 8843 서버가 응답하지 않아 저장소를 읽는 정적 서버를 시작했다. Chrome 9333의 별도 BrowserContext에서 `http://127.0.0.1:8843/`를 검증했다. 다른 세션의 저장 상태는 건드리지 않았다.
- 1440×900, 1280×900, 390×844에서 실제 렌더와 DOM을 확인했다. 라이브 화면은 CDP 캡처를 메모리로 열었으며 PNG나 검사 스크립트를 추가하지 않았다.

- 이전 방문 이력을 근거로 대상을 제외하지 않고 20종 전체 개요를 다시 열었다. 아래 후반 전략을 집중 검증해 각 판단 방식 2개 이상을 충족했다.

### baseline과 final의 직접 비교

- 목록: baseline은 사람 아바타, 큰 초록 수익률, 넓은 라임 버튼이 첫 인상을 지배했다. final은 방식과 시장, 행동 설명, 지금 상태가 먼저 읽히고 자세히 버튼이 탐색을 유도한다. 1280과 390에서도 같은 위계다.
- 상세: baseline의 AI 요약과 큰 누적 수익률 차트 중심에서 final의 지금, 하는 일, 움직이는 방식, 최근 판단, 성과 순서로 바뀌었다. 원인을 읽고 성과를 확인하는 흐름이다.
- 세 유형: 직접 탐색은 순위와 복수 보유, 조건 실행은 조건 충족 여부, 혼합은 AI와 규칙의 단계가 실제로 다르게 렌더된다. 명칭만 다른 카드가 아니다.
- 목표 판정: 서로 다른 판단 방식을 비교하고 고르는 제품에는 도달했다. F01은 이 시각적 개선을 부정하지 않지만, 선택 후 통제까지 믿을 수 있다는 결론을 막는다.

## 3부. 남은 수정

1. **P1 F01:** 지금 정리, 원본 청산 대기, 직접 관리의 상태 전이를 구현과 원장에 일치시킨다. 열린 포지션이 있는 상태에서 각 분기, 새로고침, 실제 청산, 한 번만 반환, 재시작까지 재검증한다. 코드가 이전 라운드와 같아도 남은 결함이라는 판정은 달라지지 않는다.
