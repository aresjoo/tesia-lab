# TETH 푸터 상단 바 비교 판정

두 원본 이미지 `rh-ref-bar.webp`와 `ours-bar-1440.png`를 직접 열어 비교했다. 로빈후드의 CSS 픽셀 기준은 `MEASURE-rh.md`, TETH의 기준은 현재 작업 트리의 `site-footer.js:5` CSS 문자열과 제공된 PNG다. 기존 `site-footer.js` 변경분을 심사했으며 제품 소스는 수정하지 않았다.

로빈후드 이미지는 2000×207, TETH 이미지는 1440×300이다. 로빈후드 이미지 전체에 `1440/2000`을 곱해 CSS 값을 역산하지 않았다. 확대와 재표본화가 들어간 이미지에서는 상대 간격을 비교하고, 절대값은 실측 문서를 우선했다. TETH PNG의 실제 푸터 폭은 1425px이고 오른쪽 15px는 스크롤바 영역이다. 배경, 글자, 아이콘의 색상 변경은 감점하지 않는다. 선 색상은 요청에 따라 기록하되 색상 차이와 두께 차이를 구분한다.

아래에서 글자 박스는 링크 요소 또는 제목 요소의 레이아웃 박스, 잉크는 이미지에서 실제로 칠해진 글자 픽셀이다. 두 기준을 섞으면 한국어와 영어의 글꼴 차이를 여백 차이로 오판한다. 이미지 픽셀 좌표는 0부터 시작한다.

데스크톱 수정 제안은 현재 `.gft` 컨테이너의 모바일 분기 밖에서 적용해야 한다. 특히 1번의 `min-height:87px`와 링크 이동값을 모바일까지 덮어쓰면 현재 2행 바에 영향을 준다. 5a의 두 칼럼 조정은 2열이 유지되는 컨테이너 폭 900px 초과 구간을 기준으로 한다. 이 심사는 제공된 1440 캡처 대상이며 모바일의 확대 클릭 영역은 불일치 항목이 아니다.

검증은 두 이미지 직접 열람, 원본 이미지의 브라우저 Canvas 픽셀 읽기, `site-footer.js`와 `index.html:38`의 전역 `box-sizing:border-box` 확인으로 수행했다. 보조로 별도 임시 브라우저 탭에 현재 푸터 소스와 같은 기본 글꼴 및 1425px 폭을 넣어 요소 박스를 측정했다. 이는 제공된 PNG를 대체하는 새 캡처가 아니며, 원본 로빈후드의 밑줄 computed style이나 수정안 적용 후 렌더를 검증한 것은 아니다. 수정 제안은 보고서에만 기록했다.
