# ROUND 3 (최종 synthesis 검수, Codex)

Claude 가 R1, R2 를 반영해 **제품에 구현한 상태**다. 너는 최종 화면을 기준으로 마지막 검수를 한다. index.html 은 수정하지 말고, 고칠 것을 구체적으로 지적한다.

- `ux-audit/strat20/R3-final.md`: 20개 최종 표(이름, 소개, 자산, 거래소, 아바타, 실제 계산된 성과, 규칙값).
- 스크린샷: `ux-audit/strat20/list-v3-1440.png`(1페이지 20장), `list-v3-390.png`(모바일), `detail-v3-1440.png`(상세 개요), `avatars-sheet.png`(아바타 112px 과 44px).
- 실제 제품: 정적 서버를 직접 띄워(포트 8843) 헤드리스 Chrome 127.0.0.1:9333 으로 `tfShareHub('find')` 를 열어 확인. 저장 상태를 지우고 시작할 것(localStorage.clear 후 새로고침).

## R2 지적에 대한 Claude 의 조치 (검증 대상)
1. 소개문에서 뉴스, 무기한 보유, "첫 구간", "조금 사서" 등 엔진에 없는 행동을 뺐다. 모든 소개는 진입(떨어진 뒤 반등 확인), 익절, 손절, 25일 상한, 방향 필터 안에서만 말한다. 빈도 표현(거래가 잦아요, 드문 편, 쉬는 날이 더 많아요, 평균 보유 5일, 2026년 2월 시작)은 실제 계산 결과와 맞춰 썼다.
2. 성과는 목표를 적어 넣지 않았다. 카피에 나온 익절, 손절 값은 고정하고, 자산별 가격 씨앗과 진입 깊이만 오프라인 탐색으로 골랐다. 화면의 값은 엔진 계산 결과라 승률은 항상 승/전체 분수다. 같은 자산의 전략은 같은 가격 데이터를 쓴다(예: 비트코인 3개).
3. 가격 전달: `runBacktest(params)` 가 `params.px` 로 자산 가격을 골라 쓰고(`mkWithPx`, 실행 후 복원), 상세 렌더(`tfSS3DetailRender`)와 따라가기 화면의 가격 표시도 같은 키를 쓴다. 캐시 키에 px 포함.
4. 미니 차트는 30일 첫날을 1로 다시 맞춘다.
5. 20종을 정렬한 뒤 10페이지로 반복. 필터나 검색 중에는 반복하지 않는다. 기본 순서는 카탈로그 순서(정렬 칩을 누르면 그 기준).
6. 소개는 2줄 고정 높이. 손절 값은 설정 가져오기 선택지(3, 5, 8, 12)에 있는 값만 쓰고, 익절은 원본 값이 선택지에 추가된다.
7. 아바타: 얼굴형 5종을 넣고, 겹친다고 지적된 쌍과 모자, 후드, 헬멧을 고쳤다. 나이와 위험 성향의 결합을 풀었다(예: 야수의 심장은 회색 머리, 느림보는 젊은 인물).

## 답할 것
A. 사용자 품질 기준 12문항 각각 YES / NO 와 근거 한 줄:
 1) 20장이 복붙처럼 보이지 않는가 2) 전략명만 읽어도 행동이 어느 정도 상상되는가 3) 소개가 이름과 중복되지 않는가 4) 초보자가 지표를 몰라도 이해 가능한가 5) 너무 유치하지 않은가 6) 너무 딱딱하지 않은가 7) AI 가 만든 문구처럼 느껴지지 않는가 8) 전략마다 성격이 있는가 9) 성과 숫자가 전략 성격과 어느 정도 일치하는가 10) 스크롤하며 다음 카드가 궁금해지는가 11) 따라가기를 누르고 싶은 이유가 생기는가 12) 여러 AI 트레이더 중 하나를 고르는 마켓처럼 느껴지는가
B. 소개문 20개를 엔진 규칙(index.html 의 runBacktestCore)과 다시 대조해 아직 남은 거짓이나 과장을 찾아라. R3-final.md 의 규칙값, 실제 계산 결과(브라우저에서 `tfSSRows()` 로 조회 가능: r.n, r.winRate, r.avgHold, r.exposure, r.trades)와 맞는지.
C. 숫자와 성격이 어긋나는 카드(예: 이름은 보수적인데 낙폭이 큼)를 지적.
D. 스크린샷 기준 시각 문제: 줄바꿈, 말줄임, 카드 높이, 아바타 식별, 거래소 로고 정렬, 미니 차트.
E. 회귀 확인: 상세 5개 탭, 기간 칩(1년, 2년), 정렬 칩, 검색(이름, 소개, 자산), 페이지 2~10, 따라가기 버튼 진입, 다른 화면(홈, 대시보드)에서 콘솔 오류.
F. 반드시 고칠 것 목록(우선순위 순, 최대 10개). 고칠 문구는 대안 문장까지 제시.
