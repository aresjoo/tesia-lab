# 전략 목록 20종 개편: 결정 기록 (2026-09-28)

라운드: R1(독립 분석) `R1-claude.md`, `R1-codex.md` / R2(서로 비판) `R2-claude.md`, `R2-codex.md` / R3(최종 검수) `R3-final.md`, `R3-codex.md`.

## 확정한 구조
- 목록의 실제 전략은 20종(`MK_CAT`). 20종을 정렬한 뒤 10페이지로 반복한다. 필터, 검색 중에는 반복하지 않는다.
- 성과 수치는 적어 넣지 않는다. 자산마다 가격 데이터를 따로 두고(`MK_PX_CFG`, `mkPx`) 기존 엔진을 그대로 돌린 계산 결과다. 목록, 상세 5개 탭, 따라가기가 같은 데이터를 본다.
- 카피에 나온 익절, 손절 값은 규칙값으로 고정. 오프라인 탐색(`tools/search2.cjs`)은 가격 씨앗, 진입 깊이, 방향 필터, 시작 시점만 고른다.
- 카피는 엔진이 실제로 하는 일(떨어진 뒤 반등 확인 후 매수, 익절, 손절, 25일 상한, 방향 필터) 안에서만 말한다. 빈도와 보유일 표현은 계산 결과에서 채운다.
- 30일 수익률만 최근 30일. 낙폭, 승률, 거래 수는 운용 시작부터 전체(사용자 지시).

## Codex 지적 중 반영
미니 차트 기준선 재설정, 정렬 후 반복, 식별자와 거래소와 아바타 명시 필드, 새 이름과 소개로 검색, 정보 탭 거래소 하드코딩 제거, 자산별 가격과 가격 표기, 엔진에 없는 행동 문구 삭제, 승률 분수 문제(엔진 결과 사용으로 해소), 아바타 얼굴형과 겹치는 쌍 교정, 체결 이력 청산가를 손익 계산과 같은 가정으로, 상세 최소 자산과 입력 검증 통일, AI 요약에 25일 상한, 모바일 페이지 이동 위치, 숫자와 조사 줄바꿈.

## 반영하지 않은 것과 이유
- 카드 네 지표를 전부 30일로 통일: 사용자 지시가 "수익률만 30일".
- 자산을 가상자산 4종으로 한정: 사용자가 주식, 지수, 금을 후보로 지정.
- "데모", "생성 가격으로 계산" 같은 화면 고지: 목업에서 고지 문구를 넣지 않는다는 사용자 규칙.
- 규칙 유형을 새로 만드는 안(돌파, 야간, 분할): 이번 범위 밖.

## 다시 만드는 법
`tools/` 의 `spec3.cjs`(목표와 고정 규칙값), `texts.json`(이름, 소개, 거래소, 표시 순서), `avatars.json`(인물 조합)을 고친 뒤 search2 → cat-build, avatars 순서로 실행. 스크립트 안의 경로는 작업 당시 경로라 실행 전에 맞춰야 한다.
