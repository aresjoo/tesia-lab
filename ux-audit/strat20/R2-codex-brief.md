# ROUND 2 (Codex가 Claude 안을 공격)

이 폴더의 세 파일을 읽는다: `R1-claude.md`(Claude 1라운드 안), `R2-claude.md`(Claude 가 Codex R1 을 비판한 글), `avatars-sheet.png`(Claude 가 만든 SVG 아바타 20종 시안, 큰 것 112px 과 실제 크기 44px).
너의 1라운드는 `R1-codex.md`.

## 할 일
Claude 안을 구체적으로 공격한다. 칭찬은 필요 없다. 아래 질문에 각각 답한다.
1. 이 카피가 실제 카드 폭에서 살아남는가? 실제 제품 CSS(제목 15px 굵게, 제목 영역 약 182px, 2줄 제한 / 소개 12.5px, 본문 약 238px)로 **Claude 20개 이름과 소개를 브라우저에서 측정**해서 줄 수와 말줄임 여부를 표로. 소개는 2줄 허용 기준으로도 측정. 390px 모바일도.
2. 감성적인 이름 때문에 전략 의미가 불명확해지지 않았는가? 이름별로 "자산이 보이는가, 행동이 보이는가" 판정.
3. 20개 이름이 서로 충돌하지 않는가? 비슷한 인상, 같은 접미사, 같은 말버릇.
4. 코드에서 유지보수 가능한가? Claude 의 구조 제안(전략마다 가격 데이터를 따로 두고 기존 엔진을 그대로 돌림, 목표 수치에 맞는 씨앗과 규칙값을 오프라인 탐색으로 고정)의 위험을 구체적으로. 전역 `PRICE` 를 전략별로 바꿔 끼우는 방식에서 깨질 수 있는 호출 지점을 줄번호로.
5. 한줄소개가 실제 전략 행동(엔진 규칙)과 일치하는가? 엔진이 못 하는 행동을 말하는 문장을 찾아라(예: "악재로 시끄러운 날", "튀는 순간", "첫 구간").
6. 수익률, 낙폭, 승률, 거래 수 조합이 말이 되는가? 익절, 손절 폭과 승률로 기대값을 계산해 모순을 찾아라.
7. 아바타 시안: 44px 에서 20명이 구별되는가, 같은 얼굴로 보이는 쌍, 어색한 부품(모자, 헬멧, 머리카락 겹침), 고정관념에 기대는 배정.
8. `R2-claude.md` 의 반박 1~6 에 대해 수용 또는 재반박. 재반박은 근거와 함께.
