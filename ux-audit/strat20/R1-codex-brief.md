# ROUND 1 (Codex 독립 분석): 전략 목록 20종 개편

역할: Adversarial Product Engineer + Conversion Reviewer. Claude 쪽 초안은 보지 말고(이 폴더의 `R1-claude.md` 열지 말 것) 독립적으로 결론을 낸다.

## 대상
- 저장소: 현재 폴더. 단일 파일 SPA `index.html`(CRLF, BOM, 약 18,000줄). **index.html 은 수정 금지**, 읽기만.
- 화면: 전략 찾기 목록(`tfShareHub('find')`, 카드 4열, 20개씩 10페이지).
- 관련 함수: `tfRankSeeds`, `tfSSRows`, `tfSS3GridHtml`, `mkCard`, `mkHook`(제목), `mkOne`(한줄소개), `mkEx`(거래소), `mkAi`(아바타), `mk30`, `mkSpark`, `runBacktest`, `PRICE`, `tfSS3PdCalc`, `tfSS3DetailRender`, `mkOvTab`, `mkLogTab`, `mkTradesTable`, `mkRuleEval`.
- 현재 상태 캡처: `ux-audit/card3/noai-1440.png`.

## 사용자가 원하는 것 (요약)
카드 구조는 유지한다: 아바타, 전략 제목, 거래소 로고와 이름, 한줄소개, 30일 수익률, 수익률 그래프, 최대 낙폭, 승률, 거래 수, [따라가기] [자세히]. 새 칩, 배지, 지표 추가 금지.
바꿀 것은 다섯 가지다: 전략 이름, 한줄소개, 전략별 아바타, 전략별 성과 데이터, 20개 사이의 개성과 차별화.
- 1페이지 20개만 실제로 서로 다른 전략. 2~10페이지는 같은 20개 반복(총 200). 데이터는 20개 기준 세트에서 생성.
- 이름은 "기능명"이 아니라 "상품명". "BTC RSI 반등 전략" 같은 개발자식 이름 금지. 그렇다고 "사냥꾼, 추적자, 레이더, 라이더" 접미사 돌려쓰기도 금지. 일부는 직관형, 일부는 persona, 일부는 행동 중심, 일부는 고유명사처럼. 여러 제작자가 각자 올린 것 같은 의도적 불균일성.
- 한줄소개는 기술 설명서가 아니다. 숫자만 바꾼 같은 문장 20개는 실패. 아무 제품에나 붙는 문장("시장 기회를 포착합니다") 금지. "혁신적인, 최첨단, 스마트한, 강력한" 금지. 수익 보장 표현 금지.
- 아바타: 사람형 캐릭터 가능, 실존 인물 금지, 20개가 같은 얼굴이면 실패, 미술 스타일은 통일.
- 성과: 20개 모두 값이 달라야 한다. 30일 수익률 대략 +1~18%, 최대 낙폭 -2~-18%, 승률 41~78%, 거래 수 4~90회. 숫자끼리 관계가 자연스러워야 한다(공격형은 낙폭도 큼, 거래 적으면 승률이 과하게 정밀해 보이지 않게, 단타형은 거래 수 많음, 승률 낮아도 손익비로 수익).
- 자산 분산(앱이 실제로 다루는 범위 안에서), 거래소는 Binance, OKX, Bitget 자연스러운 분포.
- 문장부호: em dash 와 가운뎃점 사용 금지. "시뮬레이션, 예시, 데모, MOCK" 같은 화면 문구 금지(코드 주석은 가능).

## 분석할 것
1. 현재 코드와 데이터 구조: 200개가 어떻게 만들어지는지, 제목과 한줄소개가 어떻게 조립되는지, 성과 수치가 어디서 오는지, 상세 페이지(개요, 성과, 거래, 활동, 정보 탭)가 무엇에 의존하는지.
2. 20개가 실제 UI 에서 어떻게 보이는지. 반복 패턴, 자동 생성 티, 이름 길이, 말줄임, 한줄소개 중복.
3. 숫자 설계 문제. 왜 30일 수익률이 전부 같은지, 고치려면 어떤 구조가 가장 안전한지(엔진 결과 유지 vs 기준 세트에 성과 기록을 두는 방식), 상세 페이지 수치와 어긋나지 않게 하는 방법.
4. 아바타 확장성: 20개 사람형 캐릭터를 SVG 로 만드는 현실적인 방법과 위험.
5. 구현 난이도와 유지보수성, 실제 API 데이터로 교체하기 쉬운 구조.
6. **Codex 자체 제안**: 20개 표(전략명, 한줄소개, 자산, 거래소, 아바타 컨셉, 30일 수익률, 최대 낙폭, 승률, 거래 수, 그래프 모양). 전략명은 카드 폭(제목 영역 약 190px, 17px 굵은 글씨, 2줄까지) 에서 말줄임 없이 들어가야 한다.
