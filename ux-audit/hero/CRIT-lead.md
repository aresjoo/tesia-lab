## 각 안의 가장 좋은 것 / 반드시 고칠 것
- claude: 좋은 것 = 레퍼런스와 같은 "글자 위, 빛 아래" 구조와 정돈된 아래 흐름. 고칠 것 = 영상이 삽화처럼 작다. 히어로 높이를 키워 영상 밴드가 뷰포트 하단까지 차고, CTA가 빛의 시작선에 걸리게.
- codex: 좋은 것 = 상황실 카드로 제품을 3초 안에 보여줌. 고칠 것 = 카드가 영상을 덮음. 카드를 히어로 밖(바로 아래 섹션 첫 요소)으로 내리면 산다.
- light: 좋은 것 = 가장 강한 첫인상, "지금 이 순간에도" 섹션. 고칠 것 = 밝은 타일 위 텍스트 대비. 서브 카피와 링크를 타일 위에서 빼거나 하단 그라데이션 필요.
