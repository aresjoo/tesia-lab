# NOTE-claude: 에디토리얼 캄

- 콘셉트: 크게 외치지 않고 조용히 설명하는 지면처럼, 세리프 한 줄과 빛나는 바닥 하나로 "맡겨도 되는 곳"이라는 인상을 만든다.
- 헤드라인 "내 기준대로, AI가 거래해요": 무엇을 하는지(AI가 거래)와 누가 통제하는지(내 기준)를 한 줄에 담았다. 서브는 한 문장으로 "이유를 남긴다"까지 예고해 아래 섹션과 이어진다.
- 세리프: Noto Serif KR 500(목업만 Google Fonts). 고딕 일색인 앱 안에서 이 화면만 "읽는 페이지"로 구분된다. 실서비스는 헤드라인 글자만 서브셋 셀프호스팅, 폴백은 Nanum Myeongjo, Batang, serif.
- 동영상 배치: 글자는 영상 위 검정 여백에만 두고 타일과 겹치지 않는다(흰 글자 대 #0c0d0f, 대비 18:1 이상). 영상은 mix-blend-mode:screen 으로 검정 픽셀이 페이지색에 녹고, 네 변 마스크로 바닥이 페이지 속으로 사라져 경계선이 없다. 390 에서는 높이 250px, object-position 가운데 아래로 빛나는 중심 타일만 크롭.
- 섹션 순서: 무엇을 돌리나(3종 카드, 예시 문장 포함) → 어떻게 판단하나(1인칭 판단 카드 2장, 쉬었어요/샀어요) → 어떻게 시작하나(3단계) → 내 돈은 안전한가(4줄) → "작게 켜두고, 읽어보고, 늘려요" 마지막 CTA. 이해, 신뢰, 행동, 안심 순으로 망설임을 하나씩 지운다.
- 절제: 수치 과시, 사용자 수, 스크롤 등장 효과 없음. 라임은 같은 행동(무료로 시작)에만 2회. reduced-motion 이면 영상 대신 poster 정지 이미지.
- 위험: 조용한 만큼 "수익이 나는가"를 기대한 방문자에게 증거가 약해 보일 수 있다. 판단 카드 아래에 실제 공개 전략 1개 링크(과시 없는 판단 기록)를 붙이는 보강이 필요할 수 있다.
