# 시안 비판 라운드 브리프

세 안: claude(에디토리얼 캄, 세리프 헤드라인, 영상은 글자 아래), codex(제품 먼저, 헤드라인 아래 상황실 카드가 타일 위), light(빛 위의 한 문장, 영상 전면 배경). 파일: ux-audit/hero/mock-<이름>-d1440.png, mock-<이름>-m390.png, NOTE-<이름>.md, mock-<이름>.html. 원안 브리프 ux-audit/hero/BRIEF.md, 레퍼런스 ux-audit/hero/ref-robinhood.webp, 현재 화면 ux-audit/hero/current-d1440.png.

자기 안은 채점하지 않는다. 다른 두 안을 실제 PNG 를 열어 보고 채점한다. 항목 0~10, 8개: 3초 이해(뭐 하는 곳인지) / 동영상 활용(빛과 글자의 관계, 잘림, 모바일 크롭) / 헤드라인 힘 / 신뢰(초보자가 돈을 맡길 마음이 드는가) / 1차 CTA 명료성 / 아래 섹션 흐름 / 시각 완성도(간격, 위계, 대비) / 구현 현실성(index.html 사이드바 레이아웃과의 충돌, 성능). 각 점수에 한 줄 근거(좌표나 요소 이름). 그 다음: 각 안의 "가장 좋은 한 가지"와 "반드시 고칠 한 가지". 마지막: 채택 추천 1개(합치기 금지)와 채택 시 필수 수정 3개 이내. 한국어, em dash·가운뎃점 금지. 산출: ux-audit/hero/CRIT-<이름>.md, 마지막 줄에 경로.
