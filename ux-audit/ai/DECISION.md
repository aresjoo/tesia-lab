# "TETH가 쓰는 AI" 섹션 결정 (2026-09-28)

- 후보: claude(역할 목록 2열), grid(아이콘 벽 3x3 + 모바일 탭 패널), codex(상황별 묶음 3열).
- 채점: 리드 codex 8.2 = claude 8.2 > grid 6.8, 결정 기준 "제목을 화면이 증명하느냐"로 codex. Claude 비평석(codex·grid) codex 우세(9/8/7/8/9/8 대 5/7/5/3/3/6). Codex 심사(claude·grid)는 자기 안 제외.
- 확정: codex. 필수 수정: 테두리 카드 → 헤어라인 열(페이지 문법), 역할 문장 text-wrap pretty(외자 줄바꿈 방지), h1 → h2, 외부 폰트 링크 제거, 상표 한 줄은 작게 우측 정렬.
- 남는 위험: 상황 묶음은 실제 라우팅 주장이므로 서비스에서 라우팅이 달라지면 문구도 바꿔야 한다.
