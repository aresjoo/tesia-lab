# AI 섹션 시안 평가: CODEX

claude를 채택한다. 역할 문장을 펼쳐 놓은 목록이 AI를 골라 쓰는 이유를 더 잘 보여 주고, 기존 판단 카드로 시선을 이어 주기 때문이다. codex는 평가에서 제외했다. 점수는 항목별 10점, 동일 가중치다.

## 확인한 근거

- `CRITIQUE_BRIEF.md`, `BRIEF.md`, 두 안의 `NOTE`와 HTML을 읽었다. AI 9개의 표시 이름과 역할 문장은 모두 원안과 일치하며, `assets/ai/SOURCES.json`의 9개 항목은 모두 `ok:true`다.
- `mock-claude-d1440.png`, `mock-claude-m390.png`, `mock-grid-d1440.png`, `mock-grid-m390.png`를 실제로 열어 확인했다.
- 페이지 맥락은 `../hero/final-d1440.png`, `../card/final-d1440.png`를 실제로 열어 대조했다. 본문 제목의 왼쪽 정렬, 세리프 서체, 낮은 채도의 설명과 구분선을 기준으로 삼았다.
- PNG 헤더에서 확인한 실제 크기는 claude 데스크톱 1425×1022, 모바일 390×1010, grid 데스크톱 1425×1163, 모바일 390×870이다. 지정된 1440×900, 390×844와 다르다. 촬영 당시 뷰포트 크기는 이 파일만으로 확정할 수 없으므로 전체 PNG가 한 화면에 들어온다고 판단하지 않았다.
- 3초 전달력은 화면의 시각적 우선순위에 대한 평가이며 사용자 시간 측정 결과는 아니다. 탭 전환과 키보드 조작은 HTML만 확인했고 브라우저에서 실행 검증하지 않았다.

반드시 고칠 것: 390px에서 9행이 이어지는 길이를 줄여야 한다. 모바일 리드는 생략하고 아이콘과 행 여백을 줄이되, 9개 역할 원문은 모두 읽히게 유지한다. `mock-claude.html:44`의 `white-space:nowrap`과 말줄임은 글자 확대나 다른 폭에서 정보가 잘릴 수 있으므로 줄바꿈을 허용하는 편이 낫다. 제출된 390px PNG에서 실제 말줄임이 보인다는 뜻은 아니다.

가장 좋은 것: 모바일에서 9개 AI의 존재를 한 덩어리로 파악할 수 있고, 다음 섹션 제목도 약 y=760에 보여 페이지의 진행이 끊기지 않는다. 선택 패널은 원문을 그대로 보여 주도록 구현돼 있다.

반드시 고칠 것: 역할 설명을 모바일 탭 뒤에만 두지 말아야 한다. 타일 안에 각 역할 원문을 읽을 수 있게 배치하고 아이콘 크기와 여백을 함께 줄이는 수정이 필요하다. 현재 `mock-grid.html:61`은 모든 타일의 역할을 숨기고, `:119`의 `pick()`은 선택한 하나만 패널에 넣는다. 탭 안내 문구는 조작 방법을 알려 줄 뿐 역할 비교의 부담을 없애지는 못한다.

## 단일 채택 추천과 필수 수정

추천은 **claude**다. 이 섹션은 뒤의 실제 판단 내용을 읽기 전에 AI별 역할을 이해시키는 자리다. 작은 아이콘 옆에 역할이 계속 보이는 목록이 목적에 더 맞는다. 두 안을 합치지 않고 claude의 목록 구조를 유지한다.

필수 수정은 두 가지다.

1. 모바일 리드를 생략하고 행의 아이콘 크기와 여백을 줄여 9개 역할 목록을 압축한다. 역할 원문을 유지하고 말줄임 대신 줄바꿈을 허용한다.
2. 수정본을 실제 1440×900과 390×844 뷰포트로 다시 촬영한다. 데스크톱 섹션 전체가 보이는지, 모바일의 9개 역할이 잘리지 않는지 확인하고 전체 페이지 캡처와 구분해 제출한다.

이 문서는 시안 평가다. 제품 코드 수정, 실제 AI 연동 확인, 브라우저 상호작용 검증은 수행하지 않았다.
