# 전략 상세 "개요" 영역 시안 브리프

레퍼런스: `ref-lot-detail.png` 의 빨간 박스(League of Traders 포트폴리오 상세). 사용자 지시: "디자인 존나 똑같이". 배치, 비율, 간격, 글자 크기 위계, 차트 표현을 최대한 그대로 옮기되 내용은 TETH 것으로 바꾼다. 색은 TETH 톤(배경 #0f1012, 패널 #17191c, 글자 #e3e3e3, 흐린 글자 #9aa0a6, 초록 #2fb98a, 빨강 #f0566a, 라임 #c8f43c 는 버튼에만).

## 위에서 아래로 (레퍼런스 순서 그대로)
1. 머리 줄: 거래소 로고(24px) + 거래소명 + 전략명 + 공유 아이콘, 오른쪽 끝에 "즐겨찾기" 버튼. 그 아래 작은 글씨 "운용 시작 2025.07.14".
2. 상자 두 개 한 줄: 왼쪽 좁은 상자 **필수사항**(행 2개: "거래소" 오른쪽에 로고 + Binance, "최소 자산" 오른쪽에 200 USDT), 오른쪽 넓은 상자 **AI 요약**(레퍼런스의 리더 메모 자리).
   - AI 요약 문안(그대로): "비트코인이 크게 떨어진 뒤 다시 오르기 시작할 때만 사요. 산 가격보다 8% 오르면 팔고, 5% 내리면 바로 정리해요. 오르내림이 뚜렷한 장에서만 움직이고, 방향이 애매하면 쉬어요."
   - 어려운 말은 쓰지 않는다. 그래도 남는 용어 2개("정리", "오르내림이 뚜렷한 장")는 점선 밑줄 + 호버 시 설명 말풍선. 설명: 정리 = "들고 있던 것을 팔아 손실을 더 키우지 않는 거예요", 오르내림이 뚜렷한 장 = "가격이 한 방향으로 꾸준히 움직이는 때예요".
3. 큰 숫자 줄: 왼쪽 라벨 "수익률" 아래 큰 숫자 **+23.9%**(레퍼런스의 $218.73 자리, 같은 크기), 그 아래 작은 글씨 "지난 24시간 +0.4%". 오른쪽에 보조 4개: 이번 달 수익률 +2.1% / 최대 낙폭 -9.0% / 승률 67% / 거래 수 12회. (남의 전략이라 계좌 금액은 보여주지 않는다.)
4. 차트 조작 줄: 왼쪽 알약 탭 3개 "수익률 (i)" / "번 돈" / "든 돈", 오른쪽에 "일별 | 월별" 세그먼트와 기간 선택 드롭다운("최근 1개월" 기본, 3개월, 1년, 전체).
   - "번 돈", "든 돈" 은 **1,000 USDT 로 시작했다면** 기준으로 환산해 보여 준다(차트 위 작은 안내 한 줄). 든 돈 = 1,000 x 기준가, 번 돈 = 든 돈 - 1,000.
   - 수익률 (i) 호버 설명: "이 전략이 매매로 번 비율이에요. 돈을 더 넣거나 빼도 수익률은 그대로예요. 수수료를 뺀 실제 수익이에요. 이 전략의 거래만 계산해요."
5. 차트: 레퍼런스와 같은 표현. 부드러운 곡선, 0% 기준선, 기준선 위 초록 / 아래 빨강, 선에서 기준선 쪽으로 옅어지는 면 그라데이션, 가로 눈금선과 왼쪽 % 라벨, 아래 날짜 라벨, 최고점과 최저점에 흰 점 + "Max +x.xx%", "Min -x.xx%" 라벨.

## 수익률 계산 (확정 규칙)
기준가 방식. 데이터 `data.js` 의 `DETAIL_NAV` 는 날짜별 기준가(시작 1.000). 수익률 = 기준가 / 구간 시작 기준가 - 1. 기간을 바꾸면 그 구간의 첫 날을 0% 로 다시 잡는다. 월별은 각 달의 마지막 날 값으로 점을 찍는다. `DETAIL_NAV` 중간에 운용금 변경 기록(`DETAIL_EVENTS`)이 있는데 수익률 곡선은 끊기지 않아야 하고, "든 돈" 탭은 1,000 USDT 환산이라 역시 끊기지 않는다.
