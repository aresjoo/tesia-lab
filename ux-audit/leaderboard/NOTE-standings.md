# NOTE standings (스포츠 순위표 원형)

1. 콘셉트: 프리미어리그 테이블 + F1 드라이버 순위 쪽. 포디움 없음, 표 한 장에 순위 축(시즌 수익률)만 라임 굵게, 나머지 열은 회색 tabular 숫자. 상금 구간을 축구표의 진출권 색띠처럼 우측 4px 밴드(1~3 라임, 4~10 파랑, 11~50 점선 회색)로 표시하고 구간 경계 행 밑에 점선 + 구간 라벨, 표 아래 범례(1~3 / 4~10 / 11~50 / 51~300)로 설명.
2. 열 구성(1440): # | 변동 | 전략(32px 이니셜 아바타 + 이름 + 유형 배지 + 작성자) | 거래 | 실행일 | 최근 5거래(W 초록 / L 회색 점 5개) | 최대 낙폭 | 시즌 수익률(라임 15.5px bold, 정렬 ▼) | 따라가는 사람 | 따라가기(28px 라임 아웃라인 필). 행 54px 12행 모두 동일(측정값), 헤더 38px sticky(top 44), 얼룩말 없이 hairline만.
3. 상위 3행: 좌측 3px 라임 엣지 + 왼쪽에서 사라지는 라임 6% 그라데이션, 순위 숫자 17px 금/은/동 색 + 같은 색 메달 아이콘, 3위 밑 점선 경계에 "1~3위 상금 구간 150,000 / 70,000 / 40,000 USDT" 라벨.
4. 내 순위 바: .main 끝에 position sticky bottom 56px, 표와 같은 grid 열이라 내 +4.1% 가 시즌 수익률 열 밑에 정확히 정렬. 내용 "내 순위 #143 ▲5 | ETH 야간 변동성 매도 규칙 | 다음 상금 구간 51~300위 800 USDT 까지 +0.8%p | +4.1% | MDD -6.3% | 내 전략 보기".
5. 390: 사이드바 숨김, 열은 순위(변동을 숫자 밑 2줄째) | 전략(아바타 제거, 이름 1줄 + 작성자 + 배지 + 22px 라임 "+" 원형 버튼) | 최근5 점 | 수익률(밑에 MDD) 4열, 거래 / 실행일 / 낙폭 / 팔로워 / 버튼 열 숨김. 행 60px 12행 동일, 가로 스크롤 없음(scrollW 390). 내 순위 바는 2줄(순위 + 전략 + 수익률 / 다음 구간 문장).
6. 스크린샷 확인: d1440(1440x1170) 헤더 카운트다운 D-3 12:41:04 틱 동작, 상금 풀 / 참가 전략 / Bitget 후원 줄, 기준 선언 바, 이번 시즌 / 명예의 전당 세그먼트, 12행 + 우측 색띠 + 하단 범례 + 스티키 바 모두 보임. m390(390x1461) 이름 잘림 없음, 4열 정렬 유지. row.png 헤더 + 상위 3행 클립에서 메달 색 숫자와 라임 엣지, 3위 밑 구간 라벨 확인.
7. 스크린샷 방법: sticky 바가 900 뷰포트 하단에 겹쳐 찍히길래 문서 높이(docH)로 뷰포트를 늘린 뒤 non-full 캡처(cdp viewport 후 shot full:false).
8. 위험 1개: 우측 구간 색띠 + 경계 점선 + 구간 라벨 + 하단 범례가 같은 정보를 4번 말한다. 사용자가 축구표 문법을 모르면 우측 색띠와 라벨 중 하나는 잘라내야 하고, 1440 미만(1100 부근)에서는 11열 grid 가 좁아져 "따라가는 사람" 열부터 숨기는 breakpoint 가 하나 더 필요.
