# 결정: table 채택 (Kaggle 식 경쟁 표)

- 리드(CRIT-lead.md) table 8.5 / standings 8.4 / codex 7.8, Codex(CRIT-codex.md) table 58 / standings 51 / codex 55. 두 심사 모두 table.
- 이유: 50px 행 12개가 한 화면에 들어오는 밀도, 라임 수익률 열 하나만 굵은 단일 축, 3위 뒤와 10위 뒤에 끼어 있는 상금 구간 구분 줄("상금 구간 4~10위 15,000 USDT")로 "순위가 곧 돈"이 표 안에서 읽힌다. 1440 과 390 모두 온전하고, 정렬 탭 클릭 시 순위 재부여와 따라가기 토글까지 목업에서 동작한다.
- standings 는 스포츠 순위표 표현력(4칸 통계 헤더, W/L 점, 우측 상금 색띠 + 범례)이 가장 좋았으나 같은 정보를 4번 말하고 모바일에서 작성자 식별이 약해 2위. codex 는 큰 순위 숫자 + 비례 막대가 매력적이지만 상금 구간이 없고 모바일 행 99px 로 밀도가 떨어져 3위.
- 필수 수정(구현 시 반영): (1) 최대 낙폭 열을 본문 색 13px 로 올려 수익률 옆 병기 원칙 유지, (2) 헤더 카운트다운을 상금 풀과 같은 급으로, (3) 모바일 버튼 터치 영역 40px 이상 + 잘린 전략명은 탭으로 전문 확인, (4) 따라가기 상태는 화면 순서(4번째 행)가 아니라 전략 ID 기준.
- 가져올 것(standings 에서 1개만): 최근 5거래 W/L 점은 table 에 이미 있음. 헤더 4칸 통계형은 도입하지 않음(한 줄 유지).
- 구현 위치: index.html 전략 따라하기 탭의 "전략 찾기"(.mk-* 카드 렌더러)를 이 표로 교체. 시즌 헤더, 기준 선언 바, 이번 시즌/명예의 전당 토글, 내 순위 스티키 바(로그인 시), 12행 + 더 보기. 어휘 금지(아레나/대결/vs), 컴플라이언스/예시 문구 금지.
