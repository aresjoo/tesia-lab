# NOTE bleed: 워드마크가 주인공
- 콘셉트: 위에서 아래로 조용한 Powered by 뱃지, 한 줄로 압축한 링크 4칼럼+문단 밴드, 그리고 거대 TETH. 글자가 바닥 밖으로 약 12% 잘려 나가서 페이지가 문자 그대로 TETH 위에서 끝난다.
- 워드마크 서체: 히어로 헤드라인과 같은 세리프 스택("Noto Serif KR","Nanum Myeongjo",Batang,serif) 500, 자간 -0.02em. 히어로 h1과 같은 목소리로 끝맺어 첫 화면과 마지막 화면이 한 쌍이 되게 했다. 폰트 링크는 넣지 않았고 페이지가 이미 로드한 서체를 쓰며, 없으면 스택 순서로 내려간다.
- fit 방법: canvas measureText의 잉크 경계(actualBoundingBoxLeft/Right/Ascent)로 실제 글자 폭을 재서 font-size를 콘텐츠 폭(거터 사이)에 정확히 맞추고, 캡 높이의 88%만 남기도록 컨테이너 높이를 잡아 overflow hidden으로 자른다. fonts.ready와 resize(rAF)에서 재계산, JS 실패 시 vw 기반 CSS 근사값으로 표시.
- Powered by 줄: 푸터 맨 위 중앙, 테두리 1px 알약형 뱃지(Powered by 흐린 글자, Bitget 아이콘 19px 둥근 사각, Bitget 굵게). 워드마크와 떨어뜨려 TETH 옆 경쟁 로고가 되지 않게 했다.
- 추천: 라임. 다크 페이지에서 라임 면으로 넘어가는 순간이 "끝"을 분명히 알리고, 검정 세리프 TETH가 잘린 채 바닥에 걸리는 장면이 브랜드색과 가장 강하게 묶인다. 다크는 품위는 있지만 본문과 경계가 약해 bleed가 덜 읽힌다.
- 390: 사이드바 숨김, 링크 2열 그리드, 문단은 그 아래 전체 폭, TETH는 16px 거터 사이 폭에 fit(약 131px)되고 똑같이 12% 잘린다.
- 위험: 12% 크롭이 E의 아래 가로획을 가리고 끝의 세리프 돌기만 남겨, 작은 화면에서 쉼표 같은 잔여 획으로 오독될 수 있다(크롭 비율 10% 이하 또는 굵기 600으로 완화 가능).
