# 푸터 시안 비판 브리프

세 안: claude(레퍼런스 충실형, 산세리프 워드마크), bleed(워드마크가 주인공, 세리프, 아래로 잘림), codex(Codex 재량). 각 안은 lime/dark 두 배경. 파일: ux-audit/footer/mock-<이름>-{lime,dark}-{d1440,m390}.png, NOTE-<이름>.md, mock-<이름>.html. 원안 브리프 ux-audit/footer/BRIEF.md, 레퍼런스 ref-robinhood-1.webp, ref-robinhood-2.webp, 페이지 맥락 ux-audit/hero/final-d1440.png.
자기 안은 채점하지 않는다. 다른 두 안의 PNG 8장을 실제로 열어 채점한다. 항목 0~10, 7개: 워드마크 임팩트(폭을 꽉 채우나, 잘림·찌그러짐 없나) / Powered by Bitget 가독성과 격(로고 선명, 광고처럼 튀지 않나) / 링크 IA 스캔성 / 오른쪽 문단 가독성 / 390 대응 / 페이지 톤 연결(다크 본문에서 푸터로 넘어가는 순간) / 구현 현실성(리사이즈 시 fit 유지, 사이드바 폭 변화). 각 점수 한 줄 근거. 그 다음 두 가지 판정: (A) 배경 lime 과 dark 중 어느 쪽이 나은가, 이유 2줄 (B) 채택 추천 1개(합치기 금지)와 필수 수정 최대 2개. 각 안의 가장 좋은 것 1개, 반드시 고칠 것 1개. 한국어, em dash·가운뎃점 금지. 산출 ux-audit/footer/CRIT-<이름>.md, 마지막 줄에 경로.
