곡선: 공용 SPARK_CASES의 60개 표본을 모두 통과하는 단조 cubic Hermite 보간으로 극값을 넘는 과장을 막았다. 두 확대 크기는 같은 viewBox를 쓴다.
기준선: 시작값 1에 0.65px 점선을 놓고 상하좌우 4px 여백을 둔다. 케이스별 세로축은 자동 조정한다.
색 전환: C는 기준선 주변 1.6px에서 초록, 중립 회색, 빨강으로 전환하고 끝점에 점을 찍는다. D는 기준선에서 색을 분리한다.
면 채움: C는 기준선까지 최대 22%의 옅은 면을 채운다. D는 곡선을 아래로 이동한 24개 얇은 스트로크의 투명도를 줄여 9.6px 안에서 사라지는 면을 만든다.
104px 가독성: C 1.55px, D 1.7px 선이며 원본 표본의 작은 진동이 남는다. Chrome에서 12개 SVG의 두 크기와 콘솔 오류 0건을 확인하고 1200×940 PNG를 직접 열었다.
위험: C의 전환 영역에서는 작은 손익이 중립색에 묻힐 수 있다. 공용 ret 숫자는 원본대로 유지했으며 마지막 표본의 실제 변화율과 다르다는 안내를 화면에 적었다.
