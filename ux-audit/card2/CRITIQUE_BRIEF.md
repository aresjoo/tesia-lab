# 2카드 시안 비판 브리프

세 안: claude(숫자 띠: 헤더 아래 숫자 3칸), stat(큰 숫자 먼저: PnL display + 수익률 알약 + 잔고), codex(장부형: 헤더 오른쪽에 숫자 3개). 파일: ux-audit/card2/mock-<이름>-d1440.png, mock-<이름>-m390.png, mock-<이름>-tip.png(용어 설명 열린 상태), NOTE-<이름>.md, mock-<이름>.html. 원안 브리프 ux-audit/card2/BRIEF.md, 현재 1카드 ux-audit/card/final-d1440.png.
자기 안은 채점하지 않는다. 다른 두 안을 PNG 3장을 실제로 열어 채점한다. 항목 0~10, 6개: 숫자 돋보임(현재 잔고·수익률·PnL이 먼저 읽히나, 과시로 보이진 않나) / 브리프 준수(문장 그대로, 예시·시뮬레이션 표기 없음, 강조 위치) / 두 카드의 대칭(같은 컴포넌트로 보이나, RSI 게이지 아이콘의 완성도) / 용어 설명 상자(위치, 가독성, 닫힘 동작이 HTML에서 확인되나) / 390 대응 / 페이지 톤 일치. 각 점수 한 줄 근거. 각 안의 가장 좋은 것 1개, 반드시 고칠 것 1개. 마지막: 채택 추천 1개(합치기 금지)와 필수 수정 최대 2개. 한국어, em dash·가운뎃점 금지. 산출 ux-audit/card2/CRIT-<이름>.md, 마지막 줄에 경로.
