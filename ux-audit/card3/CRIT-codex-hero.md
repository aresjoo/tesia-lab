판정: 수정 후 재심. 좌우 구성은 레퍼런스를 따르지만, 첫 배너의 빈 네온 장식과 근거 없는 행사 문구가 제품 신뢰를 깎는다. 모바일에서는 전략 탐색보다 프로모션이 먼저 화면을 차지한다.

[정확한 CSS 또는 문구 수정값] `.mkh-dots{margin-top:0;align-items:center}.mkh-dots button{width:54px;height:44px}.mkh-dots button::before{top:21px}`로 막대 모양은 유지하면서 터치 영역을 넓힌다. 자동 전환을 유지한다면 같은 줄에 '자동 넘김 멈추기' 버튼을 추가하고 멈춘 뒤에는 '자동 넘김 재생'으로 바꾼다. `mkhStart`는 사용자 정지 상태, 감소된 모션 설정, 배너 내부 포커스 또는 호버 상태에서 타이머를 시작하지 않아야 한다. `mkhPick`은 선택 후 무조건 재시작하지 않는다. `mkhGo`는 비활성 장에 `inert`와 `aria-hidden="true"`를 적용한다. CSS만으로 해결되지 않는 동작 수정이다. 우선순위를 줄여야 한다면 자동 전환을 제거하고 3장 수동 선택을 유지하는 대안도 가능하다.
