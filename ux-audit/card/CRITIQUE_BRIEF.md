# 판단 카드 시안 비판 브리프

세 안: claude(판단 일지: 아바타 56px + 이름, 본문 들여쓰기), quote(인용 카드: 큰 따옴표 + 본문 먼저, 바이라인 아래), codex(트레이더 프로필 카드). 파일: ux-audit/card/mock-<이름>-d1440.png, mock-<이름>-m390.png, NOTE-<이름>.md, mock-<이름>.html. 원안 브리프 ux-audit/card/BRIEF.md, 교체 전 카드 ux-audit/card/current.png, 페이지 맥락 ux-audit/hero/final-d1440.png.
자기 안은 채점하지 않는다. 다른 두 안을 PNG를 실제로 열어 채점한다. 항목 0~10, 6개: 브리프 준수(넣을 것만, 뺄 것 다 뺌) / 3초 인식(누가 무슨 결정을 했는지) / 신뢰감(초보자에게 실제 판단으로 읽히는가, 장식으로 읽히는가) / 타이포와 여백 / 아바타·이름·로고 배치 / 390 대응. 각 점수 한 줄 근거. 각 안의 가장 좋은 것 1개, 반드시 고칠 것 1개. 마지막: 채택 추천 1개(합치기 금지)와 필수 수정 최대 2개. 한국어, em dash·가운뎃점 금지. 산출 ux-audit/card/CRIT-<이름>.md, 마지막 줄에 경로.
