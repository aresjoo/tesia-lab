    전략을 실행할 거래소를 연결하세요

    두 방법 모두 안전해요. 이미 쓰는 거래소가 있다면 그대로 연결하는 걸 추천해요.

    내 거래소 연결

    이미 거래소 계정이 있다면
    • 쓰던 계정과 자산 그대로 사용
    • 자금을 옮길 필요 없음
    • 간편 연결 또는 API 키로 연결

    파트너 거래소로 시작

    거래소 계정이 아직 없다면
    • 간단한 가입으로 새로 시작
    • 가입 즉시 자동으로 연결
    • 파트너 혜택으로 이용료 무료
