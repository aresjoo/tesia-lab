# AI 사용량과 과금: 11케이스 정리 (2026-10-01)

## 0. 결론
11케이스는 케이스별 분기가 아니라 **입력 3개 + 공식 1개 + 막는 곳 3곳**으로 끝난다.

- 입력: ① 이용 방식(없음 / 초대 계정 / 구독 / 구독+초대) ② 이번 달 AI 사용량(포함분 안 / 초과) ③ 거래 크레딧(초대 계정 거래에서 생김, 사용 비용을 덮는지)
- 공식: **이번 달 청구 = max(0, 구독료 + AI 초과 사용료 - 거래 크레딧)**
  - 초대 계정만: 구독료 0 → 초과분이 크레딧보다 크면 그 차액만 청구 (케이스 3, 4, 5)
  - 구독만: 크레딧 0 → 구독료 + 초과분 (케이스 6, 7)
  - 구독 + 초대: 크레딧이 구독료부터 깎는다 (케이스 8~11)
- 막는 곳: 새 전략, 전략 수정, 분석시키기(백테스트 재실행 포함). **실행 중인 전략, 결과 보기, 설정은 절대 막지 않는다** (돈이 걸린 포지션)

## 1. 파운더 표 읽는 법 (확인 필요)
파랑 = 보임/가능, 분홍 = 안 보임/불가로 읽었다. "가입 유도" = 거래소를 TETH 초대 링크로 가입시키는 것, "카드 결제 유도" = 구독 또는 카드 등록.
이렇게 읽으면 표의 4줄이 아래 R1~R4와 정확히 맞는다.

## 3. 화면에서 보이는 것 (새로 필요한 것)
1. 설정 > **사용량** 탭 (ChatGPT 설정에도 있음): 이번 달 사용 막대, 포함분, 크레딧, 예상 청구.
2. 설정 > 결제 > 청구서: `구독 $280 - 거래 크레딧 $190 + 추가 사용 $40 = $130`.
3. 80% 알림 (한 번): "이번 달 AI 사용량이 80%에 도달했습니다."
4. 막힘 창 (R2, R5): 제목 하나, 한 줄, 단추 하나. R2는 플랜 화면, R5는 카드 등록.

## 4. 구현 (한 곳에)
- `aiMeter`: 사용량 기록 (대화 토큰, 백테스트 횟수, 분석 횟수를 달러로 환산)
- `aiBill()`: 공식 하나로 이번 달 예상 청구
- `aiGate(action)`: allow / warn / block(kind) 셋 중 하나. 대화, 백테스트, 분석시키기가 같은 함수를 부른다
- 케이스 번호로 분기하는 코드 금지

## 5. 파운더가 정할 것
1. 표 색 읽는 법(파랑 = 보임)이 맞는지
2. 플랜 화면 초대 카드의 "카드 등록 없이 이용"과 케이스 4(초과 시 카드 유도)가 충돌. 문구를 "전략 실행에 카드 필요 없음"으로 좁힐지
3. 크레딧 이름과 노출 수준. "TETH 커미션 구조 비노출" 원칙과 청구서 차감 표시가 부딪힘. 제안: "거래 크레딧"이라고만 쓰고 계산식(비율)은 보이지 않음
4. 숫자 셋: 로그인 무료분(예: 전략 2개, 백테스트 5회), 초대 연결 보너스(예: 월 $20 상당), 구독 포함분(예: 월 $40 상당)
5. 거래를 늘리라는 권유 문구는 쓰지 않음(이해상충) — 기존 결정 유지 확인
