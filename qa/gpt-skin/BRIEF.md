# TETH 나머지 화면을 ChatGPT 어휘로 다시 만드는 브리프 (2026-10-01)

대상 6곳, 순서대로 하나씩. 한 곳이 끝나야 다음 곳으로 간다.
1. 설정의 결제 탭, 보안 탭
2. 백테스트 실행 준비 화면 (`#/share/bt/<id>/go`)
3. 전략 복사 시트 (`mkFollowSheet`)
4. 전략 찾기 (`#/plan`, `find` 탭)
5. 내 공유 (`mine` 탭)
6. 거래 터미널 (`#/trade`)

## 0. 바뀌지 않는 것 (모든 단계의 프롬프트에 그대로 들어간다)

어휘 (거래소 연결 플랜, 플랜 뒤 화면과 동일)
- 검정 배경 #000 (본문 화면은 #212121 허용), 카드 #303030 반경 26, 테두리 rgba(255,255,255,.1)
- 제목 32px 400, 한 줄 설명 18px #cdcdcd, 본문 16px #ececec, 보조 14px #cdcdcd, 옅은 글 13.5px #9a9a9a
- 주 단추 흰 알약 48px(핵심 화면 52px), 보조는 밑줄 링크. 연두색 #c8f43c 금지
- 얇은 구분선 rgba(255,255,255,.1). 그림자와 그라데이션 금지(플랜 강조 카드 제외)
- 화면 하나에 결정 하나. 스텝퍼, 번호 원, 진행률, "N단계 남았습니다" 금지
- 모바일 390px: 좌우 16px, 제목 32px 유지, 카드 반경 26, 가로 스크롤 없음

말투
- 합니다체. 단추는 서술어로 끝나지 않음("전략 시작하기", "OKX에서 승인하기")
- 묻지 않은 걱정을 먼저 꺼내지 않음. 규제 고지, 면책, "데모", "시뮬레이션" 표현 금지
- "회원님" 금지. em dash, 가운뎃점 금지
- 한 화면에 한 줄 설명 하나. 설명 단락 금지

기능
- 상태 기계와 데이터 흐름은 그대로. 그리는 것(HTML, CSS)만 바꾼다
- 기존 자동 검사(flows 39, rail 31, st-full 17, px 22, pl 20, rv 11)는 계속 통과해야 한다
- TETH 커미션 구조 노출 금지. 컴플라이언스 문구 금지

## 1. 화면별 범위와 "결정 하나"

| 화면 | 사용자가 여기서 내리는 결정 | 지금 문제(가설, 1단계에서 확인) | 참고할 ChatGPT 화면 |
|---|---|---|---|
| 설정 결제 | 구독 유지/해지, 카드 바꾸기, 내역 보기 | 표 형태, 옛 색, 링크와 단추 혼재 | 설정 > 구독, 결제 관리 |
| 설정 보안 | 거래소 연결 끊기, 2단계 인증, 기기 로그아웃 | 행마다 단추, 권한 표 | 설정 > 보안, 연결된 앱 |
| 실행 준비 | 금액 정하고 시작 | 옛 스텝퍼 잔재(btGoFlow), 연두 CTA | 플랜 구성(입력 왼쪽, 요약 오른쪽) |
| 전략 복사 시트 | 이 전략을 따라갈지, 얼마로 | 모달 안에 정보 과다 | GPT 공유 미리보기, 플랜 구성 |
| 전략 찾기 | 어떤 전략을 열어볼지 | 카드 밀도, 필터 UI, 숫자 강조 과다 | GPT 탐색(GPTs) 목록, 카드 그리드 |
| 내 공유 | 공개/비공개, 어느 전략을 손볼지 | 목록과 상태 배지 옛 스타일 | GPT 내 GPTs 목록 |
| 거래 터미널 | 전략을 멈출지, 금액을 바꿀지, 어느 포지션을 볼지 | 정보 밀도 최고, 색 4종, 옛 표 | ChatGPT에는 없음. 어휘만 빌리고 밀도는 유지. 표는 얇은 구분선과 400 굵기 숫자 |

터미널은 "GPT처럼 비게" 만들면 안 된다. 거래 정보는 그대로 두고 껍데기(색, 굵기, 단추, 여백, 말투)만 바꾼다. 이것을 프롬프트에 명시한다.

## 3. Codex 프롬프트 원문

### 3-1. 1단계 원인 분석 (화면마다 <이름>, <결정>, <현재 캡처>, <참고 캡처>를 채운다)

```
당신은 ChatGPT 제품의 디자인 리드로 빙의합니다. 웹앱 TETH(거래소 계정에 전략을 연결해 자동 매매하는 서비스)의 "<이름>" 화면을 봅니다. 한국어로만 답합니다. 파일은 읽기만 하고 고치지 않습니다.

첨부 이미지
1~2. ChatGPT 참고 원본: <참고 캡처>
3~N. TETH 현재 화면(데스크톱 1440, 모바일 390): <현재 캡처>
마지막. TETH가 이미 ChatGPT 어휘로 다시 만든 화면(기준): X1-ex.png, X3-auth.png, X5-done.png

이 화면에서 사용자가 내리는 결정은 하나입니다: <결정>.

해야 할 일
A. 현재 화면이 기준 화면(마지막 이미지)과 다른 제품처럼 보이는 원인을 겉모습(색, 여백, 위계, 컴포넌트), 구조(한 화면의 질문 수, 정보 순서, 모달인지 화면인지), 카피(문장 길이, 어미, 설명 과잉, 불안 유발)로 나눠 적으십시오. 원인마다 어느 요소인지 픽셀이나 문구를 근거로 대십시오. 추측으로 채우지 마십시오.
B. ChatGPT라면 이 화면을 어떻게 만들었을지 제안하십시오. 화면 수, 각 화면의 제목, 한 줄, 입력 요소, 주 단추 문구, 보조 행동을 표로. 색과 형태는 기준 화면의 어휘(검정 배경, #303030 카드 반경 26, 흰 알약 단추, 얇은 구분선, 32px 400 제목)만 쓰십시오. 지워도 되는 정보와 지우면 안 되는 정보를 구분하십시오. <터미널이면: 거래 정보의 밀도는 유지해야 합니다. 비우는 제안은 하지 마십시오.>
C. 카피 교체안을 현재 → 제안 표로. 합니다체, 단추는 서술어로 끝나지 않게, 규제 고지나 면책은 넣지 마십시오. "회원님", 가운뎃점, em dash 금지.
D. 한 문장으로: 통째로 다시 만들어야 하는지, 스타일과 카피만 바꾸면 되는지.

형식: 표와 짧은 문단. 750단어 이내. 근거 없는 칭찬은 쓰지 마십시오.
```

## 4. 파운더가 정해야 할 것 (시작 전)

1. 참고 캡처: ChatGPT 설정 > 구독, 보안, 연결된 앱, GPT 탐색 목록, 내 GPTs 화면을 직접 캡처해 주면 정확도가 올라갑니다. 없으면 제가 기억으로 어휘만 씁니다.
2. 터미널: 색은 몇 종까지 남길지 (수익 초록, 손실 빨강만 두고 나머지 흰색 제안).
3. 전략 찾기: 카드에 남길 숫자 3개 (제안: 검증 수익률, 따라가는 사람 수, 기간).
4. 순서: 위 1~6 그대로인지.
