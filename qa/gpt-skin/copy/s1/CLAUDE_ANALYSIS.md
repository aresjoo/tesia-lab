# 전략 복사 창이 다른 제품처럼 보이는 이유 (Claude 분석)

## 겉모습
| 요소 | 지금 | 기준(X3, K2) |
|---|---|---|
| 주 단추 | 연두 직사각형 48px 700, 비활성은 어두운 올리브 | 흰 알약, 비활성은 회색 |
| 최대 손실 | 연두 슬라이더 + 흰 손잡이 | 연두 없음. 선택은 알약이나 타일 |
| 입력칸 | 검정 바탕 + 1px 테두리, 반경 12, 입력 중 연두 테두리 | #2f2f2f 채운 칸 반경 19, 테두리 없음 |
| 창 | #121417, 반경 18 | #2f2f2f 또는 #212121, 반경 24~26 |
| 제목 | 20px 700 | 20~28px 400~600 |
| 전략 줄 | 회색 판 안에 "차트 규칙, 비앤비 선물, 롱과 숏, 2배" | 이름 한 줄, 보조 줄 짧게 |

## 구조
- 결정은 "얼마로, 얼마 잃으면 멈출지" 둘인데 필드 4개(예산, 최대 손실, 기존 포지션, 주문당 상한) + 요약 문단 3문장 + 하단 문구.
- 요약이 문단이라 숫자를 찾기 어렵다. 행(라벨 왼쪽, 값 오른쪽)으로.
- "고급"을 열어야 기존 포지션 기본값(건너뛰기)이 보인다. 요약 행에 기본값을 보이고, 바꾸고 싶을 때만 누르게.
- 레버리지를 따라간다는 사실이 어디에도 없다. 2배에서 30배로 바뀌는 전략이면 가장 중요한 정보.
- 거래소 미연결 회원 창(C4)은 번호 스텝퍼 + 연두. 브리프대로 이 창 대신 플랜 화면으로.

## 카피
| 지금 | 제안 |
|---|---|
| 예산 (USD) | 예산 |
| 최소 500 (placeholder) | 최소 $500 (보조 줄로: "사용 가능 $1,000, 최소 $500") |
| 최대 손실 / 예산의 20%를 잃으면 자동으로 멈춥니다 | 멈추는 기준 / 손실이 $160에 닿으면 멈춥니다 |
| 예산 $800로 …의 판단을 그대로 따라갑니다 … (3문장) | 요약 행 4개: 예산, 멈추는 손실, 레버리지, 시작 시점 |
| 기존 포지션 처리: 건너뛰기 / 지금 따라 들어가기 | 시작 시점: 다음 진입부터 / 지금 포지션부터 |
| 주문당 상한 95% | 요약에서 빼고 "설정 더 보기"로 |
| 전략 복사 시작 | 전략 복사 시작하기 |
| 전략 복사는 무료입니다. 시작한 뒤에도 언제든 멈출 수 있습니다. | 무료이며 언제든 멈출 수 있습니다. |

## 결론
창은 유지(결정이 작다). 안은 다시 구성: 전략 한 줄 → 예산 칸 → 멈추는 기준 알약(-10 / -20 / -30 / 직접) → 요약 카드 행 4개 → 흰 알약 단추. 미연결 회원은 플랜 화면으로.
