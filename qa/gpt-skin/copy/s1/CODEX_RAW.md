**대화상자를 유지하고 내부 구성을 다시 설계하겠습니다.** 결정은 예산과 중단 기준 두 가지입니다. 전략 상세 위에서 끝낼 수 있으며, 플랜 구성처럼 두 열로 나눌 만큼 독립적인 입력과 요약이 많지 않습니다.

브리프와 첨부 화면, 현재 스타일 코드를 근거로 판단했습니다. 아래 화면 치수는 이미지 기준 근삿값입니다.

**나. 제안 구성**

설정 기준과 같은 **너비 520픽셀, 배경 `#303030`, 반경 26픽셀**의 대화상자를 사용합니다. 제목은 26픽셀 보통 굵기, 본문은 16픽셀로 구성합니다. 입력은 플랜 구성의 회색 표면과 중립 테두리, 시작 단추는 흰색 알약으로 통일합니다.

순서는 **전략 이름과 작성자 → 예산 → 중단 기준 → 확인 행 → 시작**입니다. 모바일은 한 열을 유지하고, 높이가 부족하면 내용 영역을 스크롤합니다.

| 필드 | 조작 요소 | 기본값 | 한 줄 설명 |
|---|---|---|---|
| 복사 예산 | 금액 입력칸, 단위 표시, `최대 금액` 보조 단추 | 빈칸 | 이 전략에 사용할 금액을 정합니다. |
| 손실 중단 기준 | 숫자 입력칸, `%` 표시 | 20%, 허용 범위 5~50% | 예산의 20%를 잃으면 복사를 자동으로 중단합니다. |
| 복사 시작 시점 | `다음 진입부터`와 `현재 포지션부터` 알약 선택 | 다음 진입부터 | 원본의 다음 진입부터 따라갑니다. |
| 주문당 예산 한도 | 숫자 입력칸, `%` 표시 | 95%, 허용 범위 5~95% | 한 주문에 사용할 예산 비율을 정합니다. |

마지막 두 설정은 기본 화면에서 접습니다. 확인 영역에는 **현재 선택값**을 항상 표시하고, 밑줄 링크 `복사 설정`으로 펼칩니다. 수정한 뒤에도 기본값으로 표시해서는 안 됩니다.

긴 요약 문단은 다음 확인 행으로 바꿉니다.

| 확인 항목 | 800달러 입력 시 표시 |
|---|---|
| 복사 예산 | 800달러 |
| 중단 기준 | 손실 160달러, 예산의 20% |
| 시작 시점 | 다음 진입부터 |
| 주문당 예산 한도 | 95% |

레버리지는 전략 이름 아래에 항상 **“레버리지 변경도 원본을 따릅니다. 현재 2배입니다.”**로 표시합니다. 공백 기준 7어절이며 고급 안에 숨기지 않습니다. 변경 알림은 브리프상 확인이 필요한 제안이므로 제공한다고 쓰지 않습니다.

미연결 회원은 브리프대로 플랜 화면으로 보내고, 현재의 3단계 안내 창은 제거합니다.
