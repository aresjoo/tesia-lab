# 설정(결제, 보안)이 ChatGPT 설정과 다른 제품처럼 보이는 이유

기준: ref-general, ref-appearance, ref-account (2000px 캡처, 1440 환산 약 0.72배). 대상: B1, B2, S1, G1, 모바일 B1-m, S1-m.

## 1. 겉모습

| 요소 | ChatGPT | TETH 지금 |
|---|---|---|
| 바탕 | 레일과 본문 모두 #000, 사이 1px 선 | 레일 #1a1b1f 회색 판, 본문 #101112. 두 판이 따로 논다 |
| 제목 | 400 굵기 큰 제목 | 700 굵기 30px, 굵고 좁다 |
| 섹션 제목 | 400 굵기 약 20px(환산 약 18) 흰색 | 700 굵기 16px |
| 행 라벨 | 400 굵기 약 17px, 보조 줄 14px 회색 | 600 굵기. 모든 라벨이 굵어 위계가 없다 |
| 카드 | 채우지 않은 검정 + 1px 옅은 테두리, 반경 약 20, 구분선은 좌우 여백 안쪽 | #15171a 채운 카드, 반경 14, 구분선 끝까지 |
| 오른쪽 조작 | 채운 회색 알약(#2f2f2f) 400 굵기: "변경", "자동 감지 ⌄", 삭제만 빨간 글자에 어두운 빨간 알약 | 테두리 알약 600 굵기, 행마다 1~2개("기본으로", "삭제") |
| 상태 표시 | 오른쪽 평문("pro") | 색 배지("결제 완료" 회색, "결제 실패" 빨강, "기본", "이 기기") |
| 레일 | 약 330px(환산), 글자 17px, 아이콘 20, 선택 행 #1f1f1f, 분류 이름 "개인" 400 회색, 검색 | 280px, 글자 15px, 아이콘 17, 분류 "설정" 11px, "바로 가기" 두 개(거래소 연결, 상담원) |
| 오른쪽 아래 | 없음 | 상담 단추가 떠 있다 |

## 2. 구조

결제 탭은 섹션 5개(구독, 결제 내역 표 4열, 결제 정보 3행 + 편집, 결제 수단 행마다 단추 2개, 해지)가 모두 같은 무게로 쌓였다. ChatGPT는 "무엇을 쓰고 있나" 한 카드, 나머지는 행 하나와 알약 하나로 줄인다.

- 결제 내역 표: 날짜, 배지, 금액, 화살표 4열. 설정에서는 최근 몇 건을 평문 행으로, 영수증은 행을 누르면 창.
- 결제 수단: 카드마다 "기본으로", "삭제". 설정에는 "결제 수단" 한 행(기본 카드 표시, "변경" 알약)만 두고 관리는 창에서.
- 결제 정보(이메일, 이름, 주소) 3행 + 편집: 한 행("청구 정보", 보조 줄에 이메일, "편집" 알약)으로.
- 보안 탭은 구조가 이미 가깝다(로그인 / 기기 / 거래소 권한). 겉모습과 카피만 바꾸면 된다.
- 모바일: 앱 배너 + 가로 탭 줄 + 내용. ChatGPT 모바일 설정은 목록 → 상세. 탭 줄이 잘려("←", "알림", "결제", "보안", "거래소…") 위치를 알기 어렵다.

## 3. 카피

| 지금 | 문제 | 제안 |
|---|---|---|
| "2026. 9. 11. 에 바뀌었습니다" | 띄어쓰기 어색 | "마지막 변경 2026. 9. 11." |
| "…승인. 출금 권한은 없습니다" | 묻지 않은 걱정을 꺼냄(거래소 연결 화면에서 이미 지운 문장) | 삭제. 보조 줄 "잔고 조회와 주문, TETH 초대 계정" |
| "잔고 조회, 주문 실행" (오른쪽 값) + 보조 줄 반복 | 한 행에 정보 4개 | 권한은 보조 줄로, 오른쪽은 알약 하나 |
| "권한 끊기" | 괜찮음 | "연결 끊기" (거래소 연결 화면과 같은 말) |
| "결제 완료" 배지 | 평범한 상태를 강조 | 표시하지 않음. 실패만 빨간 글자 "실패" |
| "기본으로" | 조사로 끝남 | 창 안에서 "기본 카드로 지정" |
| "해지해도 결제한 기간이 끝날 때까지는 모든 기능을 쓸 수 있습니다" | 길다 | "2026. 10. 21.까지 이용할 수 있습니다" (해지 창에서) |
| "이 기기를 뺀 모든 곳에서 로그아웃합니다" | 괜찮음 | 유지 |

## 4. 셸

결제와 보안만 바꾸면 일반, 계정, 알림이 옛 모습으로 남아 탭을 넘길 때마다 제품이 바뀐다. stRow, stSec, stBtn를 모든 탭이 같이 쓰므로 셸 전체를 바꾸는 편이 싸고 일관된다.

## 5. 결론

보안은 스타일과 카피만. 결제는 섹션 구성을 줄여야 한다(구독 카드 하나에 플랜, 결제 수단, 청구 정보 / 결제 내역 최근 3건 / 해지). 모바일은 목록 → 상세로 구조 변경. 셸은 전체 교체.
