**B. 제안하는 두 탭**

공통 스타일은 검정 본문과 레일, 1px의 어두운 회색 테두리, 검정 카드, 반경 16px로 정합니다. 제목 28px/400, 섹션 제목 16px/400, 행 라벨 16px/400을 사용합니다. 조작은 오른쪽 회색 알약, 인증 상태는 파란 토글로 통일합니다. 상태 배지는 일반 텍스트로 바꿉니다.

아래 ‘창’은 데스크톱 대화상자이며 모바일에서는 전체 화면으로 전환합니다. 별도 표시가 없는 행 본문은 클릭하지 않습니다.

| 탭 / 섹션 | 행 라벨과 보조 줄 | 오른쪽 조작과 결과 |
|---|---|---|
| 결제 / 구독 | **TETH 구독** / 월 US$280, 다음 결제일 | ‘구독 관리’ → 창. 다음 결제와 이용 종료 조건, ‘구독 해지’를 함께 표시 |
| 결제 / 구독 | 만료 시 **구독 종료** / 종료일과 해당 전략의 주문 중단 상태 | ‘다시 구독’ → 가격과 결제 수단을 확인하는 화면 |
| 결제 / 결제 관리 | **결제 수단** / 기본 카드 브랜드와 끝 네 자리 | ‘관리’ → 카드 목록 창. 기본 카드 선택, 추가, 삭제 제공 |
| 결제 / 결제 관리 | **결제 정보** / 결제 이메일 | ‘변경’ → 이메일, 이름, 청구지 주소 편집 창 |
| 결제 / 결제 내역 | 최신 **3건**. 날짜를 주 라벨로, 상태를 보조 줄로 표시 | 금액과 화살표. 행 전체 → 완료 건은 영수증 창, 실패 건은 결제 시도 상세 창 |
| 결제 / 결제 내역 | 4건 이상이면 섹션 오른쪽에 ‘전체 보기’ | 전체 내역 화면. 최신순 10건씩 페이지 이동 |
| 보안 / 거래소 연결 | **Bitget**, **OKX** 각각 한 행 / 잔고 조회, 주문 실행 | ‘관리’ → 승인일과 권한 상세 창. ‘권한 끊기’ → 영향받는 전략과 처리 결과 확인 창 |
| 보안 / 로그인 | **비밀번호** / 마지막 변경일 | ‘변경’ → 비밀번호 변경 창 |
| 보안 / 로그인 | **2단계 인증** / 로그인 시 이메일 인증번호를 확인합니다. | 파란 토글. 켜기 → 인증 창, 끄기 → 확인 창 |
| 보안 / 로그인한 기기 | **Windows, Chrome** / 현재 기기 | 조작 없음 |
| 보안 / 로그인한 기기 | **iPhone, Safari** / 서울, 마지막 활동 오늘 08:12 | ‘로그아웃’ → 해당 기기 확인 창 |
| 보안 / 로그인한 기기 | **다른 모든 기기** / 현재 기기는 로그인을 유지합니다. | ‘모두 로그아웃’ → 확인 창 |

모바일은 **설정 목록 → 탭 상세 → 관리 상세**로 이동합니다. 레일과 가로 탭 줄을 없애고 상단에 ‘설정으로’와 현재 제목을 둡니다. 다운로드 배너는 상세에서 제외하고, 상담 진입점은 설정 목록에 둡니다.

| 기본 화면에서 제거하거나 이동 | 반드시 유지 |
|---|---|
| 반복되는 ‘TETH 구독’ 내역명, 상태 배지 배경, ‘지금 사용 중’ 중복 설명 | 결제 금액과 통화, 날짜, 성공과 실패 |
| 이름과 전체 주소, 추가 카드 목록은 관리 창으로 이동 | 카드 식별 정보와 기본 카드 상태 |
| 연결 경로와 승인일은 권한 상세로 이동 | 실제 권한, 인증 방식, 기기 식별과 마지막 활동 |
| 매 행의 출금 부정문 | 해지와 권한 해제의 실행 시점, 전략에 미치는 영향 |
