**최종 통과는 보류합니다.** 판단 패널의 구조는 정리됐지만, 손익률 불일치와 기록 펼침 조작 등 필수 항목이 남았습니다. 아래 평가는 첨부 화면과 소스 확인 기준입니다.

**1. 3단계 필수 수정 재검수**

| 기존 필수 항목 | 판정 | 근거 |
|---|---|---|
| 규칙형 손절·익절 가격 | 표시 해결 | A1은 ‘진입가 대비 -3%, +8%’로 변경됐습니다. 실제 가격 계산 오류까지 해결됐다는 증거는 아닙니다. |
| 손익 기준 통일 | 부분 해결 | 생각에서 중복 수치는 없어졌지만, A3은 패널 +18.6%와 하단 표 +19.3%, A4는 +7.1%와 +7.2%가 다릅니다. |
| 현물·선물 표기 | 해결 | A2는 종목 행에 ‘보유’, 기록에 ‘현물 매수·매도’를 사용합니다. |
| 보유 상태 제목·정보 순서 | 해결 | A1~A4 모두 현재 보유를 제목으로 제시하고 거래소, 보유 행, 생각, 기록이 이어집니다. |
| 생각의 결정·변경 조건 | 해결 | ‘저는 … 유지합니다. …하면 정리합니다.’로 정리됐습니다. |
| 규칙형 기록 구조 | 해결 | A1 모바일에 날짜·꼬리표·한 문장·판단 전문이 있고 연속 유지가 묶였습니다. 한 문장 구성은 이번 변경 기준으로 수용합니다. |
| 기록 꼬리표 색 | 해결 | 매수·청산·후보 선정은 중립색이고, A2의 0.0%도 중립색입니다. |
| 기록 펼침·접기 | 부분 해결 | ‘판단 전문’은 보입니다. 소스에서는 펼치면 해당 글자를 숨기며 ‘접기’를 제공하지 않습니다. |
| 복사 전략 선택기 | 표시 해결 | A4 양쪽 크기에 두 알약과 선택 테두리가 보입니다. 소스에 축소 방지·상단 고정도 있습니다. |
| 기록·입력 영역 가림 | 확인 필요 | A1 데스크톱에서 기록 머리 부분이 입력 영역 경계에 걸립니다. 하단 여백 24픽셀 추가만으로 마지막 기록의 접근성을 확정할 수 없습니다. |
| 글자 크기 | 부분 해결 | 값 16픽셀·시각 14픽셀·기록 제목 18픽셀은 반영됐지만 본문 15픽셀, 행 라벨 14픽셀, 판단 전문 13픽셀입니다. |

**2. 남은 항목을 포함한 필수 수정**

| 캡처 | 위치 | 근거 | 고칠 값 |
|---|---|---|---|
| A3·A4 | 판단 패널과 하단 포지션 표 | 같은 보유 종목의 손익률이 서로 다릅니다. | 동일 시점의 투입금 대비 손익 계산값을 함께 사용합니다. 하단 열 이름도 ‘손익률’로 명시합니다. |
| A1~A4 | 펼친 판단 기록 | 펼침 안내가 사라지고 닫는 조작명이 없습니다. | 닫힘은 ‘판단 전문’, 열림은 ‘접기’로 전환합니다. |
| A1~A4 | 본문·행 라벨·전문 링크 | 기준 문서의 본문·행 16픽셀, 보조 행동 14픽셀에 미달합니다. | 본문·행 라벨 16픽셀, 전문 링크 14픽셀로 맞춥니다. |
| A3·A4 | 거래소 아래 다음 판단 | ‘다음 판단 다음 거래일 마감’은 반복 표현이며 날짜·시간대가 불명확합니다. | 실제 일정에서 ‘다음 판단 10월 ○일 ○시, ○○ 기준’을 생성합니다. 날짜를 임의로 넣지 않습니다. |

A1은 끝까지 스크롤한 상태에서 마지막 기록과 ‘접기’가 입력창 위에 완전히 보이는지 확인해야 합니다. A2 데스크톱의 빈 차트도 로딩 중 캡처인지 확인한 뒤 다시 제출해야 합니다. 두 항목은 현재 자료만으로 기능 결함이라고 단정하지 않습니다.

**3. ‘내 거래소’ 필터 검수**

한 거래소의 토글, 여러 거래소의 선택 목록, 켰을 때 안내 한 줄은 확정안과 일치합니다. 미연결 시 숨김도 소스에서 확인됩니다.

| 구분 | 위치 | 근거 | 고칠 값 |
|---|---|---|---|
| 필수 | 전체 목록 오른쪽 아래 상담 단추 | 기준 문서는 떠 있는 상담 단추를 숨기도록 명시합니다. 모바일에서는 카드 그래프 위를 덮습니다. | 부유 단추를 숨기고 목록 아래 상담 안내와 링크를 둡니다. |
| 필수 | E3 선택 목록 | 소스상 메뉴 역할은 지정했지만 열 때 초점 이동, 방향키 탐색, 닫은 뒤 초점 복귀 처리가 없습니다. | 열면 현재 선택 항목으로 이동하고 방향키 탐색·선택을 지원합니다. 닫거나 선택한 뒤 필터 단추로 초점을 돌립니다. |
