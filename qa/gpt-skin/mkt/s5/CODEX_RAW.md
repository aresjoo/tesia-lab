**최종 통과는 보류합니다.** 무기한 차트와 모바일 쌓기 구조는 개선됐지만, 3단계 필수 항목 일부가 남았습니다. 미리 보기 가격 문제는 합의대로 별도 처리하며 이번 통과 여부에서 제외합니다.

| 3단계 필수 항목 | 판정 | 근거 |
|---|---|---|
| 판단 가격·보유 상태 불일치 | 남음 | 전략 화면의 예시 가격 불일치는 별도 처리 대상입니다. 다만 매수 포지션을 보유하면서 “진입 조건을 확인”, “아직 진입하지 않은 이유”라고 표시하는 상태 문구도 남았습니다. 보유 시에는 청산 조건·보유 이유로 바꿔야 합니다. |

| 전략·복사 전략과 차트 연결 | 남음 | 종목 연결은 해결됐습니다. 그러나 전략은 우엑스, 복사 포지션은 비트겟인데 차트는 모두 바이낸스입니다. 운용 거래소로 연결하거나 “참고 시세: 바이낸스 / 운용: 해당 거래소”를 명시해야 합니다. |

| 카드 색·반경 통일 | 기각된 결정 | 파운더가 기존 어두운 카드와 반경 변경안 기각을 확정했습니다. 재수정 대상이 아닙니다. |
| 즐겨찾기·외부 아이콘·다운로드 색 | 남음 | 별의 무채색 전환과 상단 다운로드 배너 제거는 확인됩니다. 위젯 밖 코인·거래소 아이콘의 유채색은 남아 있으며, 해당 요구의 기각 기록은 없습니다. |
| 목록·정보·데이터 가독성 | 남음 | 컴퓨터 종목 목록은 15픽셀로 개선됐습니다. 정보 행은 여전히 14픽셀, 출처는 12픽셀·어두운 회색입니다. 데이터 축은 원본 11픽셀이 축소되어 모바일에서는 약 6~7픽셀로 보입니다. 축은 **최종 표시 크기 14픽셀**을 확보해야 합니다. |
