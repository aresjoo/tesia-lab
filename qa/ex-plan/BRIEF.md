# TETH 거래소 연결: "플랜 선택" 화면 재설계 브리프

## 0. 한 줄
거래소 연결로 들어오는 여섯 갈래를 하나의 화면으로 모은다. ChatGPT의 "플랜 업그레이드"와 "플랜 구성(결제)" 화면을 레이아웃, 위계, 여백, 글자 크기, 카피 톤까지 그대로 따른다. 카드는 둘: 무료(TETH 초대 계정)와 월 $280 구독. 결과가 좋은 백테스트에서 왔으면 왼쪽에 백테스트 결과를 같은 크기로 놓는다.

## 1. 들어오는 여섯 갈래 (전부 같은 화면으로)
| # | 입구 | 화면 왼쪽 | 첫 카드 강조 |
|---|---|---|---|
| 1 | 전략 복사 → 백테스트 결과 좋음 → 실행 | 백테스트 결과 카드(같은 크기) | 무료 |
| 2 | 전략 복사 → 백테스트 결과 나쁨 → 그래도 실행 | 없음(두 카드만) | 무료 |
| 3 | 전략 복사하기 즉시 | 없음 | 무료 |
| 4 | 내 전략(대화) → 백테스트 나쁨 → 그래도 실행 | 없음 | 무료 |
| 5 | 내 전략(대화) → 백테스트 좋음 → 실행 | 백테스트 결과 카드 | 무료 |
| 6 | 사이드바, 설정, AI 트레이딩 시작의 "거래소 연결" | 없음 | 무료 |
이미 연결된 회원은 이 화면을 건너뛴다(FLOWS.md ⑫~⑮ 규칙 그대로).

## 2. 참고 화면 (첨부 3장)
- 참고 A: ChatGPT 플랜 업그레이드(데스크톱). 두 카드, 오른쪽 카드가 파란 그라데이션 테두리와 배경, 위쪽에 매년/매월 토글, 제목 한 줄, 설명 두 줄, 가격 행, 큰 CTA, 아이콘 항목 목록, 맨 아래 작은 안내와 링크.
- 참고 B: ChatGPT 플랜 구성(결제). 왼쪽 결제 수단(Apple Pay, "또는", 카드 번호, 만료, 보안 코드, 저장 체크), 오른쪽 어두운 카드에 플랜 요약, 핵심 기능 4개, 매월 구독료/예상 세액/결제 금액, 흰색 CTA, 그 아래 자동 갱신 안내문.
- 참고 C: 참고 A의 모바일. 제목, 닫기, 세그먼트, 카드가 세로로 쌓임.
디자인은 "비슷하게"가 아니라 픽셀 단위로 같은 인상이어야 한다. 카드 반경, 테두리 두께, 그라데이션 방향, 항목 아이콘 크기(20px 선 아이콘), 제목 28~32px, 본문 15px, 가격 굵기, CTA 높이 48px, 카드 안 여백 32px, 카드 간격 24px.
TETH의 상표만 쓴다. OpenAI 로고, 이름, 아이콘은 쓰지 않는다. 별 반짝 아이콘은 TETH 마크로 바꾼다.

## 3. 카피 톤 (ChatGPT 한국어판과 같게)
- 제목은 명사구 또는 짧은 문장, 마침표 없음: "성장하는 팀을 위해" 식. 설명은 한두 문장 합니다체.
- 항목은 동사 없이 명사구: "거래 수수료 20% 환급", "24시간 계정 상담".
- 가격은 "월 $280", 무료는 "$0 / 월".
- 단추: "무료로 연결하기", "구독으로 연결하기", "Pro로 업그레이드" 톤.
- 금지: 규제 고지, 데모/예시 표기, em dash, 가운뎃점, TETH 수수료 구조 노출.

## 4. 화면 1: 플랜 선택 (참고 A)
제목: "거래소 연결". 부제 없음. 세그먼트는 없다(개인/비즈니스 대신 없음).
### 왼쪽 카드: 무료 (강조 카드, 파란 그라데이션. 참고 A의 오른쪽 카드 스타일을 이 카드에 적용)
- 라벨: "TETH 초대 계정"
- 제목: "거래하는 사람을 위해"
- 설명: "TETH 초대로 만든 거래소 계정이면 이용료가 없습니다. 카드 등록 없이 바로 연결합니다."
- 가격: "$0 / 월" (참고 A의 큰 숫자 스타일, 그라데이션 강조)
- CTA: "무료로 연결하기"
- 항목(아이콘 + 명사구):
  - "지원 거래소 7곳" (Bitget, Binance, OKX, Bybit, MEXC, WOO X, Gate 로고 줄)
  - "거래 수수료 환급: Binance, OKX, Bybit, MEXC, Bitget 20%, WOO X와 Gate 50%"
  - "전략 대회와 시즌 상금 참가"
  - "초대 계정 전용 혜택" (AC_CFG에서 읽음)
  - "24시간 계정 상담"
  - "출금 권한 없이 주문 권한만 연결"
- 아래 작은 안내: "TETH 초대로 가입한 계정에만 적용됩니다. 계정이 없으면 만드는 것부터 안내합니다."
### 오른쪽 카드: 구독 (일반 카드)
- 라벨: "TETH 구독"
- 제목: "지금 쓰는 계정 그대로"
- 설명: "이미 쓰는 거래소 계정을 바꾸지 않고 연결합니다."
- 가격: "월 $280"
- CTA: "구독으로 연결하기"
- 항목: "지원 거래소 7곳", "초대 계정이 아니어도 연결", "언제든 해지, 남은 기간까지 이용", "24시간 계정 상담"
- 아래 안내: "매달 같은 날 결제됩니다. 설정의 결제에서 해지할 수 있습니다."
### 백테스트에서 왔을 때 (갈래 1, 5)
- 3열: 왼쪽에 백테스트 결과 카드(같은 높이, 같은 반경), 가운데 무료, 오른쪽 구독. 결과 카드 내용: 전략 이름, 기간, 시작 금액, 수익률(큰 숫자), 그냥 보유와 비교, 낙폭, 거래 수, 작은 그래프. 단추 없음.
- 결과가 나쁠 때(갈래 2, 4)는 결과 카드를 놓지 않는다.
### 모바일 (참고 C)
- 제목 "거래소 연결"과 닫기. 카드 세로 쌓기. 첫 카드 무료, 그 아래 구독. 백테스트에서 왔으면 결과 카드가 맨 위.

## 5. 화면 2A: 구독 결제 (참고 B와 같은 구성)
- 제목 "플랜 구성", 뒤로 화살표.
- 왼쪽: "TETH 구독"과 "원하는 거래소를 고르십시오" 거래소 7곳 선택(참고 B의 SGD 138/300/690 칸 스타일로 로고 칸), "결제 수단 선택하기", Apple Pay 검은 단추, "또는", 카드 번호(브랜드 아이콘), 만료 날짜, 보안 코드, "향후 결제를 위해 결제 세부사항 저장" 체크.
- 오른쪽 어두운 카드: "TETH 구독", 핵심 기능 4개(아이콘), "매월 구독료 $280.00", "예상 세액 $0.00", "결제 금액 $280.00", 흰색 CTA "구독으로 연결하기".
- 아래 안내문(참고 B 톤): "취소할 때까지 매월 자동 갱신됩니다. $280/월이 청구됩니다. 설정에서 언제든지 취소할 수 있습니다."
- 저장 카드가 있으면 카드 입력 대신 저장 카드 선택. 실패 시 입력값 유지, 실패 안내, 다른 카드.
- 결제 완료 → 화면 3(거래소 승인).

## 5. 화면 2B: 무료 경로
- 거래소 선택(7곳) → "이 거래소 계정이 있습니까?"
  - 있음 → 화면 3(거래소 승인) → 초대 계정 확인 → KYC 확인
  - 없음 → 가입 안내(TETH 초대 주소 새 창, 본인 확인, 입금) → 화면 3
- 이 경로의 모든 화면 아래에 "24시간 계정 상담" 단추(상담원 연결).

## 6. 화면 3: 거래소 승인 (Fast API 연결)
- 제목 "거래소 연결", 설명 "거래소의 승인 화면에서 한 번 누르면 연결됩니다. 키를 만들거나 붙여 넣지 않습니다."
- 권한 표: 잔고 조회, 주문 실행, 출금 없음.
- CTA "Bitget에서 승인하기". 승인 창(TETH 확인 창, 거래소 주소창 흉내 없음).
- 승인 뒤 확인 단계(참고 B의 목록 스타일로 체크 진행):
  1. 연결 확인 ("승인한 계정을 읽는 중" → "연결됨")
  2. 초대 계정 확인 (무료 경로만) → 아니면 세 갈래(새 계정, 구독으로, 다른 거래소)
  3. 본인 확인(KYC) 확인 → 안 되어 있으면 "본인 확인이 끝나야 거래할 수 있습니다" + 거래소 본인 확인 페이지 열기 + "확인 완료" 다시 검사. KYC 미완료면 완료 화면으로 가지 않는다.
- 완료 화면: 계정, 이용료, 혜택, "터미널로 이동" 또는 원래 하려던 일(복사 이어서, 실행 준비)로.

## 7. 상태와 예외 (모두 화면으로)
- 손님: 화면 1을 볼 수 있고 CTA를 누르면 가입 창, 가입 뒤 같은 갈래로 복귀.
- 이미 연결됨: 화면 1을 건너뛴다. 다른 거래소가 필요한 전략이면 그 거래소만 추가(무료 회원은 초대 확인 다시, 구독 회원은 승인만).
- 구독 만료: 화면 1에서 구독 카드가 "다시 구독"으로, 저장 카드로 바로 결제.
- 승인 취소, 승인 실패, 결제 실패, 초대 계정 아님, KYC 미완료, 거래소 응답 없음(30초), 오프라인.
- 긴 전략 이름, 수익률 4자리, 거래소 로고 누락(글자 표시).

## 8. 완료 기준
- 여섯 갈래 모두 같은 화면 1로 들어오고, 갈래 1과 5에서만 결과 카드가 보인다.
- 데스크톱 1440, 모바일 390에서 참고 A, B, C와 나란히 놓았을 때 위계와 간격이 같다.
- 카피가 모두 3절 톤이다. 해요체 0, 금지어 0.
- 결제 → 승인 → 확인 → 완료, 가입 → 승인 → 초대 확인 → KYC → 완료가 QA 프리셋으로 재현되고 자동 테스트로 판정된다.
- 실제 결제와 거래소 승인은 아직 서버가 없다. 화면 안에서만 판정한다(실패 케이스는 QA 훅).

## 9. 진행 방식 (Codex와)
1. 설계 비판(Codex, 읽기만): 이 브리프와 참고 3장, 현재 거래소 연결 화면 캡처를 주고 구멍과 카피를 받는다.
2. 구현(Claude) + 프리셋 + 자동 테스트 + 캡처(데스크톱, 모바일, 참고와 나란히 놓은 비교 이미지).
3. 화면 검수(Codex, 새 컨텍스트): 참고 A, B, C와 TETH 캡처를 짝지어 "다른 점을 픽셀 단위로 나열"하게 한다.
4. 처음 보는 눈(Codex, 코드 없이 화면만): 무엇을 누를지, 어디서 막히는지.
5. 지적 반영 후 3, 4를 한 번 더.

## 10. 열린 질문 (답 없으면 괄호 값으로 간다)
- 무료 카드의 제목 문구 (기본: "거래하는 사람을 위해")
- 구독 카드에도 그라데이션을 줄지 (기본: 무료만 강조)
- Apple Pay 외 Google Pay도 (기본: Apple Pay만)
- KYC 미완료 시 부분 이용 허용 여부 (기본: 완료 전 이용 불가)
- 결과 카드에 "이 전략" 이름 옆에 등록자 표시 (기본: 표시)
