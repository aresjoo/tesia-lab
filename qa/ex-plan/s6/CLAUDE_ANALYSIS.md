# 플랜 뒤 화면(거래소 선택, 계정 안내, 연결 승인, 완료, 한도, 본인 확인)이 다른 제품처럼 보이는 이유

기준: ChatGPT 요금제(ref-A), 플랜 구성(ref-B), TETH 플랜 화면(P1). 대상: now-free-exchange, now-paid-auth, P2B, P3, P5, P4.

## 1. 겉모습: 한 번 누르면 디자인 시스템이 바뀐다

| 요소 | 플랜 화면 (괜찮음) | 그 뒤 화면 (문제) |
|---|---|---|
| 배경 | #212121, 카드 #303030 계열 | #101112 근검정, 카드 #171819 |
| 제목 | 32px, 400 굵기, 가운데 | 26px, 700 굵기, 왼쪽. "전략을 실행할 계정을 연결합니다" |
| 주 단추 | 흰색 또는 파란 알약(반경 999), 48px, 글자 400 | 연두 #c8f542 직사각형(반경 12), 56px, 글자 700. 화면에서 가장 밝은 물체 |
| 진행 표시 | 없음 | 번호 원 + 초록 체크 + 회색 번호 3~5줄 스텝퍼 |
| 선택 요소 | 타일을 누르면 바로 선택 (SGD 138 / 300 / 690) | 타일 고르고 다시 "거래소 선택" 단추를 눌러야 함 (두 번 누름) |
| 보조 행동 | 얇은 밑줄 링크 | "변경" 밑줄 링크 + "상담원에게 묻기" 테두리 단추 + 오른쪽 아래 상담 FAB, 3중 |

ChatGPT는 요금제 → 플랜 구성 → 완료까지 같은 검정, 같은 카드, 같은 흰 알약 단추를 쓴다. TETH는 플랜을 고르는 순간 "터미널 앱"의 연두 시스템으로 돌아간다. 파운더가 "첫 화면은 괜찮고 그 뒤가 별로"라고 느낀 첫째 원인이다.

## 2. 구조: ChatGPT는 화면당 질문 하나, TETH는 한 화면에 5단계 서식

- ChatGPT 플랜 구성: 제목 하나("플랜 구성"), 왼쪽에 입력, 오른쪽에 요약, 단추 하나. 남은 단계를 세지 않는다.
- TETH now-free-exchange: 제목 + 부제 + 완료 행(이용 방식) + 현재 행(거래소, 타일 7개, 각주, 단추) + 미래 행 3개(거래소 계정, 연결 승인, 초대 계정 확인) + 상담 문구. 한 화면에 7종류의 정보.
- "N단계 남았습니다"는 관공서 서식의 언어다. 남은 단계가 4라고 알려주면 안심이 아니라 부담이 된다. ChatGPT는 어디에도 진행률을 쓰지 않는다.
- 완료 행의 "변경" 링크는 스텝퍼를 유지하려고 생긴 요소다. 화면 단위로 나누면 뒤로 가기(<) 하나로 대체된다. ref-B의 "< 플랜 구성"이 그 예다.
- 완료 화면(P3)이 영수증이다: 실행 계정 / TETH 이용료 / TETH 혜택 세 줄 표. ChatGPT의 완료는 한 줄 확인과 단추 하나다.

## 3. 카피: 안심시키려는 문장이 불안을 만든다

| 현재 | 문제 | 제안 |
|---|---|---|

| "키를 만들거나 붙여 넣지 않습니다." | 사용자가 모르는 절차를 부정형으로 설명 | 삭제 |

| "OKX에서 본인 확인을 완료해 주십시오" + "연결은 되었습니다. 본인 확인이 끝나야 전략이 주문을 낼 수 있습니다." | 요청형 제목 + 설명 반복 | 제목 "OKX 본인 확인이 필요합니다", 한 줄 "본인 확인이 끝나면 전략을 시작할 수 있습니다." |

## 4. 결론

스타일과 카피만 바꿔서는 안 된다. 스텝퍼 자체가 ChatGPT 어휘에 없다. 상태 기계(acStep, acS)는 그대로 두고 그리기만 화면 단위로 바꾼다:

| 화면 | 제목 | 한 줄 | 입력 | 주 단추 | 보조 |
|---|---|---|---|---|---|
| 플랜 | 거래소 연결 | (없음) | 카드 2장 | 무료로 시작하기 / 구독으로 시작하기 | |
| 플랜 구성 (구독) | < 플랜 구성 | 연결할 거래소를 고르십시오 | 거래소 타일(즉시 선택), Apple Pay, 카드 | $280 결제하고 시작하기 | |
| 거래소 (무료) | < 거래소 선택 | 전략을 실행할 거래소를 고르십시오 | 거래소 타일(즉시 선택 = 다음 화면) | (없음, 타일이 곧 행동) | |
| 계정 (무료) | < OKX 계정 | TETH 초대 링크로 가입한 계정만 연결됩니다 | 없음 | OKX 가입 화면 열기 | 이미 초대 계정이 있습니다 → 승인 화면 |
| 승인 | < OKX 연결 | OKX에서 승인하면 연결됩니다 | 권한 2행(잔고 조회, 주문) | OKX에서 승인하기 | |
| 완료 | 연결되었습니다 | OKX 계정에서 전략을 실행합니다 | 없음 | 전략 시작하기 / 터미널 열기 | 거래소 더 연결하기 |
| 한도 | 거래소 2곳이 연결되어 있습니다 | 구독 하나로 2곳까지 연결됩니다 | 선택 카드 2개 (초대 계정으로 연결 / 구독 추가) | (카드가 행동) | 다른 거래소 고르기 |
| 본인 확인 | OKX 본인 확인이 필요합니다 | 본인 확인이 끝나면 전략을 시작할 수 있습니다 | 없음 | OKX에서 본인 확인하기 | 확인했습니다 → 다시 검사 |

모든 화면: `body.pl-page` 검정 배경, 제목 32px 400, 한 줄 18px 회색, 카드 #303030 반경 26, 흰 알약 단추 48px, 뒤로 가기 < 만. 스텝퍼, 번호 원, 연두 단추, "변경", "N단계", 부제 반복, 상담 3중 노출은 전부 제거. 상담은 화면 하단 한 줄 링크 하나.
