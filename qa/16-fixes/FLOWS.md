# TETH 사용자 흐름 표 (정본)

새 요청이 오면 먼저 이 표의 어느 칸인지 찍고 시작한다. 칸마다 프리셋, 캡처, 자동 테스트를 하나씩 대응시킨다.
갱신: 2026-10-01

## 0. 축

| 축 | 값 |
|---|---|
| 입구 | N 새 전략(자연어) / C 전략 복사 / T AI 트레이딩 시작 / A 분석시키기 / S 설정 |
| 상태 | ① 손님 / ② 로그인만 / ⑫ 초대 회원(Bitget 1곳) / ⑬ 구독 회원(Bybit, 카드 2장, 내역 3건) / ⑭ 두 곳 연결(Bitget 초대 + OKX 구독, 2단계 인증, 기기 2대) / ⑮ 구독 만료(카드 있음) |
| 결과 | 좋음 / 나쁨(그냥 보유보다 못함, 또는 마이너스) / 실패(승인 취소, 초대 계정 아님, 결제 실패, AI 오류) |

상태는 개발 패널의 QA 프리셋 번호다. 손으로 상태를 만들지 않는다.

## 2. 결과와 실패 칸

| 상황 | 지금 동작 | 판정 |
|---|---|---|
| 백테스트 결과 좋음 | 오른쪽 "이 전략 실행하기" | ✅ |
| 백테스트 결과 나쁨 (내 전략) | 같은 화면. "조건을 바꿔 다시 돌리기"는 기간과 금액만 | ❌ 보류 중. 제안: 규칙 고치기(대화로 복귀, TETH 제안) / 새로 만들기 두 갈래. 기간과 금액 링크는 없앰 |
| 백테스트 결과 나쁨 (복사 전략) | 같은 화면 | ❌ 제안: "이 전략을 바탕으로 새로 만들기" |
| 승인 취소 | 안내와 다시 승인 ✅ | ✅ |
| 초대 계정 아님 | 쉬운 말 안내, 세 갈래(새 계정, 구독, 다른 거래소) ✅ | ✅ |
| 결제 실패 | 안내, 입력값 유지, 다른 카드 ✅ | ✅ |
| 저장 카드가 있는 재결제 | 저장 카드로 바로, 다른 카드 사용 ✅ | ✅ |
| AI 답변 실패 (대화) | 오류 카드 + 다시 시도 | 🟡 다음 행동 없음 |
| AI 답변 실패 (분석시키기) | 오류 카드 + 다시 시도 | 🟡 캡처는 붙은 채 남음. 캡처가 실패하면 "설정값만으로 분석" 안내 |
| 재생 중 AI 판단 문장 실패 | "계산된 근거"로 표시, 결과에서 다시 시도 | ✅ |
| 화면 캡처 실패 (분석시키기) | 그 화면만 실패 표시, 계속 | ✅ |

## 3. 빈칸 (할 일 후보, 매출 경로 순)

1. 복사 → 활성화 → 결제 → 실행 경로의 ⑭ 두 곳 회원 자동 테스트 (지금은 캡처만).
2. 나쁜 백테스트 결과의 다음 행동. 보류 중, 확정 대기.
3. AI 실패 뒤의 다음 행동 (대화, 분석시키기 공통).
4. 터미널에서 실행 중인 전략을 다시 검증하거나 규칙을 고치는 길. 없음.
5. 실행 준비(백테스트 → 시작)의 자동 테스트. 지금은 캡처만.

## 5. 여정 테스트가 덮는 칸

A 손님 백테스트 복귀 / B 손님 목록, 초대 회원 활성화 / C 초대 계정 아님 / D 결제 실패와 성공 / E 이미 충족, 다른 거래소, 만료 / F 설정과 삭제, 초대 회원 결제 / G AI 트레이딩 시작부터 터미널 / 공통 문체, 통화, 오류.

## 6. 규칙

- 새 요청은 칸부터 찍는다. 칸이 없으면 표에 먼저 추가한다.
- 상태는 프리셋으로만 만든다. 빠진 상태가 생기면 프리셋부터 추가한다.
- 칸을 채우면 테스트 한 줄을 같이 추가한다.
- Codex 검수는 칸 단위로 준다. 캡처 2~3장과 기대 동작만.
