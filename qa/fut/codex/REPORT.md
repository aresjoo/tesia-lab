## 현실성과 데이터 진위

- 제공 파일 8×1,367일: NaN·OHLC 범위 오류·완전 평탄 결측 대체봉 0개. 원본 빌더는 누락 가격을 전일값(초기에는 최초 관측값), 누락 펀딩을0으로 채우므로 결측 수·raw 응답 보존이 필요하다. 0 펀딩일은 현 파일에서0개지만 개별 누락 정산 여부는 검증할 수 없다.
- 모든 시가=직전 종가, 일봉 고저 경로·주문 지연·호가·거래량·최소주문단위·수용 자금 규모 없음. 종가 MDD와 청산0회가 장중 위험0을 뜻하지 않는다. 실제 Bybit 청산 기준은 last-price OHLC가 아닌 mark price다. [Bybit 청산/체결 FAQ](https://www.bybit.com/en/help-center/article/FAQ-Order-Execution-and-Liquidation)
- 일 합계로는 펀딩 시각별 가격/보유 여부/급등을 복원할 수 없다. 최대 절대 일 합계는 SOL160.393bp, AVAX91.310bp. 거래소는 종목별 정산 간격이 다르므로 이벤트 원자료가 필요하다. [Bybit 펀딩 이력 API](https://bybit-exchange.github.io/docs/v5/market/history-fund-rate)
- 비용을5배로 놓으면 f5 전체244.4→134.7%, 현물180.5% 아래. f8은700.7→217.6%. 고정 5bp 슬리피지는 수용 규모 검증이 아니다.
- 8종목×3날짜 OHLC/펀딩 원본 요청48개가 모두 fetch failed, 웹 도구 API 대조도 접근 실패. **원본 시장 데이터 진위 재확인은 미완료**이며 로컬 산술 재현을 데이터 출처 검증 성공으로 쓰지 않는다. source-check.json에 요청 URL/실패 보존.

## 재현 및 증거

모든 생성물은 qa/fut/codex/ 내부. 제품 코드·AGENTS.md·우체통은 쓰기 범위 제한에 따라 수정/발송하지 않았다.

```powershell
rtk proxy node qa/fut/codex/audit.mjs
rtk proxy node qa/fut/codex/inspect.mjs

rtk proxy node qa/fut/codex/source-check.mjs
```

합성 테스트9개, 그중 미래변조30개 비교 통과. 이는 원본 엔진 테스트 실행이 아닌 독립 모형과 소스 분기의 일관성 검증이다. 입력 파일 SHA256가 최초와 동일한지 최종 확인했다.

검증 파일: `verify-files.mjs`는 생성한 .mjs 구문, JSON 파싱, 공백을 검사한다. 저장소 전체 `git diff --check`는 요청 범위 밖 index.html의 trailing whitespace로 실패했다. 해당 파일은 수정하지 않았다. 최종 tracked 변경 목록은 시작 때와 같은 4개 경로이며 검증 입력 SHA256도 동일하다. 이웃의 동일 행동 파라미터(이산 gate 등)는 표의 개수에 포함되므로 그 개수를 독립적인 통계 표본 수로 해석하지 않는다.
