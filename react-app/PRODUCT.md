# Product: TETH AI

## Register

product

## Users

한국어를 사용하며 자신만의 매매 전략 아이디어는 있지만 코딩과 검증 수단이 없는 개인 트레이더. 시장 전반을 물어보다 아이디어를 자연어로 말하고, AI의 능동적 질문을 통해 거래쌍·타임프레임·리스크 규칙이 있는 전략으로 만들고 싶어 한다.

## Product Purpose

제품 본체는 `aresjoo/tesia-lab` 원본의 전체 화면·대화·연구·거래소 연결 사용 흐름이다. UI·UX·배치·폰트·카피·SVG·애니메이션·모바일·다국어를 유지하면서 React로 이식하고, 필요한 서버 기능을 연결한다. 목표는 실제 AI 응답과 고객이 승인한 전략·위험 한도에 따른 실제 거래다. Mock·Demo·Paper·시험 응답은 내부 검증 수단이지 제품 완료 기준이 아니다. 최신 제품·보안·계약 권위는 TETH 활성 Program `PM/README.md`가 가리키는 정본 §0·§16·§17.1과 WORK_LEDGER다.

## Brand Personality

담대한, 정밀한, 든든한. 첫 대화는 ChatGPT처럼 가볍지만 구조화된 전략과 결과는 전문 투자 도구처럼 신뢰할 수 있어야 한다. 사용자가 막히면 AI가 먼저 묻고, 실패하면 다음 수정을 제안한다.

## Anti-references

ares는 참고 사이트가 아니라 제품 정본이다. 일반적인 디자인 취향이나 기존 백엔드의 제약을 이유로 원본의 배치·문구·색상·기능·흐름을 변경하지 않는다. 이전 QuantPilot·Liquid Glass 제안보다 사용자의 원본 보존 원칙이 우선한다. 원본 변경이 필요하면 대상·이유·영향·대안을 제시하고 승인을 받는다.

## Design Principles

- 첫 문장이 제품의 시작이다. 비로그인 상태에서 시장 질문이든 전략 아이디어든 바로 말할 수 있게 한다.
- 대화·연구·로그인·거래소 연결 흐름은 원본의 실제 최종 DOM·인터랙션을 기준으로 유지한다. 초기 HTML이나 다른 계정의 캡처만 보고 누락을 단정하지 않는다.
- 결과가 설명보다 먼저다. 수익률, 최대 낙폭, 승률, 거래 수를 하나의 맥락으로 보여준다.
- 실패는 다음 행동으로 바로 연결한다. 나쁜 결과에는 유지, AI 수정, 추천 전략을 구체적으로 제안한다.
- 연결되지 않은 실제 기능을 fixture·타이머·성공 문구로 대신하지 않는다. 원본 화면 복원과 실제 서버 연결 상태를 별도로 기록한다.
- LLM 출력은 주문 권한이 없다. 승인된 Strategy Version만 Validator → Risk Engine → Order Intent를 통과해 실행하며, 비밀정보는 서버에서 관리하고 출금 권한은 제외한다.
- 원본 폰트·SVG·모션을 보존하고, 승인된 접근성·번역 개선도 유지한다. 글꼴 stack 일치는 실제 glyph·픽셀 일치와 구분해 검증한다.
- 한 화면에 한 번의 중요한 판단만 요청한다.

## Accessibility & Inclusion

WCAG 2.2 AA를 목표로 한다. 키보드 탐색, 명확한 focus 상태, 색상 외 상태 표시, 44px 이상의 주요 터치 타겟, `prefers-reduced-motion` 및 `prefers-reduced-transparency` 대체 표현을 제공한다.
